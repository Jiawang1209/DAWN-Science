2026-10-21；分支 `codex/kernel-output-isolation`，基线 main `4d6f6d76`。修改留在独立工作区，尚未提交、合并或推送。

## 根因与修复

1. 普通对话共享的单个 kernelInstanceId 会被最后到达的 R/Python 消息覆盖。新增 kernels 状态中每门语言自己的可选实例身份（协议 8.24），由运行时查询并随现有状态/快照传递，主区按输出语言比对。身份未知时不猜；独立内核会话保留单实例判断；没有隐藏全部旧结果警告。
2. user_expressions 首次尝试未受内部消息屏蔽保护；R 兼容执行在 idle/超时后又撤销屏蔽，迟到输出可能进入对话。内部请求使用明确请求身份、私有应答监听，与公开订阅流分离。兼容执行和迟到消息同样隔离，不保存无限增长的完成 ID 集合，不按十六进制内容过滤。
