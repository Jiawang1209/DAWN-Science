# OpenAlex 文献检索与来源核验

用户已批准文献检索这一独立功能，采用本仓库实现与 DAWN 命名；按现有流程验证后合并本地 main，不推送。仅依据官方 API 文档独立实现，未引入外部参考项目代码、标识或文案。

## 用户入口和范围

设置 → 插件新增“科研文献 · OpenAlex”，默认关闭，启用后新建会话使用。三项工具：`openalex_search`（关键词、年份和条数），`openalex_lookup_doi`（精确 DOI 索引核对），`literature_save`（保存本会话实际取得的所选记录）。现有自定义 MCP 无变化，不另设模型或内核依赖。基础查询匿名访问，有服务额度和网络要求；401/403/429、超时、取消和无结果必须分开，首版不申请账号或存储 API Key。

每次检索有实际来源 URL、UTC 查询时间、原始检索条件、总数和返回数量；记录有稳定 ID、题名、作者、年份、期刊、DOI、来源和摘要状态。缺失字段明确空值；摘要只从来源提供的倒排索引重建，并说明截断。DOI 核对仅证明在索引中查到匹配元数据，不表示阅读全文、论文可靠或科学结论正确。

保存只接受本会话查询缓存中的记录标识，拒绝模型自行传入的题名/作者等引用数据；查到的记录最多保留最近 100 条，仅在当前会话运行期缓存；重启应用后需重新查询。写入工作区 `outputs/literature/` 下新建唯一目录，包含 references.json 与 文献清单.md，不覆盖旧文件。首次仅支持本地保存；远端会话可查文献但不提供本地保存工具，避免写错机器。

## 实现边界

TypeScript 客户端固定 OpenAlex 官方 HTTPS 地址，使用 fetch，不增加包。单次最多 25 条，超时 20 秒、响应预算 2 MiB、查询长度受限；不自动分页、下载 PDF、跳转到结果 URL 或重试刷请求。展示链接只允许 http/https，原始返回不作为指令执行。

工具作为第四个内置插件装配，沿用现有开关、新会话生效、读写权限门、只读方案门、Run 和产物观察。查询被明确登记为只读；保存必须有输出目录、通过写权限且拒绝符号链接、工作区逃逸、原始数据目录与覆盖。新功能不调整其他插件的默认状态。

首版用插件入口与自然语言对话完成检索，不新增独立文献库、PDF 阅读器或完整文献综述流程。比较过“要求用户安装第三方 MCP”和“单独新增文献工作区”两种方案；内置受限查询工具复用现有入口，能以最小范围交付可核验流程。

## 验收

客户端和保存逻辑先写失败用例；验证日期/条数参数、DOI 匹配/未找到、缺失摘要、坏响应、限流、取消、预算、已查记录选择、会话隔离和路径保护。真实 Electron 用本地固定 API 服务与共享推理夹具完成启用 → 新会话 → 实际工具查询 → DOI 核验 → 保存 → 文件预览；检查默认关闭、失败不报成功、方案期可查但不可写、关闭后新会话无工具。另保留少量真实匿名 API 探针，明确与固定数据验收分开。

插件总数为 4；设置导航显示的是启用数，文献默认关闭，因此仍为 3。既有视觉基线应保持不变；任何失败先检查实际 diff，原阈值与 mask 保持。固定 Dev Preview launcher 查看原生界面。新增内容做名称/标识扫描，历史文档和合法归属声明不做无关清理。

官方依据：https://help.openalex.org/api/authentication/ 、https://help.openalex.org/api/searching/ 、https://help.openalex.org/api/get-single-entities/ 。
