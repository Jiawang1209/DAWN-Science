# 给子 agent 一份可检查的交接材料

本轮专项实现，尚未提交或合入 main。它扩展普通子任务交接，不替代冻结科研路线和契约。

可以对主会话说：“先查看可交接来源，把早期确认的方法、单位和数据保护要求交给 scout，只读核查；引用当前路线步骤。”主会话使用 `subagent_context_sources` 查看当前分支的已完成正文 ID、路线步骤 ID 和历史已验收子任务 ID，再通过原 `subagent` / `start_subagent` 派单。

选择示例：

```json
{"agent":"scout","task":"只读核对早期要求，报告证据缺口","handoff":{"recentMessages":1,"messageIds":["实际正文ID"],"routeStepId":"实际步骤ID"}}
```

messageIds 数量必须等于 recentMessages（1–8）；不指定时保留原“最近 N 条正文”的行为。可另给 acceptedChildIds（最多 4 项），宿主只接受当前父会话下已结束且带 accepted 回执及版本的身份。字段只指定 ID，正文和引用由宿主读取，不允许模型自行填写“证据内容”。来源工具只读，不能启动任务；目录显示最近 64 条正文、32 个回执，较早正文省略数量可见。

交接保存来源、正文、选择、路线修订、历史回执摘要指纹和产物内容版本；正文不超过 16 KiB，v2 整体不超过 64 KiB，超限拒绝。不会带思考、未完成回复、工具原文或新增权限。路线是记录，不代表用户批准；历史 accepted 及版本身份不证明当前文件仍相同，正式采用产物仍须走原版本核验与契约验收。

在“团队 → 运行总览 → 已冻结交接”展开，可以查看早期要求、来源会话、指纹和人可读路线；需要核对时再展开引用原文。续问和应用重启保留同一份交接，不追入父会话的新内容。缺失、篡改、换选择、跨父会话来源均拒绝；原 v1 交接保持兼容。

科研契约任务和其独立审阅仍使用原冻结路线、输入/产物版本及宿主回执，不接收这种普通父对话快照，避免分析者推理污染审阅。

最终实际桌面示例见 `validation/evidence-evaluation-20261107/final-demo/evidence/`；构建与回归记录见 `reviews/2026-11-07-evidence-evaluation.md`。该示例使用真实 Electron/Pi/文件/恢复链路和本地确定性推理，不证明真实模型一定会正确选择交接材料。
