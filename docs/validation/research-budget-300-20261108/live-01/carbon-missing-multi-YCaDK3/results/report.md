# carbon_mg_g 算术均值 — 结果报告

## 1. 输入

- 数据文件：`input.csv`（唯一数据源；只读，未做任何修改）。
- 结构：1 行表头 + 48 行数据，列恰为 `site, carbon_mg_g, rain_mm`。
- 目标列：`carbon_mg_g`；单位 `mg/g`（单位仅来自列名 `carbon_mg_g` 与用户声明，文件内没有独立的单位元数据或方法说明，未做任何单位换算）。
- 协变量：`rain_mm`（mm，单位同样仅由列名推断）在全部 48 行都有值；本次计算**不使用**它做筛选、分层或协变量调整。

## 2. 处理

- 缺失规则：**仅**丢弃目标列 `carbon_mg_g` 为缺失（字面量 `NA` 或空字符串）的行；其他列（含 `rain_mm`）不参与任何筛选。
- 实测缺失：7 行——文件行号 2, 9, 16, 23, 30, 37, 44，即数据第 1, 8, 15, 22, 29, 36, 43 行（对应 `plot-1, plot-8, plot-15, plot-22, plot-29, plot-36, plot-43`；`input.csv` 第 1 行为表头）。文件内缺失编码一致，只有字面量 `NA`，无空字符串、无 `NaN`、无 0/-999 等哨兵值，因此未做任何填补、插值或截尾。
- 有效样本：41 / 48 行（脚本内实测计数，非预设）。
- 非缺失且非数值的取值会让脚本报错并以非零码退出，不做静默跳过或按 0 兜底。
- 方法：算术均值（等权），`mean = Σx / n`，累加用 `math.fsum`（精确舍入），未使用中位数、几何均值或插补后均值。
- 未按 `rain_mm` 做任何筛选、分组或加权；未做训练/测试切分或模型选择。

## 3. 结果

| 指标 | 值 |
|---|---|
| 有效样本数 n | 41 |
| 算术均值 | 13.870731707317074 mg/g |
| 有效值域 | [12.0, 15.6] mg/g |
| 缺失（已丢弃） | 7 行（目标列 `NA`） |

- `mean = 13.870731707317074`（未截断的浮点值），单位 `mg/g`。
- 这是**可观测子集**的点估计，没有区间估计。

## 4. 局限

1. **缺失机制未知。** `carbon_mg_g` 的 7 个 `NA` 恰好每 7 行出现一次（plot-1/8/15/22/29/36/43），呈确定性等间隔排布；在缺少数据生成说明的情况下无法假定 MCAR/MAR，也无法排除与取值相关的缺失。因此本结果是完整案例（可观测子集）均值。
2. **不可外推。** `rain_mm` 随 `site` 序号严格单调递增（300→817，每行 +11），site/rain 存在完全共线的梯度；未纳入设计信息，故该均值不应被当作任意 site/rain 水平下的总体均值或梯度均值。
3. **单位仅源于列名。** 文件内无独立单位元数据，`mg/g` 来自列名 `carbon_mg_g` 与用户声明；若上游实际单位不同，本结果不能直接解释，需要换算。
4. **未做不确定性估计。** 无抽样设计、无重复测量信息、无权重，因此未计算标准误、置信区间或任何 p 值；报告不作"显著""效应量"等推断性表述。
5. 未做缺失填补、敏感性分析或协变量调整（按批准方法有意排除）。

## 5. 复现

单一命令（在包含 `input.csv` 的目录下运行，仅用 Python 标准库，无 subprocess/网络/第三方包）：

```bash
python3 -I results/analysis.py
```

脚本只读 `input.csv`，只写 `results/result.json` 与本报告 `results/report.md`；自证性检查（n 为正整数、行数守恒、均值有限且落在观测值域 [12.0, 15.6]、落盘 JSON 与内存计算一致）任一失败即以非零码退出。

`results/result.json` 内容（平铺对象）：

```json
{"n": 41, "unit": "mg/g", "mean": 13.870731707317074}
```
