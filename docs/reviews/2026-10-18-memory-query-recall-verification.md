## 根因与最终行为

原实现对整个 query 做连续 includes。真实案例的多词查询即使包含正文中的词也无法匹配；单关键词“生物量”能读取同一记忆，排除记忆不存在或作用域关闭。

现在先对查询和可搜索文本做 NFKC、大小写、连续空白归一化。精确短语结果优先；只有记忆允许分词召回，使用内置 Intl.Segmenter 中文分词，移除单字符/少量功能词并去重。中文词做连续片段匹配，非中文词按词边界匹配；至少两个有效词命中才召回，按命中数、命中字数、目录序稳定排序，再做原 offset/limit 分页。空查询保留目录序。中文查询不额外对每条正文做无用分词。

技能仍按名称/用途字面匹配，原先用途完整文本可查。所有评分在现有可见索引及 kind 过滤之后；不加载待确认/归档/其他项目或分支，不扩展权限，响应结构和短预览保持。正文原文不做归一化改写。没有新增依赖、向量库、服务或模型检索请求。

这是关键词召回，不保证同义词、翻译或语义理解。工具说明要求读取候选正文确认；无结果仍可缩短查询或空查询分页列目录。
