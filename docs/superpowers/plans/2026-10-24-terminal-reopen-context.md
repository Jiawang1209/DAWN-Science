# 终端关闭后直接重开与原会话恢复

用户已批准修复：关闭最后一个 DAWN 终端后，不必先去会话页点击重连，即可直接新开终端并恢复原会话。使用 `codex/terminal-reopen-context`，基线 main `0c96a5e9`；不合并、不推送、不替换安装版。

**架构**：Normal Shell 的创建只需要合法的本地 API 主会话记录，不要求原模型运行时活着；模型控制与执行仍要求活跃且可控制的本地主会话。历史恢复沿用原订阅和原 session ID，不新建或复制消息，不改变普通 dawn 新建的行为。

**实际预览 QA**：使用独立开发配置和已配置模型，原图会话不复制、不丢弃。检查关闭唯一终端 → 空状态 → 直接新开 → 接续原会话；原图缩略图与追问；返回同一会话；Normal 来回切换；常驻统计不挤掉 `> DAWN` 输入。额外检查暂停主会话不能取得模型终端控制权，以及数据缺失和窄终端显示。预览标题明确标识新分支，保留安装版。

**统计来源边界**：SDK 会把厂家省略的部分字段补为 0，已有历史记录无法区分这种零值与真实零值。只要有这种不确定条目，累计正数显示为已知下界 ≥；累计仅为 0 时显示“未确认”，不宣称真实 0，不计算不完整的命中率。整条全零成功回执视为用量未提供；失败/中断但有非零回执的实际消耗仍计入，空占位跳过。保留原有模型传输，不为展示统计拦截或重写网络响应。
