# 温度算术均值分析报告（tabular-ecology@1）

## 1. 结论

| 项目 | 值 |
|---|---|
| 目标列 | `temperature_c` |
| 指标 | 算术均值（arithmetic mean） |
| 样本量 n（使用 / 读入） | 4 / 4 |
| 均值 | **20.0 °C** |
| 单位 | `°C` |

均值 = (14.0 + 18.0 + 22.0 + 26.0) / 4 = 20.0 °C。

## 2. 输入

- 文件：`input.csv`（UTF-8，逗号分隔，5 行含表头，4 条数据行）
- 表头：`site, temperature_c`
- 读取到的 temperature_c 观测：`[14.0, 18.0, 22.0, 26.0]`
- 站点标识：`['A', 'B', 'C', 'D']`；重复站点：无
- 取值范围：14.0 ~ 26.0 °C；极差 12.0 °C；相邻差 [4.0, 4.0, 4.0]

## 3. 方法与适用条件核查

**所用方法**：目标列全部有效观测的算术均值，单位 °C（与输入列同单位，未做任何换算）。

条件逐条核查结果：

1. **数值型连续变量** —— 通过：4 个观测全部可解析为有限浮点数，无 `nan` / `inf`，无文本混入。
2. **目标列缺失值** —— 通过：temperature_c 中缺失值 0 个。非目标列缺失值 0 个（与本指标无关，按要求仅忽略该列、不影响 n）。
3. **不得丢弃样本** —— 通过：读入 4 行，参与计算 4 行，差值为 0。
4. **输入结构符合冻结契约** —— 通过：表头含 `temperature_c`，数据行数等于声明的 4 行，每行字段数与表头一致。
5. **单位可判定** —— 通过：列名 `temperature_c` 与契约单位 `°C` 一致，未做单位推测或换算。
6. **算术均值本身可用** —— 通过：观测为等权独立记录（每行一个站点、无重复站点），加总与除法的定义域成立。

**计算与交叉校验**：主算法 `statistics.fmean` 得 20.0；`math.fsum/n` 得 20.0；内建 `sum/n` 得 20.0。
三者差均 ≤ 1e-09（契约容差），校验通过。

## 4. 处理过程（可复现）

1. 以 UTF-8 读 `input.csv`，按 `csv` 模块解析，表头逐字段去除首尾空白。
2. 校验表头存在 `temperature_c`（大小写与拼写精确匹配）；缺失则阻塞退出。
3. 丢弃纯空行（不计为样本）；校验每行字段数 = 表头字段数。
4. 目标列缺失标记（空串、`NA`、`N/A`、`nan`、`null`、`-` 等）计数为 0；若出现则按契约 `missing: block` **阻塞**，不填补、不丢弃。
5. 逐值 `float()` 解析并要求 `math.isfinite`；任一失败即阻塞。
6. 校验 n 等于声明的 4 行。
7. 计算算术均值，并用两种独立实现交叉校验至 1e-09。
8. 写出 `results/result.json`（平铺对象 `{n, unit, mean}`）与本报告。

运行方式（唯一命令，隔离解释器，不创建子进程）：

```bash
python3 -I results/analysis.py
```

脚本仅用 Python 标准库（`csv`/`json`/`math`/`statistics`/`pathlib`/`sys`），无网络、无随机、无时间戳，重复运行输出一致。

## 5. 局限

- **样本量极小（n=4）**：无法评估分布形状、离群值与稳健性；此处仅报告点估计，未给出标准误、置信区间或显著性检验，因为这些在 n=4 下不具可靠推断力。
- **摄氏度是区间尺度**：°C 的零点为约定零点，均值的加总只对温度*差*有意义。若需跨数据集比较或计算比值，应改用开尔文（K）；本报告按契约只报告 °C，未做单位换算。
- **未做分层/加权**：每个站点等权，未按面积、时长或观测频次加权；若各站点代表范围不同，简单均值会被代表范围大的站点拉扯。
- **单列、单变量**：未检验与其他列（如 `site`）的关联，也未做时间或空间自相关诊断。
- **缺失值策略的后果**：契约要求"目标列出现 NA 即阻塞"，因此本脚本不会给出"剔除缺失后"的替代结果；如未来数据含 NA，需要上游决定补齐读入策略（并重新冻结 n）。
- 结果只对 `input.csv` 本次内容成立；文件一旦变更需重跑。
