# 终端上下文按钮检查

分支 `codex/terminal-reopen-context`，基线 `a77d10ec`。用户要求把底栏末尾的上下文文字改成会话页同款按钮，模型与其余累计统计保持原样。不合并、不推送、不替换安装版。

内置终端复用原 `ContextMeter`：圆环＋百分比常驻，悬浮查看、点击钉住，Esc 或点外部关闭；详情显示已用/上限和自动压缩阈值。仅增加读取详情，不增加手动压缩写操作。独立终端保留完整文字读数。

CLI 底栏按原居中布局预留十列，发出仅含视口几何和刷新版本的控制帧；UI 严格验证字段、整数、末行和屏幕范围。数值及目标会话不接受终端字节指定，仍从已绑定 native 会话的 `getContextUsage` 读取。按用量快照版本及打开详情刷新，无定时轮询；晚回包受版本守卫保护。Normal、缩放、退出及卸载时清理旧按钮。鼠标点击不传给 Shell/Agent。
