# 终端历史搜索实施计划

目标：在已有终端布局上增加“搜索历史”和“找回输入”，保持一个终端输入区，搜索和采纳均不执行命令。

- [x] 先补失败测试：DAWN 当前内容跨屏检索、草稿保留、输入历史按关键词筛选、Enter 只填草稿、Esc 取消、多行原文及恢复会话。
- [x] DAWN 复用 TUI 的全文搜索索引和定位；补可见入口和桌面快捷键。搜索期间独占输入，不能误触发发送、工具展开、退出或停止。
- [x] DAWN 用独立输入历史浮层，Ctrl+R 打开，按关键词过滤，上下键选择，Enter 填草稿、Esc 取消。来源只含当前原生会话的用户输入，恢复原会话时重建，不混入模型和工具输出。
- [x] Normal 内容搜索采用官方 xterm SearchAddon，查当前终端已保留的滚屏，显示匹配数、上下个命中、无结果和关闭；查找输入仍发送 Ctrl+R 给原 Shell，不读写 Shell 的历史文件。
- [x] 顶栏两个入口；Cmd/Ctrl+F 查内容，Ctrl+R 查输入。短窗口不新增第二输入框；模式切换和切换终端清理搜索状态。
- [x] 运行相关单元测试、类型检查、构建和真实 Electron 搜索、关闭与返回回归；在隔离实际预览检查宽窄窗口。记录本地提交，不合并、不推送、不替换安装版。

边界：内容检索只覆盖当前终端保留的记录；不是跨会话全局检索。DAWN 已折叠的工具详情需先展开再搜；完整原会话可返回会话页查看。输入历史最多保留最近 100 条，找回时保留多行。
