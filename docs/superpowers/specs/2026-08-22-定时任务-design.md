# 定时任务（schedule）

> 学自 `MichengAI/dsh-automation` v0.1.5（Apache-2.0；本地副本 `ccb_hive_code_learn/dsh-automation`，
> 解读全文 `dsh-automation-解读.md`）。思路借、代码自己写。作者 2026-08-22：「可以，开始做」——
> 第一批四种计划；定时任务能选服务器。

## 是什么

到点了就开一段**全新的**会话（`createTask`，本机项目或服务器），把任务说明以用户身份写进去，等 agent 这一轮说完——
那段话就是摘要。**不继承任何对话**。无人值守：权限用设置里的档，要确认的一律拒（门本来就这么做）。

## 定案

### 三条铁律（照它的）
- **一次运行是一个快照**：任务说明与定义版本在入队那一刻拷进 run；改了定义版本 +1，已排队的按旧的跑，改之前的到期不再认领。
- **at-most-once**：`occurrenceKey = 定义id:版本:到期时刻`，run id 是它的哈希；手动跑带 nonce。
- **没跑成也留一条并说为什么**：`skipped(overlap)` 上次还在跑；`skipped(misfire)` 回来时超过 15 分钟补跑窗口；
  `failed(host_interrupted)` 重启时还没跑完；`failed(definition_deleted)`；`failed(executor_error)`；`timeout`（60 分钟）；`session_exited`。

### 计划（`schedule/recurrence.ts`，纯函数，带时区、不引 luxon）
一次 / 每天 HH:mm / 每周几 HH:mm / 每 N 分钟（从锚点起）。时区用本机的，记在定义里。
`Intl.DateTimeFormat.formatToParts` 反解本地时刻 → UTC，夏令时空洞取靠后的解。月与「每 N 天」第二档。

### 调度器（`schedule/scheduler.ts`）
一个 `pumpOnce`：认领每条 active 定义的「最近一次到期」→ 按容量（2 并发、同一定义最多 1 活）启动排队的 → 按下一次到期设 timer（unref）。
操作串成一条 promise 链。时钟与执行器注入，单测用假的。每条定义留 200 条记录。

### 存储（schema v15）
`schedules`（定义）、`schedule_runs`（运行；`occurrence_key UNIQUE`）。删定义**记录留着**。

### 界面
侧栏「远程助理」下常驻一行「定时」（它是建东西的入口，不像「已归档」）。一屏：常驻一句**「DAWN 关着的时候不跑。回来时超过 15 分钟的那次记成跳过，不补」**；
列表（名字 / 计划 / 跑在哪 / 下一次 / 上次结果、暂停 ⇄ 恢复、「⋯」：立即跑一次 / 编辑 / 看它的记录 / 删除）；新建 / 编辑表单
（名字、任务说明、计划四选一、跑在哪 = 项目或服务器、用哪个 agent——远端只列能上服务器的）；下面执行记录，点一条打开那段会话（标题「<名> · <时刻>」）。

## 第二档（作者：「第二档依旧也要做」，同日做完）

- **计划**加每月几号、每 N 天（没有那一天的月份跳过；每 N 天从起点那天起算）。
- **每条任务自己的权限档**：`ToolGateContext` / `语境` 多 `sessionId`，`造门(取档(sessionId))`；`wiring.ts` 有一张「按会话的档」表，定时的会话开起来时按定义里存的档登记，别的会话跟全局设置。表单里两档：拦危险的（缺省）/ 全放行（列表上标红）。
- **对话里建**：MCP 网关多三件工具 `dawn_schedule_create / list / delete`。跑在哪、用哪个 agent 取当前会话的。**当前会话是「拦危险的」档时建成暂停的**，回话里让 agent 告诉人去「定时」按恢复——这就是我们的「授权卡」：无人值守的东西不该由一句话就开起来。
- **结果推微信**：跑完 / 失败各一句，跟远程助理「跑完通知」的两个开关走；没绑就不发。
- **执行记录筛**：今天 / 这一周 / 这个月 × 状态。
