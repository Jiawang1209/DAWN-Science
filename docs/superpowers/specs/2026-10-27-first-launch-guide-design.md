# 主区域四步首次使用向导

用户已确认采用主区域四步向导，保留现有密钥验证与错误提示，R/Python 配置可以跳过；在独立分支开发，并展示真实应用效果。

## 页面与交互

1. 欢迎：现有品牌图标、产品定位，说明对话、代码与研究成果可以在工作台中协作。
2. 功能：科研对话、R/Python 与 Notebook、项目文件与成果、远程计算四张简短卡片，明确计算功能的环境前提。
3. API Key：沿用服务商选择、密码输入、保存并验证、凭证异常、模型目录异常、安全存储提示。成功后由用户点下一步；保存失败留在本页；网络验证不确定仍沿用现有 soft 规则。允许稍后配置，但不能把跳过描述为密钥已验证。
4. 计算环境（可选）：复用 InterpreterPicker，检测或手填 Python/R 路径，展示内核包状态。未配置可直接进入工作台；不执行安装。

顶部显示四步进度与当前步骤，底部保留返回和主操作，页面切换后焦点移到页面标题；验证进行时禁止离开配置页。密钥和探测结果保存在向导组件中，返回上页不丢失状态。

## 状态和兼容

继续使用现有无凭证触发、向导在保存凭证后保持显示的机制。新增独立介绍完成标记，兼容旧 setupSkipped；已有用户不会被升级强制拉进介绍。完成或跳过向导记录介绍已完成；从状态栏补填密钥直接进入第三步，跳过后重启不重复介绍。首次中途关闭尚未完成的介绍不记录完成，也不持久化密钥草稿。

API Key 保存调用与后端验证机制不变。解释器检测仍按用户点击触发；存储失败或路径问题继续反馈给用户。

## 验收

组件回归覆盖四步顺序、回退、密钥草稿保留、验证等待、保存失败、硬失败和 soft 提示、多服务商可用性、跳过与存储兼容、解释器探测和可选进入。Electron 回归覆盖真实默认配置、保存后仍在向导、解释器落设置、重开跳过、直达密钥页、首条 native 对话。构建后截图四页，检查窄窗口和双语。所有运行使用隔离配置与假模型，不使用真实密钥或替换已安装应用。

## 用户补充确认：连接检测与界面语言

介绍页及后续步骤提供中文/English 切换，写入主应用已有的语言偏好，进入工作台与重启继续沿用。向导期间保持组件身份稳定，切换语言不清空步骤、Key 草稿和检测结果；语言选择支持方向键与单一 Tab 入口。

API 配置可选择运行时目录服务商，也可填写自定义 http(s) URL。目录返回不含凭证的默认地址和协议，用于精确 origin/路径匹配；常见 chat/completions、responses、messages 路径规范化为基址。未知地址不通过 Key 前缀冒认服务商；用户可指定模型 ID 和接口协议。填写的 Key 可直接测试连通；检测不落盘，修改输入后撤销旧结论，保存继续走原验证链路。

检测、连接保存、保存验证及自动生成的默认模型保持一致：显式模型优先于目录合并顺序，显式协议落在模型条目上；补填已有连接时保留其他模型。缺少明确配置的模型时如实报告，不悄悄替换。Key 暂缓时进度显示稍后配置，不显示已完成勾选。

## 用户视觉修正：独立卡片

用户查看效果后要求采用 card 形式：每次只呈现一张居中紧凑卡片，完成后切换下一张。卡片最大宽度 36rem，语言、页面内容、进度圆点、上一步和下一页均位于同一张卡片内部；主区域保留工作台背景。四步行为和已实现的验证、语言偏好逻辑不变。长内容仅在卡片正文滚动，导航始终可达。
