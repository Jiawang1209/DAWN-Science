# 协作证据直达与交付评测

已选定对话协作台为默认入口，展开进入流程工作台。参考 Harness 的成员联动和按需查看轨迹，沿用 DAWN 的宿主验收、契约和产物锁。

1. 在隔离工作区，为新执行的原始 Pi 工具调用和结果记录位置；结算摘要仅保存小型引用。按需读取一条记录，先匹配会话、运行代次或团队任务尝试，再匹配工具身份。旧记录、没有可核实来源的 Bot、缺失或歧义数据只显示原有摘要。验收：重复工具编号、旧代次和跨会话均不误读；真实 Electron 中可看到一条调用的原始参数与结果。
2. 展开工作台中图和列表保持联动，详情进入布局内的独立栏；窄屏用纵向布局。工具记录按需增加显示、支持仅看失败。保留返回、焦点、旧子任务入口和预览守卫。验收：桌面截图检查列表与详情不互相遮挡，打开记录不会启动任务，取消后的诊断不冒充验收。
3. 沿用配对评测与请求门，新增短任务和较大样本任务，保留单位未知的正确阻塞对照。报告独立核验合格交付数、正确阻塞、误验收、请求额度耗尽以及每份合格结果消耗（含失败试验成本）。先用离线确定性推理走真实执行链和文件验收，结果与真实模型收益分开。本轮不自动发真实请求。
4. 定向单测、类型检查、构建、完整 Node/UI 与相关 Electron 回归，复核后提供可查看截图和评测报告。旧 Electron 偶发关闭异常仍保留 OPEN。按本轮范围保留专项工作区，不自动提交、合并、推送或发布。
