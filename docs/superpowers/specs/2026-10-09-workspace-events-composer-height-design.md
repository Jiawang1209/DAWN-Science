# 工作目录迁移事件与空输入框高度修复

用户已确认继续修复全量验证发现的两处缺陷。基线 main d7e7724d，分支 codex/fix-workspace-events-composer-height；复用当前隔离工作树，不触碰原工作区 run_code 改动。

## 事件生命周期

保留 NativeRuntime.stop 清理旧生命周期观察者的约束。后端创建、恢复、rehome 成功后共用一个事件接线入口：旧接线先退订，新接线只保留一份，先记账再呈现；退出时释放接线。迁移后向事件中枢补 started 和当前开关，历史条目保留。重复选择当前目录不得重复呈现或累加用量。不同会话独立。

不采用撤销 sinks.delete 的方案，因为那会恢复旧生命周期重复记账问题；也不在 UI 轮询回复，事件丢失应在后端修复。

## 输入框

使用浏览器的 :placeholder-shown 识别 DOM 空值，此时 field-sizing: fixed、height: 44px；非空继续使用原生 field-sizing: content 与原有上限。这样不需要额外 React 草稿状态，不改变中文组词机制，主区/侧边共用规则。空占位文字单行显示并在右侧裁剪，不生成内部滚动条；输入真实文字仍按内容伸缩。停止与宿主收摊时等 exited 才退订，保留停止期间最后一笔用量/产物记录。

## 验收

真实 NativeRuntime + 后端回归验证迁移、重复迁移、停止恢复后的事件一次性与 token 记账。Electron 原失败两条工作目录用例、1280/1920 两条侧边几何用例必须由红变绿；扩展侧边输入增高、清空收回。复验会话恢复、重启续聊、输入法、草稿和自动增高路径。已有四项 app-default-client mock 失败及旧视觉基线不属于本轮修复。
