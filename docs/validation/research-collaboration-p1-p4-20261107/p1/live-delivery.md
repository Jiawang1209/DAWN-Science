## 原始失败与用量边界

- 审阅首次提交缺少必填 `data.reviewedPaths`，被 SDK 拒绝；下一轮 assistant 补齐后正式验收。不是网络自动重试，也不能把 SDK 拒绝算成宿主退回。原始 JSONL 第 13—15 行保留。
- 核查阶段两次提前读取尚未生成的产物，产生 ENOENT；真实工具失败也保留。下轮效率改进应据此评估，不能把本轮描述成无错误执行。
- `19,903 / 53,080` 仅为已记录 input+output，不是总 token 或金额。报告 `partialUsage:false` 也只表示这两项有记录。
- 原始 SDK cacheRead 分别为 113,152 / 162,432，totalTokens 为 133,055 / 215,512；仅作原始数值观察。single 出现 cacheRead=0 的未核实覆盖，child collector 会保留 partial。不能以 cacheWrite/cost 的占位 0 断言服务商零缓存写入或零费用，也不能把本报告当 D2 预算账本。
