# DAWN 命令行 Agent

用户已选择：Normal 是原 Shell；输入 `dawn` 进入 Agent，退出后回原 Shell。该决定取代此前“桌面内复制对话”及“CLI 内部双模式”的方向。独立分支开发，不合并、不推送、不替换安装版。

## 交互

`dawn` 是真正的前台命令行程序，在任意终端中使用。继承启动时的 cwd 与环境，直接自由对话并按需调用 DAWN 的工具。只显示一份命令行记录和一个 `DAWN ›` 输入提示，不创建第二个桌面聊天输入。`/exit` 或空闲 Ctrl-C 退出回原 Shell，执行时 Ctrl-C 停止当前回合；退出/报错均关闭会话与输入处理，恢复终端状态。权限原样列出数字选项，问答逐题呈现；未获批准的动作不执行。非交互管道输入按行串行处理、EOF 等待完毕，遇权限询问自动拒绝并明确失败状态。

Normal 期间不截获普通命令。Agent 子进程继承原 Shell 环境，但其内执行 cd / export 不会回写父 Shell；外层 Shell 保持原状态。退出到 Normal 后再进 Agent 是一次新会话，首版不宣称自动续接进程内变量。

## 接入

命令行复用 `createWorkbench` 的核心、工具、权限门、Notebook 和 MCP 装配；本身不启动 Electron。CLI 呈现基础文本、工具过程、错误、权限与问题，不维护另一套运行时。内置 provider 读取标准 API key 环境变量，自定义 provider 可用 `DAWN_API_KEY`；不会解密或复制桌面密钥。每次 CLI 运行在专属数据子目录建库，避免多 CLI / 桌面启动对账误判活动会话。可通过 `DAWN_CLI_HOME`、`DAWN_CONFIG` 指定 CLI 数据及配置。

第一版提供仓库内 `bin/dawn` 与 package bin 映射。预览仅把仓库 bin 加入该预览终端子进程的 PATH，不修改用户 Shell 配置或系统 PATH。原有 `agents/run/sessions/demo` 命令兼容；无参数直接进入 Agent，`--help` 查看用法。

## 桌面终端

打开终端后主区使用整页原生 xterm；原聊天界面隐藏并保持草稿。只有一个真实终端输入，在其中输入 `dawn` 即进入 CLI。顶部轻量工具栏保留终端标签、启动目录、返回对话。无需另造聊天卡或用按钮模拟 Shell / Agent 状态。没有本地主对话时，原终端入口继续可用。关闭终端仍结束相应进程；返回普通对话不结束终端。

## 验证

真实 PTY：原 Shell 设置变量并 cd，调用仓库 dawn，完成普通对话、工具写文件、权限拒绝/批准、结构化问答、中断及退出，再核对原 Shell PID/cwd/变量和 stty 状态。无凭证、模型错误、EOF、SIGTERM、两个独立 CLI 均有清楚结果；独立数据库不误改桌面。隔离 Electron 同一路径展示实际 CLI，明暗主题及 900×700 / 1280×840 检查输入、滚动、工具栏和横向溢出。固定模型验真实工具调用与进程交接，不声称验过任意真实模型推理质量。
