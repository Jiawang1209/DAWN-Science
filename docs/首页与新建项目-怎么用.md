# 首页与新建项目

首次进入的顺序是 **四步引导 → 首页 → 工作台**。本地解释器和工具仍然可选；有可用模型即可新建对话。工作台上的“首页”可以回到项目入口，底部“导航栏”重新打开四步引导。

## 三个入口

- **新建对话**：直接开始，不要求项目或本地环境。
- **打开项目**：选择已有文件夹，沿用已有文件和历史。
- **新建项目**：填写项目名称，选择或粘贴父目录，在父目录下创建同名文件夹。已有同名目标会提示使用“打开项目”，不会覆盖文件。

创建成功即进入该项目工作台。第一次发送消息时才创建会话；仅打开工作台不会产生空会话。

## 可选内容

**项目说明**只用于首页辨认项目，不自动加入 AI 提示词。

展开“科研目录与 AI 约定”后，可以开启标准科研目录，或填写 Agent 上下文。这些默认都不要求配置。

标准目录包括 `data/raw/`、`data/processed/`、`analysis/scripts/`、`analysis/notebooks/`、`figures/`、`results/tables/`、`results/models/`、`results/reports/` 和 `literature/`。启用时会同时保存对应产物位置约定。

Agent 上下文保存在新项目的 `AGENTS.md`。DAWN 的 Native 新会话会读取它；外部 Agent 依照各自已有的项目指令支持读取。后续可以通过文件预览或编辑器修改此文件，再新建会话使用新约定。

## 管理项目

卡片右下角的星标收藏项目，收藏项优先显示。旁边的设置可修改显示名称和项目说明；这些修改不会重命名磁盘上的文件夹。收藏和设置保存在本机，重启后保留。

最近会话排除已归档会话与终端会话；点击可以继续原对话，工作台返回首页保留未发送草稿。关闭页签依然只关闭页签，明确执行归档才会收入“已归档”。
