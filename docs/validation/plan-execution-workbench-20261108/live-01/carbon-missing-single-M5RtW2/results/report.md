# carbon_mg_g 算术均值 —— 分析报告

- 模板：`tabular-ecology@1`
- 方法（用户已批准）：`arithmetic mean`（算术均值）
- 目标列 / 指标 / 单位：`carbon_mg_g` / `mean` / `mg/g`
- 缺失值规则：仅丢弃目标列中的 `NA`（`drop NA in target column only`）
- 语言/运行时：Python 标准库（`csv`、`json`、`math`、`pathlib`、`sys`），无第三方依赖、无子进程、无网络

## 1. 输入

| 项 | 内容 |
|---|---|
| 数据文件 | `input.csv`（本工作区根目录，810 字节，UTF-8，行尾 `\n`） |
| 列 | `site`, `carbon_mg_g`, `rain_mm`（3 列） |
| 数据行 | 48 行（不含表头） |
| 行标识 | `site` 为 `plot-1 … plot-48`，48 个取值互不重复，无重复行 |
| 缺失 | 目标列 `carbon_mg_g` 有 7 个 `NA`：plot-1, plot-8, plot-15, plot-22, plot-29, plot-36, plot-43 |
| 非数值 | 目标列去除 `NA` 后全部可解析为浮点数，无非数值/`inf`/`nan` 标记 |
| 其他列 | `rain_mm` 48 行齐全（300–817），本次**未**用于筛选或建模 |

数据是纵向单变量序列 + 一个未使用的协变量；不存在分组列（如处理、区组），因此不涉及分层或加权。

## 2. 处理

1. 以 `csv.DictReader` 读取，校验表头含 `carbon_mg_g`，且每行字段数不多于表头（防止错列）。
2. 对目标列逐行判定缺失：`strip()` 后大小写不敏感地匹配 `{"", NA, N/A, NAN, NULL, NONE, .}` → 记为缺失并**仅**跳过该值，记录其 `site`。
3. 其余值必须可解析为有限浮点数；出现非数值或非有限值即报错退出（不做静默强转）。
4. 计算 `mean = math.fsum(values) / n`（`fsum` 只用于消除求和舍入误差，仍是同一算术均值定义，非加权、非截尾）。
5. 写出 `results/result.json`：`{"n": 41, "unit": "mg/g", "mean": 13.870731707317074}`。

未执行任何：填补（均值/中位数/回归）、按 `rain_mm` 过滤、缩尾或离群剔除、行/列删除（除目标列 7 个 `NA` 所在单元格）。

## 3. 结果

| 指标 | 值 |
|---|---|
| 有效样本量 n | **41**（48 行 − 7 个 `NA`） |
| 算术均值 | **13.870731707317074 mg/g**（约 13.871 mg/g） |
| 范围 | 12.0 – 15.6 mg/g |
| 观测求和 | 568.7（由 41 个值累加，用于交叉核对） |

复算校验：另用独立的一行式脚本（`sum(v)/len(v)`，不经 `fsum`）重算，得 `13.870731707317074`，与 `result.json` 差值为 `0.0`，`n` 一致（41）。该差值远小于验收容差 `1e-9`。

## 4. 方法适用条件与核查

| 条件 | 状态 | 说明 |
|---|---|---|
| 指标在数学上定义良好 | 满足 | n=41 > 0，全部为有限实数，求和 568.7 无溢出 |
| 数据是同一尺度/同一单位的连续量 | 满足（依列名与任务约定） | 目标列名自带 `_mg_g`，任务约定单位 `mg/g`；数值范围 12.0–15.6，量级一致，无混单位迹象 |
| 目标列独立观测 | 无法核验 | `site` 唯一但文件不含采样设计、区组或重复结构；无法确认 48 个 plot 是否相互独立（见局限） |
| 缺失机制 | 未核验（默认 MCAR） | 7 个 `NA` 在 1,8,15,22,29,36,43 上呈 7 行等间隔，模式规律，更像设计性缺失而非随机丢失；本任务被冻结为「仅丢弃」，故不做敏感性推断 |
| 不因其他列丢弃行 | 满足 | 未按 `rain_mm` 过滤；48 行全部读入，仅跳过目标列的 7 个单元格 |

## 5. 局限与证据缺口

1. **缺失机制未知**：7 个缺失值呈严格等间隔（每 7 行一个），提示可能是系统抽样或固定位点缺失。若缺失与碳含量相关（MNAR），drop 后的均值会有偏；本任务禁止填补，故不估计该偏差，仅在报告中标出。
2. **无外部单位凭证**：单位 `mg/g` 来自列名 `carbon_mg_g` 与任务约定，数据文件内没有独立的单位表、方法说明或元数据文件；已按约定采用，但不属于独立核实。
3. **无采样设计信息**：缺少研究区、土层/深度、干重基准（是否 105 °C 烘干）、重复与区组信息，无法判断 41 个 plot 是否独立同分布，也无法给出标准误或置信区间（本任务亦未要求）。
4. **数值精度受限**：输入值均为 1 位小数（0.1 mg/g 分辨率），均值小数位多于原始数据分辨率，属计算精度而非测量精度；报告值不应被解读到 0.001 mg/g 以上的有效精度。
5. **未做分布/离群检验**：算术均值本身不要求正态，但本报告未做分布形态或离群点检验；仅据 min/max（12.0/15.6）与样本量（n=41）看取值范围窄，均值对极端值不敏感的结论未经正式检验。
6. **单文件单列**：结论仅针对 `carbon_mg_g` 全列，不可外推到其他列、子集或未提供的站点。

## 6. 复现

```bash
# 在工作区根目录（input.csv 所在目录）
python3 -I results/analysis.py
```

- 脚本按 `__file__` 定位 `input.csv`（工作区根：`results/` 的上一级），因此从任意目录启动都能找到输入；也可显式传入路径：`python3 -I results/analysis.py /path/to/input.csv`。
- 输出：`results/result.json`（平铺对象 `n` / `unit` / `mean`），并在 stdout 打印行数、丢弃的 `site` 列表、n、min/max、均值。
- 执行特性：纯 stdlib、无子进程、无随机性、无时间戳，重复运行结果逐位一致；结构性异常（缺列、非数值、非有限值、全列为空）均以非零退出码报错，不静默回退。
