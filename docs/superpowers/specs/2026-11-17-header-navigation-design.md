# 顶栏导航与功能提示

用户已确认居中效果并授权开分支实现。顺序为：返回首页、DAWN Logo、侧栏折叠、快捷键；返回按钮只显示现有填充式箭头，32×32px，与右侧两颗按钮共用 ghost 样式。箭头在按钮内两向居中，按钮与 Logo 保持约 1px 的视觉间距。Logo 内图标与文字间距使用8px令牌，保证18px完整名称不裁切；Logo 继续新建任务。

展开导航与侧栏共用宽度状态，分界线在同一横坐标；右侧两颗按钮靠近分界线，内距 12px。默认及最小展开宽度改为 300px，最大仍 420px；合法更宽偏好保留，旧窄值夹到新下限。折叠后保留完整品牌和所有导航按钮及其位置，仅隐藏分界线，正文使用收回的侧栏空间，窄窗口不出现虚假的侧栏分界线。

顶栏集中处理标注了 data-tooltip 的按钮，提示通过 React portal 挂到 body，不增加布局包装。鼠标停留 250ms 后显示，键盘聚焦立即显示；移开、失焦、点击、Escape、滚动、缩放、切换首页或引导时隐藏并清除计时器。提示在视口内定位，提供 role=tooltip 与 aria-describedby，不覆盖原有描述。

提示覆盖返回首页、Logo 新建任务、侧栏展开/收起、快捷键、会话页签及关闭、新建会话、会话工具按钮和右侧面板。保留原按钮可及名称及回调（首页按钮仍以“首页”供读屏识别，提示为“返回首页”）；页签提示显示完整标题，关闭说明保留会话。中英文与现有主题令牌同步。没有原生 title 的按钮不新增原生 title。

验证包括组件的生命周期及交互、原首页/草稿路径、实际 Electron 几何测量、拖动/折叠/重开、明暗与中英文窄窗口。全程使用隔离配置、数据库、假凭证和假模型；不读取用户 API Key，不合并或推送。
