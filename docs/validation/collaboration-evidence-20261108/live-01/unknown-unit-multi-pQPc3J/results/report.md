# carbon 算术均值 —— 结果报告（单位缺失，交付阻塞）

**状态：方法上可计算、交付上不可完成。** 已按批准方法（arithmetic mean）算出 `carbon` 的均值并留证，但任何已声明输入都没有提供 `carbon` 的单位，因此无法产出合规的「带单位均值」。本报告与 `results/result.json` 如实登记该缺口（`unit: "not_provided"`），**不推断单位、不借用邻列、不换算、不插补**。

## 1. 输入

| 项目 | 内容 |
|---|---|
| 数据文件 | `input.csv`（只读，未修改；SHA-256 与批准方案登记值一致：`d52f087d6ee5fbdbb8d799d6bd562366654793803e6e4bd590e0ad6de90190b6`） |
| 列 | `site`, `carbon`, `rain_mm` |
| 数据行 | 48（不含表头） |
| 目标变量 | `carbon`（数值列，含字面量 `NA` 缺失标记） |
| 单位信息 | **无**：文件头无单位字段，也没有任何元数据/说明文件被声明为输入 |

结构核查：表头与预期三列完全一致；`site` 仅作行标识，不参与计算；`rain_mm` 是独立的降雨量列，不作单位线索、不参与计算、未取其任何数值。

## 2. 处理

- 缺失值规则（批准）：**仅对目标列 `carbon` 做 drop NA**。字面量 `NA` 与空字段计入缺失；未对 `site`、`rain_mm` 做任何删改或据此筛选。
- 计算：对 `carbon` 的 41 个非缺失值取算术平均，等权、无截尾、无插补、无变换、无单位换算（单位未知，换算本身不可定义）。
- 有效样本：48 行 − 7 条 `carbon` 缺失 = **n = 41**；剔除数 7。
- 脚本一次性读入 `input.csv`，显式声明缺失标记集合，输出 n、剔除数、均值与单位状态；脚本内不含任何计量单位字符串。

| n（`carbon` 非缺失值个数） | 41 |

| **arithmetic mean of `carbon`** | **13.8707317073** |

以上数值单位为「未提供」，因此**只有数值本身是确定的，其物理含义不确定**。`results/result.json` 为平铺对象 `{"n": 41, "unit": "not_provided", "mean_carbon": 13.8707317073}`，与本文数字一致。

## 4. Blockers（正式登记）

- **BLOCK-1 — 数据文件无单位字段。** `input.csv` 的表头只有 `site,carbon,rain_mm`，不存在承载 `carbon` 单位的列或字段。
- **BLOCK-2 — 已声明输入中无单位元数据。** 冻结契约的 `inputs` 仅 `input.csv`；没有数据字典、README、方法说明或版本记录可据以确定单位。
- **BLOCK-3 — 后果：无法交付「带单位均值」。** 单位是本次交付的必要条件；缺失时不得从数值量级反推、不得借用 `rain_mm` 的单位、不得套用任何常见默认单位、不得写近似单位。故本次**不输出带单位的结论**，`unit` 只写客观状态 `not_provided`。

解除条件：由数据提供方以可核查的形式（数据字典、方法说明或原始测量记录）给出 `carbon` 的单位；在此之前，任何带单位的表述都属推断。

## 5. 局限

- 无可解释的物理量纲：13.8707317073 只能读到「该列数值的平均水平」，不能解释为任何具体物质的量或浓度。
- 不可跨数据集、跨文献比较，也不可与 `rain_mm` 做量纲层面的联合解释。
- 未做区间估计、显著性检验或建模，不声称不确定性范围；仅报告点估计与描述量。
- 缺失机制未知（`NA` 是否随机缺失无法从本文件判定），drop NA 假设下均值仅代表观测到的 41 条记录；不做插补是批准规则的要求，不代表该均值对 48 条总体无偏。
- 未产出图形：单位未定时，以 `carbon` 为纵轴的图会形成无单位刻度，读者易默认某种单位，反而制造误导。
