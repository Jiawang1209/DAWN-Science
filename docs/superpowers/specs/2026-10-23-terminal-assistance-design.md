# 会话终端协助第一版

2026-10-23。用户已确认本设计并授权独立分支实现、实际 Electron 预览；不合并、不推送、不替换安装版。基线 main `38959c57`。

## 使用目标

用户在 DAWN 底部终端准备环境、进入目录或打开 Python/R，明确把该终端交给当前内置模型对话。模型读取实时终端画面，在原进程继续输入；用户随时接回。接回、停止模型等待、中断前台程序和关闭终端是四种不同动作。

## 范围

- 首版仅主 native/API 对话与 DAWN 已有本地 PTY；保留原 shell、cwd、环境变量及 R/Python 变量。
- 用户显式选择当前程序类型 shell / Python / R。没有可靠类型信息时不猜、不自动启动或退出解释器。
- API 提供终端列表、实时画面、执行、受限按键、等待和中断；控制权仅由用户界面授予，模型不能自行认领。
- 不接管外部终端，不增加远端持久 shell、复杂全屏助手适配、自动审批、公共网络控制服务或跨应用重启恢复。
- 现有 bash、run_code、Notebook、@R/@Python 和 ACP 路径保持。新工具不出现在 Bot、普通子任务和远端会话中。

## 架构

`PtyRuntime` 继续拥有真实进程；新增 `TerminalControl` 管活终端、归属、程序类型、授权代次、执行状态；`TerminalScreen` 使用 headless xterm 解析与前端相同的字节和尺寸。后端画面不依赖面板可见性。工具和 UI 共用同一个服务。

终端与对话绑定由服务端验证：终端是活 PTY，拥有者是活的本地 native 主对话，两者项目和工作区一致。原界面映射只负责显示，不再作为模型授权依据。创建时可带 ownerSessionId；旧终端只能通过用户显式授予绑定。每个终端最多一个拥有者/控制者。

服务复用会话写权租约，补充具体 ownerSessionId 与 grant generation。授予是用户动作：放下 user 租约、取得 engine 租约。模型写入前检查归属、实例、代次、有效租约和中止信号；权限询问返回后再次检查。后台每60秒仅续期仍有效的 engine 租约；过期或 user 已持有时绝不自动重新认领，收起面板不影响续期。人工输入立即撤销授权并取得 user 租约，迟到的模型输入不得发送。

## 执行与证据

- 当前画面返回终端 ID、实例 ID、尺寸、程序类型、修订和截断事实；读取需刷新解析队列。终端输出是不可信任务材料，不构成权限指令。
- shell / Python / R 各有独立输入封装，保持原进程环境，不写用户 shell 配置或临时脚本文件。完成标记使用随机调用身份，通过私有 OSC 解析，不能把回显的包装语句误判完成。
- 一次只执行一个任务；执行结果区分 running / completed / interrupted / unknown。只有匹配完成标记才能报告退出/执行状态。超时只结束等待，不重发、不杀程序。
- 模型使用代码前读取画面；程序类型由用户选择，不能靠工具参数切换。终端命令与 REPL 输入走现有权限档；未知工具不能默认绕过权限、方案模式或显式不执行约束。
- 受限按键显式映射 Enter / Ctrl-C / Escape，禁止通过任意控制序列绕过执行检查。终端输出里出现授权菜单不自动批准。
- 控制权收回不杀进程；明确中断发送 Ctrl-C 并如实标记结果待核对；关闭终端沿用原停止/删除流程。关闭或进程退出撤销授权，旧终端身份不得复用。
- 工具调用保留在原模型转录/Run 里；不把终端文件变化冒充 Notebook 或确定的科研产物。模型停止时撤销未发送输入，不自动中断用户原任务。

## 界面与协议

保留底部终端布局，在原标签栏下增加紧凑协助行：程序选择、人工/AI 控制状态、交给当前对话 / 接回控制；AI 控制时可显式中断程序。手动键盘输入可直接接回。面板收起不终止任务。仅本地 native 主对话可授予，其余显示原因。

协议 8.25 增加只读控制状态、用户授予/收回及尺寸同步；增加用户显式中断操作；全部在共享 mock 同次补齐。新终端与旧终端均可使用。切换对话/终端后的迟到查询不得覆盖新状态。标记、工具描述和界面中不带参考项目标识。

## 验收

1. 人工设置环境变量、cwd、进程 PID 后交给模型，真实 shell 内结果保持；收回后仍同一进程。
2. 人工在 Python/R 定义变量后模型继续计算；不启动 Jupyter，Notebook 状态不变。
3. 并行/跨会话/旧实例写入拒绝；询问期间接回、取消和终端关闭均阻止迟到输入。
4. 长任务等待超时返回 running；没有重复副作用。显式中断、收回和关闭语义分别核对。
5. ANSI 清屏/覆盖、Unicode、多行、分段标记、非零状态、窄窗口与尺寸同步有回归。
6. 类型检查、相关及全量单测、构建、真实 Electron 的手动准备→模型工具→接回链路。工程模型可为共享固定回复，真实进程/文件结果必须真实；不宣称真实模型通用判断质量。
