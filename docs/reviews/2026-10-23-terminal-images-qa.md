# 终端图片 QA

用户可见：DAWN 中真实剪贴板截图和拖图只暂存，下一句话发送一次；待发图可放大和移除；上传处理中 Enter 不丢图；原终端为唯一文本输入。Normal 不附图，隐藏的原会话不接收图片。每终端/新 CLI 隔离。

输入图与 Agent 的本地 Markdown 图片/工具文件事实/内核 PNG/JPEG 输出显示在终端原位置，缩略图点开大图、Esc/关闭按钮退出，主题和尺寸适配。重开终端能恢复仍在缓存的图片；超缓存明确显示原因。

GUI 返回同一 native ID，附图可见，真实模型不重复上传原图仍能针对细节续问；原主人草稿保持。能力不足、损坏图、超过大小/数量、路径越界、发送失败留图是异常核验重点。

自动化固定模型只证明传输/事件/界面链路，真实识图另验已有配置模型和凭证。实际1280×840亮色、1000×720暗色，图片中随机文字/颜色答案可核对，留可交互预览。源凭证校验一致，不合并/推送/替换安装版。
