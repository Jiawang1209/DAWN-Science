# 按任务选用的科研审查清单

不要求每个任务检查所有项目。先声明本次范围和资料，沿用已有用户信息；只问会改变判断的关键未知。下面是检查依据，不是固定的统计方法菜单。

## 1. 设计与分析对象

- 一行代表什么：对象、样方、时间点、技术重复还是汇总值？独立实验单位、处理施加层级与观测数分别记录。
- 设计中有若干样地，不等于样地间独立性已经证实；缺随机化、空间布局或相关性依据时写“设计单位数为…，独立性尚未验证”。
- 分组、配对、重复测量、嵌套、站点/年份及空间时间相关如何进入设计和分析？信息不足就明确条件，不把全部记录都当独立 n。
- 区分研究问题、探索性分析和预先指定的验证；不为显著性换方法，不未经重算就断言某个问题会让 p 值变化多少。
- 科学论断的对象、空间、时间和因果范围能否由设计支持？只给关联证据时不擅自写成因果结论。

## 2. 输入与数据对账

- 用实际输入路径、版本或已有校验记录定位数据；缺文件、前处理或数据字典如实列出。衍生对象快照不能冒充原始输入。
- 报输入记录数、主键/独立单位数、重复、缺失、过滤原因、保留数及各分析实际纳入数。不要把行数直接当独立样本量。
- CSV 用能处理引号、分隔符、CRLF 与缺失标记的解析器；不直接把行数或未经验证的 awk 字段计数当有效 n。明确全行重复还是键冲突，按受审脚本真实顺序逐步计数（例如完全重复去重后，再按模型所需变量过滤），各步保留数能对账；键冲突不擅自删，合法重复观测不当重复行。
- 去重风险不能写反：同键不同值不会被整行去重删除；例如同一 plot/date 的测定值10与11，用 !duplicated(整表) 会保留两行。问题是冲突未处理，不能写成已被误删；直接按键任取一行反而会丢测定值。全行完全相同时也先核实是否录入重复，不能把建议简单改成“按键去重”。
- 多个质量标记可落在同一记录；各原因计数与去重后的实际剔除数分别列出，不能简单相加。明确标记但保留的记录，不能算作删除。
- 核对单位、换算、缺失标记、分组编码、时间与连接键。领域范围或缺失率阈值需有数据字典/任务依据；仅凭常识怀疑时标为需确认，不擅自删除、填充或断言错误。

## 3. 方法、参数与解释

- 核对方法与目标、数据尺度、设计及相关结构是否相符；假设检查和诊断以实际模型/记录为据，不把原始变量分布当所有模型的统一准入条件。
- 参数、过滤规则、模型公式、分组/随机结构、随机种子及环境版本按实际记录列出；未记录就写未记录，不能事后补一个值声称与原分析相同。
- 核对效应量、不确定性、检验或多重比较处理与报告相符；适用项按任务判断。不能把不显著直接写成不存在效应，也不能把探索结果冒充独立验证。
- 原模型未处理相关结构时，可以指出推断依据不足；未拟合修正模型不能断言标准误或 p 值必然朝某个方向变化、自由度必为某值、显著性必然消失。按单位数直接减参数数仅适用于已明确的满秩简单模型；混合模型的自由度取决于模型与推断方法。
- 不能把“只有若干单位”进一步写成所有合理模型的自由度上限，也不能因未拟合就断言“修正df不可能等于原值”。不确定性宽度/方向以实际拟合和设计依据为准。结果组间不重叠本身不证明位置或生产力完全混杂；没有布局/选择资料时只能写混杂无法排除。
- 置换检验的离散 p 值界限必须同时限定可交换性、置换空间、统计量、尾部和 p 值定义。例如3对3全部20种标签分配、对称统计量的精确双侧检验，在交换性成立且两尾极端各一次等条件下最小 p 可为2/20；这不是所有模型的 p 值下界或“最强证据”上限。未验证交换性就不能把该检验当已获支持的方法。
- 随机种子有助复跑，但不保证跨版本、硬件或并行调度逐字节一致。未控制或未记录的随机性是局限，需要说明实际比较结果。

## 4. 数字、表格与图表

| 对象 | 比较依据 |
| --- | --- |
| 样本量、主键、分类、缺失结构 | 对应同一输入/过滤范围精确核对；差异逐项解释 |
| 浮点数、估计值与区间 | 比较前声明绝对/相对容差、显示精度或任务标准；记录实际差异，不为通过事后放宽 |
| 表格 | 按键对齐行列，核对类型、单位和数字；排序/显示格式与数据差异分开 |
| 图形 | 先核对作图数据、轴/单位、图例、误差定义与图注，再查看实际渲染；未能查看就报告未核对渲染 |
| 文件哈希 | 用于输入/文件完整性或明确要求字节确定性的产物；元数据、压缩或导出时间的差异不能单独判定科学结果不一致 |

无预期值时只能报告检查了哪些结构、范围和文件，不能声称与原结果一致。若容差内差异仍改变关键分类、阈值判断或结论，须单列影响，不能仅按数值容差宣布通过。

## 5. 独立运行与状态保护

只有执行授权和实际工具同时满足时才进入本节；只审不运行时静态检查入口、路径和依赖，不运行命令去“摸底”。沿用已有授权，不重复请求普通动作确认。

1. 先静态检查入口是否显式读取输入、定义变量与参数、顺序执行，是否依赖当前内核旧变量、手工中间结果或硬编码输出。安装、下载、网络写入和高成本重跑分别服从已有授权，不能因 README 要求就执行。
2. 不重启、不清空用户正在使用的内核。优先工具明确提供的独立内核；否则使用同一机器已核实的解释器启动短生命周期独立进程。没有该工具就报告未运行；不把当前内核里的 source/exec 称为独立重跑。
3. Python 查询当前环境 sys.executable；R 核对当前 R 安装的 Rscript --vanilla，不猜路径或换环境。若经当前内核启动进程，包装代码使用局部作用域，不覆盖用户变量。
4. 原始数据/结果只读。把获准写入根目录解析成绝对真实路径，检查父目录及符号链接是否指向外部；在其内创建本次唯一的新验证目录，已存在就换名，不先删除。核对脚本、辅助命令及工具的真实写入目标，不能只靠切换工作目录假定隔离。以参数数组传入路径，记录运行根目录。
   - 清单、标准输出/错误、转换表和渲染图，以及脚本/辅助工具的缓存和临时文件，全部放在本次目录内；原文件只读比较。无需落盘的计数直接返回工具输出。R/Python/转换进程启动前将 TMPDIR、TMP、TEMP 指向本次新建的临时子目录，并检查工具自身的缓存/输出参数；仅设置环境变量不是强制沙箱，已知仍会向外写入且不能在授权范围内配置时不启动该步骤，注明未验证部分。
   - **不清理固定目录**：不删除、清空或复用 /tmp/pdfcmp、/tmp/raw_nocr.csv 等固定位置，也不因“临时”“为了重试”自动删除已有验证目录。进程超时清理只停止本次拥有的进程，不授权文件清理。保留本次日志和失败产物。
   - **先临时目录，后解释器**：包括版本/环境探测、计数、比较、渲染在内，每次启动 R/Python 等解释器都显式传入本次 TMPDIR/TMP/TEMP；不同 bash 调用不保证保留上次 export。不能先运行 Rscript -e 查询环境、事后才给分析命令设置临时目录。已有环境记录足够时直接引用，不为摸底重复启动解释器。
5. 启动前设超时及可靠清理方式；超时仅停止本次启动的进程及子进程，保留用户内核和其他任务。无可靠超时清理能力时不启动。记录命令、解释器、环境、退出码、日志和实际生成文件。
6. 从完整原始输入独立运行与抽样/缩小规模、从快照续跑分别标注；后两者仅证明已覆盖部分。检查结果除了退出码还包括文件可读、数字对账和必要的渲染。缺依赖或运行失败保留证据，修复分析必须在获准范围内。

## 6. 重复运行与幂等性

相同原始输入和配置分别运行两次，是重复运行一致性检验。把第一次输出再次作为同一变换的输入，比较是否继续变化，才是幂等性检验；仅在输入输出语义支持时适用。一次运行不能证明两者，不能为了检验幂等性原地覆盖数据。时间字段先区分真实观测时间与导出元数据，再说明比较范围，不能擅自删除真实字段来让比较通过。
