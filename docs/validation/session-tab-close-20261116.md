# 关闭页签与归档分离 — 2026-11-16

## 当前行为

用户要求只有明确归档的会话才进入归档。原顶部页签的关闭回调调用“归档几段”，导致按 × 也会写入 archived_at。此次将关闭改为窗口级页签隐藏状态，不写会话归档状态。

- 关闭当前页签：选择另一个可见页签；没有其他可见页签时清空当前选择。
- 会话与草稿仍保留在侧栏；重新选择可恢复页签。
- 返回首页后再进入同一会话也可恢复页签。
- 页签隐藏状态不写入会话数据库；窗口重新加载后可重新显示未归档会话。
- 明确选择“收进归档”仍沿用原归档流程与计数。
- 既有归档记录未批量取消；旧记录没有区分 × 与归档菜单的来源信息。
