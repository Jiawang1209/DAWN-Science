# 对话协作台与流程工作台

用户已选择：日常保持对话协作台，流程工作台作为展开视图。实施中用户提供 Harness 编队截图，展开视图需占用完整工作区、左侧 Agent 网络、右侧多列成员卡片，支持节点联动、名称搜索和状态筛选。

## 信息与权威

- 默认对话上方紧凑摘要，仅有子任务记录时显示；点击打开所属会话协作，不自动切面或抢焦点。
- 协作面板上方任务行，下方过程、交接、产物、记录四个 ARIA 页签。额度及完整会话记录折叠。
- getRunOverview 是唯一运行投影。client/session 共享只读轮询；最后订阅卸载后停止，异步结果按 owner 校验，失败清掉旧快照。无新增调度、写入、恢复 API。
- 执行 completed 与回执 accepted 独立；停止中和已排空分开；disk/unknown 不宣称实时。预算挡住 idle 任务不能称执行已结算。
- 冻结交接 v1/v2 原样复用。路线不是批准，历史版本不代表当前文件有效。没有文件清单的运行投影只显示版本数量。
- 累计 tokens 使用 observation input/output/cacheRead；缺字段为部分。顶部可核验 token 和未知轮次来自现有预算，不倒推上下文占用或费用。

## 展开视图

原生 modal dialog 提供背景 inert、焦点约束和 Esc 返回。触发按钮重挂后恢复焦点；返回保留同一会话选择及页签。状态仅在窗口内按会话保存，最多64份。

左侧连线表示同一宿主的直接编排记录，不代表递归血缘或任务依赖。运行中线条为虚线，所有状态仍有文字。右侧按已记录 run 展示卡片，名称搜索与全部/活跃/已结束筛选。

TeamSnapshot 必须 captainSessionId 匹配当前 owner；任务依赖用原 team-dag 布局。task 与 run 使用独立选择 key，不按角色名推断绑定。未执行 pending 任务也可查看，attemptId 与 receipt 绑定仍由后端持有。

默认协作保留原团队管理与原始记录的折叠入口；子任务完整转录继续跳到原 SubagentPane，原权限与续聊/取消判断不变。流程视图不能凭 UI 给予冻结任务续聊权。

## 验证与交付边界

UI单测覆盖共享轮询、迟到会话结果、验收区分、disk、预算idle、缓存token、真实依赖。Electron覆盖8个真实子执行、锁等待、搜索联动、Esc/焦点、窄屏、交接、续聊、恢复与原契约流水线。模型响应使用既有本地mock，不新增真实API请求。

工作区沿用上一轮未提交分支；main不改，不提交/合并/推送/发布、不替换正式App。历史偶发关闭超时继续开放跟踪，单次通过不能证明历史根因已解决。

## 复审后的显示约束

任务选择key含Team ID和task ID；只读的旧结果与正在进行的代次分开解释，非结算态不显示旧receipt为本轮通过。原预算仍是取消/在途用量的权威入口，原始结果与历史账本不删除。耗时用累计结算口径。原生modal与既有全局键位协调：退出后打开命令面板/原面板；IME组合键不向背景传播，也不阻止输入法默认处理。
