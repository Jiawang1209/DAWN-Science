# 终端 Agent 图片输入与预览

用户已确认：终端内缩略图＋点击放大；支持粘贴与拖入图片，返回会话后继续问原图。沿用 codex/terminal-assistance，不合并、推送或替换安装版。

## 交互

DAWN 模式下粘贴或拖入 PNG/JPEG/WebP/GIF，在终端下方出现紧凑待发缩略条，可点开和移除；原 DAWN › 是唯一文字输入。按回车时图片与下一句话发给当前认证 Agent；粘贴不自动发，失败保留。Normal 不接管图片输入。每终端最多四张，附件按会话隔离，切模式/换 CLI 不泄漏到新会话。

输入图和工具/回答返回的本地图片在终端输出相应位置显示缩略图，点击同一图片预览浮层放大。原图和消息走已有 native 图片通路，返回图形界面后同 ID 续问。图片生成仍由既有工具承担。

## 实现边界

复用既有 native writeToSession(images)、视觉服务和转录。桌面主进程保存每个已认证 CLI 的待发图片，通过独立协议操作收取附件，不把大图塞进 4MiB 的 CLI socket。发成功才消耗待发批次，失败保留；上传中的回车不得发出无图请求。

输出来源：随消息发送成功的图片、内核结构化图片、工具文件事实中的本地图片、回答 Markdown 图片引用。读取输出文件沿用工作区 realpath 守卫，不把普通文本或任意终端转义当作图片。主进程生成不透明图片 ID，CLI 只输出 ID 标记及占位行；xterm decoration 在标记位置画原生按钮/图片，点击放大。模型文字继续过滤转义。无需更换终端或增加第二聊天框，也无需安装通用图片协议插件。

每终端图片缓存有数量/字节上限，过期标记明确提示；大图预览压缩，完整内容另取。隐藏/重开终端可用相同 ID 恢复。CLI 退出清待发；PTY 退出释放图片缓存。当前模型不能收图且视觉服务不可用时，上传入口给出明确原因，不能谎称看过。实际验收使用已经配置且有凭证的看图模型，不新增用户凭证。

## 验收

真实 Electron 验粘贴、拖放、待发删除、回车只发一次、点击放大、重新打开、Normal、多个终端、发送失败保留、返回后同会话续问及原主人草稿独立。真实 API 使用随机图形/代号，终端识别且 GUI 不重复上传也能回忆。亮/暗、宽/窄检查。只保留独立预览，不改源配置与凭证。
