# 输入区工具排列

用户已确定并授权实现：左侧 `+ → 终端 → 权限设置`；右侧 `上下文 → 模型 → 推理 → 发送`。

终端使用现有面板开关，移出添加菜单，保留按下态和键盘操作。主对话、侧边对话和未创建会话的首页使用一致入口；首页没有实际会话上下文时不伪造用量。上下文复用原读数、悬停/点击详情和压缩能力，移至模型前；累计会话统计仍在卡外。上下文按钮平时背景透明，悬停和按下使用与其他按钮一致的交互背景；终端图标与加号一样使用设置中的主题强调色。极窄栏允许左右两组分行，右侧组保持顺序和靠右，弹层不得越出窗口。

实施与验证：
1. 核对现有布局并跑相关测试基线。
2. 更新已有测试，调整终端入口、上下文位置及窄栏样式。
3. 运行相关 UI 测试、类型检查、构建和真实 Electron 交互/布局验收；检查终端开关、权限、上下文详情、草稿及中英窄栏。
4. 保留开发分支，使用本机隔离 profile 启动预览，不合并、不推送。
