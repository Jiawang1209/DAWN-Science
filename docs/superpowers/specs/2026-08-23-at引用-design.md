# `@` 引用工作区文件（at-file）· 设计定案

> 2026-08-23。学自 `omdsh-dev/dsh-at-file`（MIT），解读在 `ccb_hive_code_learn/dsh-at-file-解读.md`。分支 `at-file`。
> 背景：占位符从 2026-08-19 起写着「@引用工作区文件」，而此前 `@` 只在空框行首开一个系统文件对话框——作者：*「我知道我原来写过，但是实现的并不好」*。

## 三条定案

1. **引用 = 路径 + 类型，不是内容。** 发送前只验存在，附一条 `<workspace-reference path="…" kind="file|directory" [host] />`；
   文件一个字节不读、目录不列。模型要看自己用工具读——那一步过权限门、进账本。PDF / 大表 / 图片一视同仁。
2. **草稿里是纯文本 `@路径`，不做 chip。** 引用栏是从草稿 parse 出来的视图；× = 抠掉那几个字。正在打的那个不进栏。
3. **识别语法只有一份**：`src/files/mentions.ts` 的 `引用令牌`。菜单、引用栏、发送前扫描都从那里取；
   `design-contract` 扫描盯着别处不许再写这条正则。**全角标点是边界**（它只认空白——它的用户写英文）。

## 形状

| 层 | 东西 | 在哪 |
|---|---|---|
| 语法 | `引用令牌`、`扫引用`（去重、剥尾随标点与尾 `/`）、`引用标记`、`展开引用(text, 查, host)` | `files/mentions.ts`（不 import node；`stat` 注入） |
| 菜单逻辑 | `在打艾特(draft, caret)`（`@` 前要是行首 / 空白——邮箱里那个不算）、`艾特选完`、`抠掉引用`、`排路径`（照它的 rankFiles：文件名匹配 完整>前缀>子串>子序列；带 `/` 按段顺序；空词浏览浅在前、目录在前）、`成候选行`（重名把父目录写进主标题） | `ui/at-file.ts` |
| 菜单 | `AtMenu` + `use艾特候选`：空 / `xx/` 走 `listDirectory`，有词走 `searchFiles`（从最后一个 `/` 前的目录搜起）再本地排；每次击键作废上一次；截断出声。`AtRail` 引用栏 | `ui/at-menu.tsx` |
| 输入卡 | 两张都接（对话 + 空态）：上下挑、回车引用、→ 钻目录不关菜单、Esc 关；光标由 `onSelect` 报 | `ui/views.tsx` |
| 源 | `引用文件 = { 根, loadDir, search }`：就是坞里文件格那两条；远端跟着那台机器、令牌相对会话当前目录 | `ui/App.tsx` |
| 发送 | `writeToSession` 在 `sessions.write` 前 `附上引用`：本地 `stat(resolveInWorkspace)`、远端 `executor.stat(cwd/rel)`；转录存原文 | `workbench/backend.ts` |

## 不借

- 整套 DSH 插件接线（Typert / Remote / slots）；`lib/` 提交构建产物。
- 另建索引：`searchFiles` 已经有预算、截断出声、不跟链接，本地 / 远端同一走法。

## 第二档（同日，作者：「第二档也要做」）

| 东西 | 做法 | 在哪 |
|---|---|---|
| 粘贴的 `@` 不算 | 粘贴时剪贴板文字里每个 `@x` 后塞零宽 word-joiner（`粘贴标记`），屏幕一字不变；`扫引用` / `在打艾特` 见标记即跳过——真实存在的 `@data/a.csv` 粘进来也不算；发送前扫完剥掉，模型与转录都见不到。设置里可关（`atfile.ignorePasted`） | `files/mentions.ts`、`ui/at-menu.tsx` 的 `接管粘贴`、`backend.ts` |
| 文件名过滤 | 规则 `{kind: exact\|regex, pattern, caseSensitive}`，全局一套（`atfile.rules`）+ 按工作区一套（`atfile.rules.<工作区路径>`）；只看文件名。**两头都验**：界面存之前 `规则的毛病`，服务端 `setAtFileSettings` 再验。滤在菜单候选那一步（`编文件规则`），不动 `searchFiles` | 协议 7.23 `getAtFileSettings` / `setAtFileSettings`；设置「文件引用」一格 `ui/at-settings.tsx` |
