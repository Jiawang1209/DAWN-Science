# 光标粘贴与讨论 / 执行边界验证

日期：2026-10-15（Asia/Shanghai）。实施分支：`codex/composer-paste-execution-boundary`，基线 `2dea03fc`（0.0.29）。用户实看分支预览并确认问题已修复，随后授权本地提交并快进合并 main；不推送、不替换安装版。

## 交付行为

- 裸文件名检查无真实文件或读取失败时，按粘贴时的选区插入 / 替换，光标停在新文本之后；欢迎页、主会话与侧边会话共用处理器。
- 保留真正的系统附件、图片及 `@` 保护。等待期间键入的新字不被旧草稿覆盖；浏览器 `beforeinput` 选区用于重复字符中的准确锚点移动；组词结束后才落下粘贴。查询逆序返回时按粘贴顺序处理，卸载 / 换会话取消旧回调。
- native API 会话统一提示普通提问 / 方法讨论直接文字回答，已授权分析连续执行，不逐步确认。明确只讨论 / 不运行 / 只给代码的指令进入外层工具门；shell、内核、写入、代码探查与委派无法绕过，明确只读工具仍可用。
- 约束来自 pi 当前分支实际送达的用户消息，压缩前记录、续接和回退沿用同一来源。不读待发队列、工具输出、助手发言、代码块、引用及附图转述作为执行授权。明确开始 / 恢复 / 内核快捷及具体执行命令解除限制；保留方案审批、权限门及内核语言选择。

## 先失败、后通过

旧版本 13 项粘贴组件检查中 11 项失败；欢迎页、会话页两项真实 Electron 中间粘贴检查均失败，实际值为 `前段后段尾部data.csv`，且选区没有被替换。修复后新增 23 项组件检查全部通过。

运行时先复现 `run_code` 在明确只讨论时仍可调用、压缩条目后约束缺失；另复现关闭溯源 / 未设置权限门时内置工具绕过外层门。修复后 4 项真实 pi 运行时检查通过：拦截 run_code / bash / write、保留 read；解除后连续多次内核调用；压缩条目 / 续接 / 分支回退；无权限 / 溯源装配仍受约束。

独立只读复审指出“运行结果是空的 / 修改后的代码给我看看”误解除和重复字符锚点偏移，均补出失败测试再修复。后续复审发现明确“保存结果”被过度限制，同样补出正反测试并修正。最终复审无遗留 Important / Critical 问题。策略测试共 46 项。
