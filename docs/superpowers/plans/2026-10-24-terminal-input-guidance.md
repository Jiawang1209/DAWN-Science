# 终端 DAWN 输入引导

在现有隔离分支上完成，保持单输入、`> DAWN`、底部统计和上下文按钮。

1. 快捷键与图片说明放到顶部；短视口收起重复头部，权限、提问和生成中状态继续清楚显示。
2. 首次空输入在提示符后显示灰色快捷键，不写入草稿；输入后隐藏。
3. 复用会话页 `suggestNextPrompt`，只针对最后一条已完成 Agent 回复生成下一句建议。400 ms 防抖，每轮最多一次；输入时隐藏、迟到旧轮结果丢弃，失败静默。右方向键采纳、Enter 才发送，Tab 仍展开工具。
4. 桌面传输仅暴露绑定会话的 `$suggest`，不开放跨会话读取或任意操作。历史恢复也可生成建议，原图和原会话继续沿用。
5. 补 TUI、建议生命周期、桌面通道、实际 Electron 回归，检查宽窄窗口、鼠标编辑、图片坐标、关闭和返回；完成后打开真实分支预览。先不合并、不推送、不替换安装版。
