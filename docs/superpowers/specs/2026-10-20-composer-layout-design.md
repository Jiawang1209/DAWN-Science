# 输入区分层预览

用户已批准在独立分支制作可操作预览。工作目录与本机/服务器放在输入卡上沿，文字与附件保持中部。按用户第二轮反馈，优化输入连同基础/标准/专家档位收进「＋」菜单；底部工具带左侧放「＋、权限」，模型、推理强度与发送放在同一行右侧；上下文按钮移到输入卡下方的累计统计旁。

添加菜单收纳文件、图片、数据、优化输入、生成方案与终端。优化组件在菜单关闭后保持挂载，确保进行中的改写、取消、撤回和快捷键仍有效。开启方案显示明确状态。首页、主对话与侧边对话采用同一组织方式；目录长名称省略，完整路径可点开查看；远程显示实际服务器名称与远程路径。

只调整输入区呈现与菜单组织，复用现有选择目录、附件、方案和终端动作，不改变会话归属、文件落盘、模型调用、权限或发送语义。菜单支持上下移动、Home/End、Escape返回触发按钮；点击外部关闭，草稿与附件保留。不可用方案显示原因。优化档位使用独立向右二级菜单，不向下撑开主菜单；右侧空间不足时左移主菜单，为二级菜单留出位置。右方向键进入，左方向键或Escape返回档位入口；关闭一级菜单时二级同步关闭。

验收：真实Electron查看亮暗主题、首页与会话、菜单打开/关闭、优化档位与改写/撤回、方案提交、文件引用、280px窄侧栏和普通发送。配置、数据库、userData和演示文件全部隔离。初始阶段只交付分支预览；用户验看后已授权：功能验收通过即本地合并main，不推送或替换安装应用。

最新交互确认：优化输入是一整行入口，点击或鼠标悬停均展开二级菜单，右箭头只作提示，不再单独作为按钮。选择基础/标准/专家后按该档立即优化并关闭菜单；默认档同步保留给快捷键。撤回上次优化只在二级菜单底部分隔区显示，一级菜单不随撤回层数增加而增高。悬停展开不抢键盘焦点，跨两级菜单留有短暂关闭延迟，离开整个区域后收起。

背景与主题色确认：顶部目录栏融入文字区，共用输入背景并取消分隔线；底部工具带保留浅色背景。菜单可用项的悬停、键盘聚焦与展开状态使用当前主题色浅背景及主题色文字/图标，覆盖亮暗主题与自定义颜色，禁用项保持原状态。

底栏位置确认：添加、权限、模型/推理与发送按垂直中线同排；上下文仪表加入卡外统计区，查看、压缩及不可用原因沿用原逻辑。统计与仪表整体居中，窄栏自然换行并与主区同步预留高度；上下文弹层受当前输入区宽度约束。首页使用相同操作顺序，不生成虚假用量。

留白与尺寸确认：增加目录行和文字区上下留白，底栏上下内距增至12px；添加与权限入口同为36px高、主图标20px、下拉箭头12px，权限文字与模型使用同级字号，左组间距12px。窄栏间距收至8px，添加入口宽32px，保持同排及菜单可达。

背景圆角确认：添加与权限入口均使用Button默认圆角，权限入口不再使用直角的行内文字尺寸；悬停和聚焦保持同一背景形状。

底栏厚度确认：保留已增加的文字区上下留白，将底部灰色工具带上下内距收至4px（左右12px），按钮仍为36px高，使整条工具带从60px收至44px。

首行位置确认：文字区上内距从24px收至8px，下内距从24px增至40px，保持总高度并将首行上移16px。占位提示精简为“输入问题，@ 引用文件，/ 使用指令”，英文同步缩短；用户设置的主题色和聚焦边框保持原样。

目录与正文间距复核：目录栏上下内距从8px收至4px，栏高48px降为40px；文字区上内距8px归零，首行再上移16px。底部留白和按钮保持，整体输入卡同步缩短16px。刷新时先判断是否存在选中会话，空态不等待不存在的会话标题；核对实际加载的CSS文件与目录/输入坐标。

环境栏尺寸确认：工作目录与本机/服务器文字使用与权限入口相同的14px字号，主图标统一20px，下拉箭头12px，环境栏高度和首行间距保持。

合并前审查补充：360px以下且同时显示推理或适配器额外开关时，底栏分两行，模型/推理/发送获得完整第二行。普通首页、主区及不带这些开关的侧栏仍为单行。使用实际ACP会话在280px侧栏检查按钮宽度、两两不重叠及模型/推理/设置菜单操作。
