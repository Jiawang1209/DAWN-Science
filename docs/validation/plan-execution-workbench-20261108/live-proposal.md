# 本轮真实模型复验范围

- 授权：用户本轮明确新增最多 30 次请求；旧额度不滚存。
- 当前模型核对：只读检查正式 DAWN 最近会话的最后 model_change，实际为 `deepseek/deepseek-flash`。不输出对话正文、端点或凭证，不更改正式配置/数据。
- 沿用 `evaluate:science --research-current-api`、现有请求分区、无自动重试配置、科研模板、宿主验收、独立真值及模型清单冻结。
- 一个自制 `carbon-missing` 任务，单执行者 / 多执行者各一次，各最多 15 请求。多执行者核查与分析共享 11，独立审阅 4；合计不超过 30。
- 本轮多执行者使用新 `approved-plan` 编译适配器，从批准的明确安排冻结执行者、契约与内容版本，进入原 Team 调度器。与原单执行者使用同一输入、方法、产物、预算和真值判据。
- 此处固定核查/分析/审阅是受控评测条件，不是产品默认任务块数。它验证新绑定执行路径，不评估模型自动拆分质量，也不能用单次试验证明稳定提效。
- 输出为本目录 `live-01/`；文件与会话只写隔离试验目录。候选代码和子进程构建冻结后开始，运行中不修改。失败不自动重跑；达到预算即停止。
- 历史偶发关闭超时仍 OPEN，不因本次正常退出样本关闭。未推送、发布、安装或替换正式 App。
