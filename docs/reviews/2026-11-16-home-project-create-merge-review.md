# 首页与新建项目：合并复查

复查对象：`codex/home-project-create`，相对 main 基线 `b6e18e8f` 的首页、新建项目、元数据、协议与迁移改动。

## 发现并修复

在隔离临时目录里复现：新建项目将父目录解析为真实路径；原 `ProjectManager.open` 只按输入路径查找。同一 macOS 目录经 `/var/...` 与 `/private/var/...` 重新打开，会出现两个 projectId。

修复：优先保留旧的精确路径记录；没有命中时，再查真实路径对应的项目。只有本次创建所使用的规范路径身份已存在时才复用，不重写已有记录、目录或会话历史，尚不存在的工作区仍沿用原行为。补充跨平台符号链接/junction 回归和旧记录保持测试，以及 Electron 的重新打开与计数断言。

红绿验证：新增测试先失败（同目录得到不同 projectId），修复后 6 文件、130 项相关检查通过。构建与类型检查通过。
