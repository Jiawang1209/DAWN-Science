**实现：** 抽取会话菜单项组件，App为顶部接入既有会话回调；预览复用已有PreviewCloseButton与closePreview，补齐非脚本格式、读取中和失败态。

- [x] 菜单：先补顶部与侧栏菜单一致、非当前标签操作、键盘关闭的失败用例；抽取共享组件并接通现有操作，运行相关组件测试。
- [x] 预览：先补Markdown/表格/读取中/失败态收起及迟到读取用例；复用同一收起组件和回调，验证焦点返回及现有图片/脚本流程。
- [x] 验收：运行相关Vitest、typecheck/build、顶部标签/产物Electron回归；实际预览检查右键菜单和长文预览收起，检查窄窗口和菜单边缘定位。
