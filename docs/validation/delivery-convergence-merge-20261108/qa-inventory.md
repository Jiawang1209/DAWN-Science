# 交互与视觉验收清单

使用本地模拟模型，真实Electron与文件/验收/恢复；只在隔离临时root操作，绝不读取正式凭证，不新增付费API。默认对话协作台、展开流程工作台；用户可操作的开发版来自合并后main。

| 用户可见行为/控制 | 功能检查 | 视觉状态与证据 |
|---|---|---|
| 启动和隔离说明 | 初始窗口、项目名称含模拟模型，配置/DB/userData等全部隔离 | 初始视口、窗口尺寸和必要控件无遮挡 |
| 目标自动安排及采纳 | 目标→生成安排→任务块数是结果→采纳3任务样例 | 方案结果、冻结权限与方法说明 |
| 任务执行与验收 | 3任务完成且当前回执accepted；原输入未变；产物2文件 | 默认对话协作台/流程工作台/验收进度 |
| 重复开始 | 完成后再次开始不增加本地模型调用 | 无重复成员和任务 |
| 成员/工具/展开返回 | 选择、记录页、原始参数与干净结果；关闭检查面板、返回 | 成员联动、页签/焦点保留；原始ID与长内容折叠 |
| 主产物与版本 | 统一入口列出验收文件；核对一致→修改→不一致→恢复 | 来源/短SHA/详细来源展开与核对状态 |
| 会话隔离 | 新会话没有旧会话成员/产物；切回正确恢复 | 不混图、不显示其他会话验收 |
| 取消排空 | 延迟模拟响应时停止；最终无running/stopping；不接受迟到结果 | 取消状态和排空完成 |
| 重开恢复 | 同一隔离配置重开，保存验收/取消历史，不自动重跑 | 历史来源明确，调用数不增加 |
| 窄窗与旧入口 | 900px无对话框横向溢出；文件/方案/团队入口正常 | 初始视口、最密成员、详情滚动及返回控件 |

探索边界至少包含：修改已验收文件、取消后重开、不同会话切换。截图检查与功能检查分开；视觉不合格不能仅靠数值断言通过。此演示不把模拟模型结果冒充真实模型质量，已完成30/300对照单独引用。
