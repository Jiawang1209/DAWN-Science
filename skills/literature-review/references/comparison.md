# 字段与交付模板

三张表共用 P1、P2……文献 ID 和 P1-E1、P1-E2……证据 ID。同一研究的不同论文可各有文献 ID，但要写明研究关系。

## 文献清单：每篇一行

| 字段 | 记录方式 |
| --- | --- |
| 文献 ID / 原始文件 | 稳定编号与用户工作区实际路径；不改原文件 |
| 题名 / 作者 / 年份 / DOI | 只抄可核实信息；缺失不填造 |
| 材料状态 / 已读范围 | 全文可读、摘要、仅题录、文本不可提取；逐段列实际已读 PDF 物理页，全文可读不等于全文已读 |
| 研究对象 / 设计 | 物种、人群、实验/观察/模型，处理与对照及时间点；附证据 ID |
| 样本量与单位 | 按组/终点列 n，生物重复和技术重复分列；未提供不计算 |
| 分析方法 / 主要结果 | 条件、终点、效应方向/大小/单位及不确定性；附证据 ID |
| 局限 / 同研究关系 | 作者自述局限与模型归纳分开；引用证据 |

## 逐项证据：每条事实一行

`证据 ID | 文献 ID | 字段 | 原文信息 | 原文件 | PDF 物理页 | 印刷页码 | 原文短摘 | 状态/已读范围`

页码必须来自该文件的实际读取结果，不能由文献页数/DOI/题录生成。非 PDF 文本用实际章节或行号并注明“非 PDF”，物理页留“未提供”。缺失信息也可记一行，但不捏造支撑该缺失的引文、页码或证据。

## 差异对照：每个比较问题一行

`比较项 | 涉及文献与证据 ID | 各研究结果 | 可比性 | 综合判断 | 待核对/模型归纳`

先写可比性，再下结论。研究对象、处理强度、对照、时间点、测量终点或独立样本单位不同，不直接宣称结论互相推翻；使用“方向不同，可比性待核对”。没有足够效应量、方差和设计依据时不合并效应。不要只数正反论文篇数得出科学定论。

## 文献总结.md

```markdown
# 文献对照：<实际问题>

## 材料与覆盖范围
本次选定材料 <实际数量> 篇：全文可读 <数量>、仅摘要 <数量>、仅题录 <数量>、文本不可提取 <数量>。
列各文献 ID、原文件及实际已读页段，说明未读或提取失败范围。不称为穷尽检索或系统综述。

## 可支持的发现
按比较问题组织段落；每项事实标文献 ID、证据 ID 和 PDF 物理页。综合判断标“模型归纳”。

## 分歧与可比性
列各方证据、比较条件和缺口；解释性假设标为待验证。

## 局限与待补充
区分作者自述与模型判断；列未提供字段、未读全文、图表待核对、扫描件等。

## 文件与核验范围
实际 Excel 路径和三张表；记录做过的读回检查及未核验部分。文件核验不替代科学核验。
```

这只是结构：用实际材料填入内容，删除占位符，不在没有来源时补齐“看似完整”的表。
