# 主题色：一键换色（2026-08-23）

作者：*「绿色可以设置为一个可选的颜色……在设置、外观的地方设置一个颜色选择器，一键改为其他颜色。」*
*「活的东西跟着你，对错还是红绿。」*

## 为什么便宜

整张样式表里的强调色只回到**一个种子** `--theme-accent`（设计契约守着「styles.css 无裸色值」）。
按钮实底、选中底、卡片绿边、勾选框、发送键——全是 `color-mix` 从它派生。
换色 = 改一个变量。

## 形状

外观 → 「主题色」一行：六个预置色块（绿 / 蓝 / 紫 / 橙 / 粉 / 灰）+ 一颗「自定义」（原生 `<input type="color">`，macOS 弹系统色盘）。
选的瞬间整屏变；存 `localStorage["dawn.global.accent"]`，作用域「这台机器上这个人」，与主题、语言同一层。

## 定案

| 问题 | 决定 |
|---|---|
| 亮 / 暗各选一次？ | **不**。人选一个，暗色那一支由 `暗色变体`（往白兑 14%）算。默认绿例外：不写行内样式，用 tokens.css 手调的 `#19c37d`。 |
| 浅色主题色配白字？ | 按 WCAG 相对亮度判：> 0.4 用深字（`按钮字色`）。 |
| 「成功 / 活着」跟不跟？ | **拆成两个令牌**。`--dawn-live`（正在跑、已连上、已绑定、`ok`）跟主题色；`--dawn-success` / `--dawn-danger`（diff 加删、任务完成失败、传输完成出错）固定红绿——主题换成橙红时它们不能撞色。 |
| 默认值写几处？ | 两处（`DEFAULT_ACCENT` 与 tokens.css），单元测试读 tokens.css 对它。 |

## 坐在哪一层

- `src/ui/tokens.css`：`--theme-user-accent / -dark / --theme-user-on-accent / -dark` 四个种子的种子；`--theme-accent` 与 `--dawn-on-accent` 从它们来；`--dawn-live: var(--theme-accent)`。
- `src/ui/state/accent.ts`：`$accent` / `setAccent` / `loadAccent` / `applyAccent`（行内样式写到 `<html>`），颜色算术（`相对亮度`、`暗色变体`、`按钮字色`）。
- `src/ui/Settings.tsx` `AppearancePanel`：色块 radiogroup + 自定义。
- 判据：`tests/ui/accent.test.ts`（算术、默认值一致、默认不写行内）；`e2e/accent.spec.ts`（选色整屏变、活着跟、成功不跟、重载还在、浅色换深字）；视觉基线 10 张不动（默认像素不变）。
