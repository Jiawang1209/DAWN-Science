# 产物极简流程

用户于 2026-10-28 批准：看结果 → 一键保留 → 历史看旧副本；来源详情折叠，整理交付退到次级入口。继续在 `codex/artifact-provenance` 实施，不提交、合并或推送。

## 界面契约

- 默认产物页展示文件和图片清单，页头只留“结果”“历史”“更多操作”。交付说明、交付页签与醒目整理按钮退出默认视图；交付功能经“更多操作”可达。
- 打开文件仍显示现有预览。预览上方常驻“保留”，点击即保存这一个结果，以文件名和当地时间命名，不弹名称/备注表单、不离开预览；成功显示已保留。正在保存时可中止，重复点击不能重复发起。
- 来源默认只有语言/工具及记录时间一句摘要。实际代码、输入、环境、Run、完整哈希、观察历史、校验和缺口放进关闭的“详细来源”。来源摘要不把观察归属或输入声明提升为已确认因果。
- “更多保留选项”按需展开名称、备注、多文件组合与限额。单文件主流程不依赖填写；组合沿用整组原子留存。
- “历史”只展示真正留存的组，名称、当地时间和文件名；点文件直接预览已保存字节，默认无原始 JSON。来源和删除/交付操作分别折叠；删除仍明确确认。旧版本内容不存在或损坏时不回退当前文件。
- 无可信来源的现有文件仍可显式保存当前字节，并说明生成过程未记录。若选定观察后文件变化，拒绝错绑，提供刷新入口；不自动将新字节绑定旧来源。
- 不修改数据库/协议/留存服务，不清理任何原用户数据。保留已有体验项目、结果、副本与会话。

## 验证

组件回归检验默认无表单或技术详情、一键保存固定身份且不离开预览、详细来源按需展开、只列已保存历史、直接旧字节预览、迟到响应不串会话、失败不静默回退和次级交付可达。Electron 检验实际文件保存→覆盖→历史预览旧字节及英文/窄面板布局，原交付和视觉基线继续运行。最后用同一隔离体验资料重开分支原生预览。
