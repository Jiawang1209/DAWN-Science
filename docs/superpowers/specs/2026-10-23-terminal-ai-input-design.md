# 终端默认 AI 对话入口

> 历史方案，已被用户确认的 [真正 CLI 入口](2026-10-23-dawn-cli-design.md) 取代；不再以此描述当前界面。

用户实际预览后澄清：应直接在终端面板自然语言对话，不需要先进入Python。已选择“默认AI对话，按需切换手动命令”。继续使用codex/terminal-assistance独立分支，不合并、不推送、不替换安装版。

## 交互

有本地内置主对话的终端默认AI对话。终端面板内显示自然语言输入、当前对话的回复、执行反馈和停止入口；与当前主对话共享上下文，回复仍在主对话留存。面板内发送是用户对所选终端的显式授权，不再要求先点交出或打开解释器。手动命令切换立即接回，按键直接进入原PTY；切回AI不立即发送命令。已有Python/R仅在原PTY的实际前台进程名和标准就绪提示符同时匹配时同步程序类型，不能识别时保持已有类型并拒绝不匹配的执行。

无本地内置主对话的旧终端保留手动能力，并提供明确的不可用原因，不自动新建或替换用户对话。首版使用前仍需打开本地内置主对话。

## 数据流与执行

新增sendTerminalPrompt协议操作及共享mock伙伴（协议8.26），绑定确切owner/terminal并重复校验活性、项目和工作区。复用writeToSession的引用处理、队列送达、原话转录、轮次记账及标题链；显式@R/@Python仍优先原内核入口。运行时在接收普通用户文本时，为模型单独附上本轮终端上下文；策略指令识别与可见历史剥去该上下文，避免内部指引污染用户指令；主界面、搜索和历史仅呈现原话。当前消息中的目标约束终端工具，不能借用另一终端；下一条普通主对话消息不继承。模型执行沿用原讨论、方案与权限门，不能改走bash/run_code绕开所选终端。

支持普通shell中的Python/R单次命令；保持已打开解释器中的变量续用。不因用户说自然语言而把文本直接写到shell/REPL。发送失败保留草稿，切会话/终端的迟到回复不得污染新对象。停止AI撤销控制但不杀原进程；Ctrl-C仍是单独动作。

## 呈现与验证

沿用现有Markdown、权限卡和问答卡；AI输入与手动终端分别有可见状态。窄窗保证输入、发送、模式切换、停止与原终端均可达。原底层控制测试保留；新增默认AI、自然语言不进PTY、选中目标、切手动接回、标准解释器识别、失败/切换/权限/讨论/方案，以及实际Electron直接从终端输入自然语言的回归。真实预览模型保持隔离固定模型，真实命令与文件证据另核对。
