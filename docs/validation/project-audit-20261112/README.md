## 已修复的问题

1. **启动被取消后，并发调用结果不一致。** 原先一个调用报停止，另一个却拿到已停止会话的句柄；现在所有调用等待同一份完整启动结果，停止路径仍只等待原始初始化，避免互相等待。
2. **初始化失败且被停止后，下一次正常重试也被停止。** 启动结束时清除该代的停止标记。两条实际运行时回归均先复现失败，再验证通过。
3. **定时任务接受不存在的日期。** 例如 `2026-02-30` 被悄悄转成三月日期。现在保存前核验真实日历日期，后端拒绝无效请求且不留下任务。
4. **更新文件名可以越出下载目录。** 旧代码在请求网络前删除拼接路径，恶意文件名可删除目录外文件。现在先拒绝路径分隔符、盘符/流语法、NUL、空名和点名；临时哨兵文件的回归证明目录外文件保留、未发起网络请求。

同时修正技能预览焦点测试的异步等待、旧底栏单行布局断言、内核测试只检查 macOS 固定目录的前置条件，以及 README 对“跨重启保留变量”的不实描述。按现有锁文件重装开发依赖，解决两个本地 `minimatch` 安装版本漂移；`package.json` 和锁文件哈希未变。
