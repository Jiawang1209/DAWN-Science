## 设计依据

![已认可的整合效果图](../../design-references/2026-10-10-ui-refresh/approved.png)

这张图是视觉参考，科学图表、文件名、分析结论均为示例，不代表真实分析结果。实现以现有能力和下列约束为准，不逐像素复制生成图中的文字与虚构按钮。

本轮目标是让左侧导航、主对话、输入框和右侧预览形成同一套视觉语言。重点是层级与留白，不以单纯换主题色代替设计。

## 已确认的产品约束

| 区域 | 决策 | 行为边界 |
| --- | --- | --- |
| 整体 | 首次使用默认浅色，暖中性灰外壳、白色工作面、克制的青绿点缀 | 保留用户已保存的亮色、暗色、跟随系统与自选强调色 |
| 左侧 | 新建任务 → 项目 → 服务器 → 最近 → 会话 | 项目和服务器最常用；其余会话下移，不改变会话归属 |
| 左下 | 远端服务器、定时、已归档、设置及已有更新入口 | 保留实际操作回调；连接管理与服务器会话分组各司其职 |
| 对话署名 | 显示每轮的服务商/厂家，例如 DeepSeek | 沿用 item.by 与 nameOf；历史回答不跟着当前模型改名 |
| 输入框 | 精确模型名、推理强度和发送键同组 | 配置不支持推理强度时不造“高”选项 |
| 输入工具 | 添加文件、工作目录、终端、优化输入、生成方案可见 | 窄栏可换行，不统一塞进省略菜单；权限/能力限制继续生效 |
| 附栏 | 上下文百分比与权限状态 | 不添加效果图曾出现的独立“标准”下拉 |
| 右侧 | 文件 / 结果文件 / 笔记本 + 更多 | 结果文件是 artifacts 的显示名，保留所有内部 ID 与其他面板 |
| 结果信息 | 对话以简洁摘要为主，右侧负责详细清单与预览 | 不改变本轮归属、未知状态、缺失文件和读取失败的事实 |

“优化输入”的 basic/standard/expert 与工作步骤的 simple/standard 是现有能力，不因删除虚构的“标准”控件而被删除。

## 布局和视觉

以下是工程起始值，最终通过真实应用截图校准，不能拿生成图的像素直接写死三列宽度。

- 顶栏保持低噪声；搜索入口继续走真实项目/会话/文件检索，不新造一套搜索。
- 左侧初始宽度建议 248px，保留现有 200–420px 拖拽与已存宽度。行高约 36–40px；分组之间 20–24px，组内 4–6px。
- 全局背景是浅暖灰；主对话与右侧是连续白色工作面，间隔约 8px，圆角约 12px。正文、工具过程不继续套多层卡片。
- 项目选中行使用低饱和淡青绿面；最近中的同一会话使用轻量文字/标记，避免多个大色块争夺注意。
- 服务器行以名称、图标及真实连接状态为主。展开后仍可查看其会话；详情经现有连接管理入口查看。
- 正文以 15–16px 作为起点，标题层级约 24/18px，辅助文字约 12–13px。代码、表格沿用等宽与现有交互。
- 输入框保留“正文输入区 → 模型/强度/发送 → 工具行 → 卡外状态”的清楚顺序。无附件且空白时保持紧凑；多行输入可增长。
- 右侧宽度先保留现有默认 380px、280–720px 拖拽边界，用户可拉宽图表。预览铺满可用区域，不再附加多重阴影和描边。
- 全部颜色从 tokens.css 派生，复用 primitives；新令牌登记到 docs/DESIGN.md。暗色仍是完整可用主题。

## 真实能力与效果图的对应

1. `App.tsx` 的 agentLabel 已按 native provider 配置解析名称；`views.tsx` 的消息已优先使用 item.by。此次保留并验证，不把所有消息改成 DAWN，也不把历史统一替换成当前服务商。
2. `files.tsx` 的 FilePreview 已支持 PDF（embed）、图片和其他内容。复用真实预览，不增加第二套 PDF 阅读器。
3. 助手回答的现有复制等操作保留；“修改”仅对用户原话可用，并作为新消息重发。参考图中助手下方的“编辑/回复”不自动变成新功能。
4. `generated-strip.tsx` 的结果统计按提问分段与工具调用关联。摘要仍以这份事实为准，不把整个会话文件数当成本轮数量。
5. 右侧原有九个面板是 review/files/artifacts/notebook/overview/web/subagent/team/chat。常用三个直达，其余通过明确的“更多面板”入口可见；选中更多中的项目时，也显示其当前身份。
6. 连接状态必须来自现有连接状态源；不把示例 Genek 绿色圆点当作永远在线。

## 状态与适配验收

- 核对新建任务空态、有本地项目、远端会话、无连接、长名称、多项目、多会话、归档、定时、设置与更新入口。
- 核对主区与右侧对话各自的草稿、模型、权限、终端控制；问题接管、生成方案、排队/停止/重发保持行为。
- 核对中文输入法、Enter/Shift+Enter、Tab 接受下一句建议、@文件、/命令与附件。
- 1280×800、1440×900、1920×1080 下主输入与右侧预览无越界；窄侧边对话工具行换行后依然全部可达。
- 鼠标与键盘都可操作。状态不只靠颜色；焦点环、文字和按钮对比度按现有设计契约检查。
- 切换项目不自动打开右侧、不抢输入焦点；拖动宽度、折叠组、选择面板和主题的原持久化范围保留。

## 本轮不纳入

单位账户/权限体系、机构数据目录、Web 服务端、底层协议重做、独立内部溯源系统、复制两套业务核心、发布安装包和替换已安装应用。这些不属于本次视觉刷新实现。
