# 下一句灰色建议

用户已确认：空输入框显示灰色的下一句建议，Tab 接受后才成为真实文字，Enter 不接受或发送建议。

API 会话在最终回复完成后，用当前会话模型独立生成一句建议；不调用工具，不修改转录。不为 ACP 自动借用其他模型。仅使用最近六条最终对话（每条最多 2000 字），不读取文件。允许返回空建议，避免完成任务后强行续聊。独立请求最多等待 15 秒；输入组件生命周期内每段回复缓存一次（最多 30 项，重新打开可重新请求），失败不影响正常输入。

输入框复用灰色 placeholder，保持既有单行省略样式和 44px 空框高度。主区和侧区共用实现。Tab 只在 DOM 确实为空、非组词、无修饰键时接受；Shift+Tab 仍导航。用户输入、附件、待答问题、执行中与会话不可用时隐藏。旧请求通过会话与回复身份隔离；建议不是草稿，不参与发送和历史。建议请求错误只记录诊断，不占用聊天区。

验证：建议生成上下文与长度边界、空建议和错误；输入框 Tab/Enter/Shift+Tab/IME/草稿保护；请求时序和会话切换；类型检查、构建、相关回归。
