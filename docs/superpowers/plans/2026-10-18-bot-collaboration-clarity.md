# Bot 协作清晰度升级

已批准范围：统一状态表达、团队进展摘要、交付入口收拢。保持三栏布局，主对话显示紧凑摘要，Bot 坞提供总览 → 成员结果 → 交付文件 → 预览；完整讨论和发言保留。独立分支实施，不合并、不推送、不替换安装版。

1. 用测试固定状态投影：任务返回和成员可用性分离，当前轮交接、等待确认、失败/取消分别表达；协作回应不计为任务完成。
2. 共用结构化状态投影及已核验文件索引，不从模型正文推断文件或科研正确性。
3. 实现作用域内导航，保留讨论、草稿、发送对象、滚动、失败重试和任务停止/补充入口。
4. 主对话改为摘要和团队/交付入口；坞内单行成员列表，文件分组及来源，复用文件预览与关闭。
5. 更新定向测试及真实运行时协作 E2E，构建和回归，打开隔离 Electron 实跑案例。

验收清单：处理中/等待队友/已回应待继续/待回答/待批准/失败/取消/文本返回无文件；当前 attempt 和跨会话隔离；总览和详情导航、独立发言对象、草稿与失败请求 ID；文件去重、脚本/表格/图/报告预览和读取失败；窄坞和暗色；真实 Python 计算与原始输入不变。确定性推理仅用于工程验收，不声称验证真实模型科研判断质量。
