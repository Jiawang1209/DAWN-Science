# 协作台怎么用

当主助手创建子任务后，对话上方会出现“协作”摘要：任务数、当前进度和宿主验收数。点它打开右侧协作面板；原右侧“团队”入口继续可用。

1. 在紧凑列表选择成员，查看它当前在执行、等产物锁、排队还是停止排空。
2. 下方“过程”看阶段；“交接”看冻结正文和历史引用；“产物”看宿主验收及版本；“记录”看技术信息。
3. 点击“展开流程工作台”，在完整工作区左边看网络，右边查看、搜索或筛选成员。点节点或卡片会联动选择，并打开同一份详情。
4. 真正的任务依赖单独列出；网络里同属主助手的执行记录不会被画成假的串行流程。
5. 点击“返回对话协作台”或按 Esc 返回，原任务和页签保留。“查看子任务过程”仍进入原子对话，续聊与停止由原后端权限决定。
6. 额度在底部“查看额度”；原队长、成员、任务消息等功能保留在“团队管理与原始记录”。

“执行完成”不代表“宿主验收通过”，也不代表科学结论已通过独立审查。“停止中”表示还在等待进程排空。历史快照只读，不会因为打开界面就恢复任务。

用量是已记录的累计tokens，不是当前上下文占比；缺字段标为部分，费用没有数据就显示未记录。截图演示使用本地测试模型驱动真实执行，不是新增科研效果实测。

本轮处于隔离工作区，正式安装版尚未替换；历史偶发 Electron 关闭超时继续跟踪。

## 本地集成前复审补充

同一会话重建团队后，任务选择按团队ID和任务ID一起绑定，重复的t1不会继承旧选择。续跑、排队、停止或中断时，保留的旧结果不会计为本轮验收或显示为本轮tokens；当前用量以会话额度账本为准，保留版本信息仍可在记录中核对。阶段耗时标为累计结算。

展开时按⌘K/Ctrl+K会先退出工作台再打开原命令面板；⌘P/Ctrl+P和Ctrl+Shift+G先收起再进入原文件/审阅入口。输入法组词占用的组合键不触发背景操作。无团队时恢复/team提示，原团队管理仍在显式展开入口内。
