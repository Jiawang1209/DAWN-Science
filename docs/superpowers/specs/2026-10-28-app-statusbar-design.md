# App 底部状态栏

用户已批准：底部左侧依次显示当前模型、R、Python；右侧依次显示启用的插件、Skills、MCP、子 Agent 数量，版本号在最右侧。继续在 `codex/composer-toolbar-order` 实现，验证并更新本机原生预览，不合并、不推送。

## 布局与交互

- 状态栏基础高度 30px、字体 12px，无常驻色块，鼠标悬浮显示轻背景。正常小图标使用主题强调色，异常使用危险色；文字同时表达状态。
- 模型显示主区当前会话的模型，而非服务商名称；尚无会话时显示即将使用的默认模型。模型详情显示服务与运行方式，提供现有模型设置入口，不增加第二套切换器。
- R、Python 点击打开详情，显示当前本地/远端环境、所配置路径、检测结果、检测按钮和配置入口。路径未读取不显示为未配置；读取失败显示异常。只填路径显示“已配置待检测”；匹配该路径且内核包齐全才显示“已就绪”。检测由用户触发，不在启动时扫描所有环境。
- 主区内核 starting/idle/busy 分别显示启动中/已就绪/运行中，detached 显示连接中断，exited 回到配置及检测状态；内核就绪不证明当前配置路径已验证。远端会话只用远端解释器配置与检测结果，点击配置打开对应连接设置。
- 四类数量均为当前启用数量，0 如实显示，未加载/失败显示横线而非假 0；悬浮说明作用范围，点击进入对应设置页。Skills、MCP、子 Agent 随项目变化，旧请求不能回填新项目。
- 版本取 App 已有版本信息，点击进入关于。窄窗口将四类计数收为“扩展”菜单，模型可省略长名称、详情保留全文，版本始终可见。
- 保留连接、凭证及操作错误提示，放在状态栏上方独立提示区域，可换行/滚动，不与状态项争抢空间。

## 验证

组件测试覆盖各状态、路径/连接切换后的检测隔离、失败、0/未知计数、菜单与键盘交互。App 集成测试覆盖启动请求收敛和模型展示。Electron 验证实际入口跳转、窄窗布局、版本位置、无自动解释器扫描及此前侧栏/工具栏行为。最后更新独立原生预览，保留预览配置和会话。
