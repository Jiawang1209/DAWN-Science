# 终端自然语言入口 QA

用户已确认默认AI、按需手动。沿用当前主对话上下文；不要求先打开Python/R。

| 用户可见项 | 功能检查 | 视觉检查 |
|---|---|---|
| 默认AI对话页签与自然语言输入 | 直接从终端提交；原话进入对话和模型，不进PTY | 初次打开、普通1280×840与窄窗900×700 |
| 提交给AI、失败草稿与输入法 | 单次发送、IME Enter不提交、失败保留、切对象不串 | 输入/错误/执行中按钮状态 |
| 终端对话记录、执行反馈 | 同一主对话真实回复、实际工具结果、隐藏/重开保留上下文 | 可滚动记录、长结果不横向溢出 |
| 手动命令、AI对话切换 | 手动立即接回原PTY，回AI不自动执行 | 两页签选中态、原终端输出和可见控制行 |
| 打断AI、Ctrl-C | 停止模型与中断程序分开，原进程保留 | 对应状态入口明确可见 |
| 权限与澄清卡 | 复用当前对话卡片，不显示重复按钮 | 卡片可滚动操作，主输入不被遮挡 |
| 多终端与既有执行边界 | 本轮仅选中终端，普通下一轮不继承；讨论、方案和内核明确选择不变 | 作用域切换状态及时更新 |

探索：立刻提交与PTY启动的竞争；提交失败重试；切手动保留PID；收起/重开；普通主对话接续；关闭和自然exit。类型、全量、构建、Electron结果及实际截图见同日核验报告。
