# 笔记本修缮 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 项目会话里 agent 真的用 `run_code`（= 笔记本）；远端会话明说没有内核；对话与笔记本都能导出，落到 `<项目>/docs/` 或下载路径；导出提示浮出淡去。

**Architecture:** 提示词改在每段会话都带的两处（工具描述 + `appendSystemPromptOverride`）。cell 派生搬到 `src/protocol/notebook-cells.ts` 供前后端共用；`.ipynb`/`.md` 生成是纯函数（`src/session/export-notebook.ts`）；目录规则是后端一个纯函数 `导出目录`，`exportSession` 与新操作 `exportNotebook` 共用。界面一个 `导出提示` 浮层组件两处共用。

**Tech Stack:** TypeScript / zod 协议 / React / vitest / Playwright。spec：`docs/superpowers/specs/2026-08-27-笔记本修缮-design.md`。

### Task 4: `.ipynb` / `.md` 生成（纯函数）

**Files:**
- Create: `src/session/export-notebook.ts`
- Test: `tests/session/export-notebook.test.ts`

```ts
export interface 笔记本头 { title: string; agentId: string; createdAt: string; workspace?: string | undefined }
export function cells成ipynb(头: 笔记本头, cells: readonly Cell[]): string   // JSON 文本
export function cells成markdown(头: 笔记本头, cells: readonly Cell[]): string
export function 笔记本文件名(title: string, id: string, ext: "ipynb" | "md", when?: Date): string // 「笔记本-」前缀 + 导出文件名 的时间戳
```

- ipynb：`nbformat: 4, nbformat_minor: 5`；`metadata.kernelspec` 按多数语言：python → `{name:"python3", display_name:"Python 3", language:"python"}`；R → `{name:"ir", display_name:"R", language:"R"}`；混排时首格 markdown cell 说明，且与 kernelspec 不同语言的 cell 源码首行加 `# [R 内核]` / `# [Python 内核]`；语言未知的 cell 首行 `# [语言未记录]`。
- 每 code cell：`{ cell_type:"code", id, execution_count: n, metadata:{ dawn:{ who, startedAt?, runId?, interrupted? } }, source: [按行, 保留 \n], outputs }`。
- 输出映射：`stream` → `{output_type:"stream", name, text:[...]}`（`truncated` 时末尾追加一行 `（已截断：原 N KB，保留 M KB）`）；`result`/`display` → `{output_type: kind==="result" ? "execute_result" : "display_data", data:{[mediaType]: data}, metadata:{}}`，`result` 带 `execution_count`；`tooLarge` → 一条 stream stderr `（输出太大未保留：N KB）`；`error` → `{output_type:"error", ename, evalue, traceback}`；孤儿 cell 源码空、首行注释 `# （未记录代码）`。
- md：头三行同 `转录成markdown`；每格 `### [n] Python · agent · HH:MM:SS`（`who` you → 你）；代码围栏语言 `python`/`r`；stream 文字围栏 `text`；`error` 围栏 `text` 用 traceback 去 ANSI（`/\x1b\[[0-9;]*m/g`）；`image/png` → `![输出 n](data:image/png;base64,...)`；`text/markdown` 原样；`text/html` 围栏 `html`；其它 mediaType 一行 `（mediaType，N 字节）`；截断/太大同上；`interrupted` → `（已中断）`。
- [x] 测试：一套含 stream/png/error/tooLarge/truncated/混排/孤儿的 cells；断言 ipynb `JSON.parse` 形状、kernelspec 取多数、混排说明存在；md 含 data URI 与 `### [1]`。
- [x] commit `feat(笔记本): ipynb / markdown 导出的纯函数`。

  export function 导出目录(a: { workspace: string; temporary: boolean; remote: boolean; downloadDir: string; dir?: string | undefined }): string {

    if (a.temporary || a.remote) return a.downloadDir

  }
