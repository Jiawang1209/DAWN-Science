# DeepSeek Flash 终端图片专项验收

仅复用既有 deepseek-flash 和加密凭证，保持独立开发分支，不改生产配置，不合并、推送或替换安装版。

- 终端实际模型元数据须为 deepseek/deepseek-flash；原生识图，不经过视觉转述。
- 新随机代号只出现在 PNG 内；真实剪贴板粘贴后先暂存，不自动发送；问题不含代号/颜色/形状答案。模型正确识别三者，证明真实图片送达。
- 缩略图可点击放大、关闭，宽窗口可输入。给 Agent 生成图片的任务，须有工具执行、实际输出文件和终端图片预览；本版不声称模型原生生成图片。
- 返回会话是同一 native ID，原图可见；不重新上传，续问仍答出图中随机代号和细节。
- 补充拖入/移除待发图片、再次打开终端保留图片、原主人草稿保持两项边界，最后预览停在 deepseek-flash DAWN 模式可试用。
- 保存截图、语义证据和文件校验；原凭证/配置哈希不变，主目录干净。若发现问题，先定位再修复并补对应检查。
