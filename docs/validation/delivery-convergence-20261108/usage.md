# 如何查看本轮效果

代码在隔离 worktree：`/Users/liuyue/.codex/worktrees/dawn-delivery-convergence-20261108/dawn-science`，分支 `codex/delivery-convergence-20261108`。正式安装的0.0.44没有被替换；正式App暂时看不到这份未集成改动。

1. 在开发候选中打开一个项目任务，从团队入口描述任务并自动安排。任务块数继续由任务决定，允许调整；本轮没有改回默认填数字。
2. 采纳可执行方案后，原冻结执行机制派发。带契约的原生子任务/Team执行者可以只读调用 `get_task_status`，看到自己还缺哪些读取/执行/审阅证据。工具进展变化时会收到简短提交提醒，正式验收仍以 `submit_task_result` 和宿主回执为准。
3. 对话协作台中展开“流程工作台”，左边看真实宿主委派网络，右边看紧凑成员卡片；卡片显示职责、身份、动作/阻塞、真实状态。点成员后检查过程、交接、产物、记录；返回对话协作台会保留选择与页签。
4. 打开原来的主“产物”页。任务验收文件和旧主会话/路线产物在同一入口；点文件可看“任务验收版本”。默认显示职责及短指纹，完整SHA和原始身份放在“验收来源详情”。
5. 点“核对当前内容”：一致、已改变或无法核对来自本次有界哈希检查，带核对时间。页面预览读取当前工作区文件；旧验收记录不能证明当前文件仍相同。改写/删除文件后应重新核对。
6. 重开任务只读恢复原记录，不自动重跑。历史验收会显式标记；旧文件、路线和保留/交付入口继续可用。

本轮预算实时提示限定在现有科研评测网关内，帮助验证预算内交付；没有更改正式产品的模型计费/执行轮数预算。真实模型对照是一个自制任务的试验结果，不能推广为所有科研任务的普遍收益。规划请求已计入实际请求总量；规划会话的 token 目前未汇入执行任务用量表，可见 token 列不能当作完整成本，不能据此宣称费用收益。
