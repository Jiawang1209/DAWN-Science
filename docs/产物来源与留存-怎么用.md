# 查看结果与保留版本

在右侧“产物”点开图片或文件，直接看预览。满意时点预览旁的“保留”，即可保存这份结果和当时记录的来源，不需要填写表单。名称会按文件名和时间自动生成；保存后仍留在预览中。

点击顶部“历史”，按名称和时间找到已保留版本，点文件就能查看旧副本。工作区的同名文件被覆盖或删除后，已保留内容仍可打开。只记录过身份、没有保存内容的普通观察不会混在这份版本列表里。

## 需要时再展开

- **详细来源**：检查实际提交代码或工具参数、输入声明、环境、执行日志摘要、Run 和内容身份。日常预览只展示简短摘要。
- **更多保留选项**：自定义名称、备注，或勾选多个结果一起保存。默认上限为 50 MiB/文件、200 MiB/组、1 GiB/项目，不自动删除旧副本。
- **更多菜单中的整理交付**：沿用文件选择、结果说明和独立验证流程。历史组的“版本操作”也可将确切留存副本交给该流程。
- **版本操作中的移除留存副本**：明确确认后只移除应用内副本，不删除工作区原文件。

## 来源与保存状态

自动记录覆盖本地已接入的 API 工具及 Python/R Notebook。“声明输入”只说明核对过声明的文件身份，不证明代码实际读取；已有变量、动态 I/O、数据库和网络依赖可能未捕获。原始输入数据默认不复制。

“已保留”会核对当前文件与已存身份。若文件被外部修改，会显示生成过程未记录，保留时对当前内容作后补留存，不改写旧来源。若在核对后、复制前又变化，保存会拒绝错绑；可以明确选择保留更新内容。没有可信历史来源的现有文件同样可以保存，但会保留后补来源说明。

删除或压缩聊天不删除项目已保留结果。移除项目会列出受影响的留存数量和大小，确认期间集合变化时需重新核对。

本版没有完整输入/变量快照，也不承诺远端、独立 CLI、ACP、Bot、子任务有同等自动记录。只有内核显示、未落盘的图片需先保存为文件。

保留表示字节和记录已保存；独立重跑验证及科学结论核验仍各有自己的判据。
