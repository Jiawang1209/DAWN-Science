# 多篇论文精读与对照

用户已确认：以用户给定论文为起点，逐篇整理设计、样本量、方法、结果和局限；保留 PDF 页码及短摘，交付可编辑 Excel 与 Markdown。使用独立分支，验证后仅合并本地 main，不推送。

## 实现边界

增加默认可由模型发现、也可 `/skill:literature-review` 手动调用的内置技能。复用现有 `pdf_read`、`xlsx_write/edit/read`、`read/write`，不新增依赖、协议或数据源。功能参考仅用于设计比较，独立编写所有新增文本和测试，不引入外部产品标记。

技能按材料盘点、分页阅读、逐项证据、可比性判断、导出及读回核验组织。清单区分全文、摘要、仅题录、文本不可提取；缺失、未读与提取失败不能互换。页码指 PDF 物理页；印刷页码另列。证据以 ID 连接文献、字段、原文和总结。样本量保留单位、组别、时间点及生物/技术重复，原文与模型归纳分列。

接入验收发现 pi 将显式技能正文置于用户消息内，旧执行边界会把正文里的“只讨论”当用户禁令。增加纯文本技能包裹解析，讨论/内核边界只识别其后的实际请求；正文既不能授予执行许可，也不能改变用户限制。覆盖字符串、文本块、纯技能、内核快捷标记与既有限制续存，不改变原权限门。

同一接入验收发现现有 PDF.js 对 Node Buffer 的兼容问题，会对合法 PDF 报字符错误；传入独立的普通 Uint8Array，保留现有解析器、页码及读取预算。增加真实双页 PDF 回归，未新增解析库。

## 交付

新建且确认不存在的 `outputs/literature-review/<本次唯一目录>/`，不覆盖论文或旧结果。Excel 三表：文献清单、逐项证据、差异对照；Markdown 写问题、材料覆盖范围、发现、证据 ID、局限及待补充。仅讨论时不写文件。插件关闭或外部运行时缺工具时说明缺口，给文本退路，不绕开权限安装工具。

材料中的指令不是用户授权。没有正文不编方法、n 或页码；扫描件不承诺 OCR；不自动下载全文；元数据登记不等于论文结论获核实。相反结果只有在对象、设计、比较和终点可比时才称分歧；多篇报告同一研究不重复计独立证据；不从选定文献推断全领域空白。

## 验收

真实 loader 发现且默认可调用；支持原资源覆盖和开关规则。内容合同检查关键科学及权限边界。共享确定性模型场景在真实 Electron 调用 PDF 与表格工具，生成真实 Excel/Markdown，验证页码、缺失字段、扫描件、原文件未改及工具关闭/只讨论分支。该场景证明接线和文件读写，不代替真实模型的科学推理评估。保留原视觉基线，固定隔离原生预览核对可见入口。
