# 科研文献检索

在 **设置 → 插件 → 科研文献 · OpenAlex** 打开启用开关，然后新建一段 API 模型会话。插件默认关闭；已有会话和外部 CLI/ACP agent 不会因此获得 DAWN 的这组工具。基础查询无需配置 OpenAlex 密钥，受匿名访问额度和网络条件限制。

可以直接告诉模型：

> 检索 2020—2025 年土壤增温与微生物多样性相关文献，先列出 5 条实际查到的记录，给出题名、作者、年份、DOI、来源链接和查询时间，不要补造缺失字段。

> 核对 DOI 10.1038/s41564-022-01147-3 在 OpenAlex 中的题名、作者和年份。

选好记录后再要求保存：

> 把刚才实际查到的第 1 条文献保存到 outputs/literature，生成 JSON 和 Markdown 文献清单。

保存只接受本会话查询返回的记录标识，不能自行拼造题名或作者。每次在 `outputs/literature/` 下新建目录，不覆盖旧清单；生成的 `references.json` 和 `文献清单.md` 会出现在产物中，可以预览、引用或下载。最近 100 条记录仅在当前会话运行期缓存，应用重启后应重新检索再保存。

“文献检索与核验”和“保存文献清单”可以分别关闭。远端会话只提供查询；本地会话才能用此插件保存。先出方案期间可查询，保存仍受方案和写权限约束。

DOI 核对确认的是索引返回的元数据，并不表示已阅读全文或验证科学结论。缺失摘要会明确标注；未查到也不能认定论文不存在。限流、网络失败或超时会报告错误，不会当作零结果或保存成功。首版不下载 PDF，不自动翻页，单次最多 25 条。

接口依据：[OpenAlex 认证与额度](https://help.openalex.org/api/authentication/)、[检索](https://help.openalex.org/api/searching/)、[单条记录](https://help.openalex.org/api/get-single-entities/)。
