# App 首页

用户已批准首页交互预览，按此实现。

首次安装依次显示四步引导、App 首页、工作台。已完成引导的启动直接显示首页。首页沿用 RP 标志、现有主题和按钮，展示正式项目、跨项目最近会话、继续上次、打开项目和新建对话。最近会话按 lastActiveAt（回退 createdAt）排序，排除归档与终端；临时会话不显示内部 scratch 路径。加载和失败状态明确，可重试。

工作台提供带图标的首页入口；返回不修改会话、视图、附件和代码草稿，运行继续。底部“导航栏”保持四步引导含义；首次结束引导进入首页，从工作台重开后回原页面。预览工具右下角的调整图标不进入产品。

复用现有项目和会话协议及 App 操作，不新增依赖、协议或本地环境要求，不改真实模型凭证。验证启动顺序、跨项目、目录选择、错误重试、草稿保留及引导往返。

后续“新建项目 / 目录”的表单、标准科研布局和项目上下文，按[用户认可的创建流程参考](2026-11-16-project-creation-reference.md)继续设计开发；该流程尚未实现。
