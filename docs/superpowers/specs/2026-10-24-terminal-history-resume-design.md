# 终端历史会话恢复

用户已授权独立分支实现与实际预览，不合并、不推送、不替换安装版。基线 main 77c49585。

普通 dawn 继续新建；dawn --resume 显示当前目录的本地 API 会话列表，dawn --resume <完整ID> 明确恢复。内置终端 Normal 模式增加“接续旧对话”入口，复用现有会话目录和模型配置。恢复直接订阅原 native ID，不复制消息、不生成摘要、不新建任务。

第一版只恢复当前目录的未归档、本地、普通 native 主会话。服务端再次验证目录、类型、归档、实际运行状态及是否已被另一 CLI 占用；无目标或恢复失败明确报错。取消选择不创建会话、不调用模型。目录不存在时不退回家目录。独立于桌面运行时明确提示此入口需要连接桌面，暂不合并独立 CLI 数据库。

恢复模型历史保持 pi 原记录和图片原始内容。终端初始化回放有限的文字、工具记录与图片缩略图；原图仅由原终端缓存按 ID 读取，不进入命令字节通道。展示截断明确提示，模型上下文不由展示截断改变。返回会话仍进入同一 ID；关闭与 Normal 退出沿用现有生命周期，不恢复已结束的 Shell/REPL 变量。

列表与 CLI 握手共用后端过滤规则。GUI 查询只在空闲 Shell 上发起固定、带随机标记的 pwd -P 探针，以实际 cd 后的目录筛选；因此新增列表操作按 mutating 处理，协议版本为 8.30。恢复流程防止并行占用和迟到输入，GUI 选择器可取消、搜索，过期列表不会直接放行目标。沿用单一 > DAWN 输入和既有图片放大。第一版不增加模型切换、导出、SSH 或分屏。

验收：新建不变；取消与空列表无副作用；关闭最后终端后恢复原ID、原任务数量不变；图片上下文在真实模型请求中仍存在；恢复后旧图片可显示；GUI 继续同一会话；归档/删除/跨目录/外部占用拒绝；真实 Electron、类型检查、相关单测与构建；隔离真实预览。

展示上限为最近 100 条、合计 1 MiB 文字及工具记录；最多恢复最近 12 张原始用户/工具图片。Markdown 返回图从仍存在于工作区的原文件恢复，沿用 24 张 / 64 MiB 缓存上限；只输出仍可读取的图片 ID，淘汰或历史截断会明确提示。CLI 数据通道剥离 GUI 缩略图，原图通过终端作用域读取。旧文件缺失仅提示，不重跑工具。

订阅前后检查模型流式请求、视觉转述、压缩、回退、停止等忙碌状态；现有会话正在工作时拒绝接管。图片缩略图由原始 pi 用户消息重建，应用重开后 GUI 仍可查看原图。
