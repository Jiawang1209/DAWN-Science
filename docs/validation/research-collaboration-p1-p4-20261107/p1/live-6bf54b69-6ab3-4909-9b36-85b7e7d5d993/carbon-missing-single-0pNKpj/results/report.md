# carbon_mg_g 算术均值 — 结果报告

- 模板：tabular-ecology@1
- 方法（用户已批准）：arithmetic mean
- 单位：mg/g
- 缺失值规则：仅丢弃目标列中的 NA，不按 `rain_mm` 筛选、不填补
- 脚本：`results/analysis.py`（Python 标准库，单命令 `python3 -I results/analysis.py`）
- 结果文件：`results/result.json`

## 1. 输入

| 项 | 值 |
|---|---|
| 文件 | `input.csv` |
| 数据行 | 48（另有 1 行表头） |
| 列 | `site`, `carbon_mg_g`, `rain_mm` |
| 目标列 | `carbon_mg_g` |
| 目标列缺失 | 7 行（`NA`）：plot-1, plot-8, plot-15, plot-22, plot-29, plot-36, plot-43 |
| 其余列缺失 | `rain_mm` 无缺失（48/48）；`site` 48 个唯一值 |
| 取值范围（可用值） | 12.0 – 15.6 mg/g |

单位 mg/g 由任务契约给定，不从数据推断；脚本不做任何单位换算。

## 2. 处理

1. 以 `csv.DictReader` 读取，校验表头唯一且含 `carbon_mg_g`，并确认存在数据行。
2. 目标列按字符串判定缺失（`NA`/`N/A`/`NaN`/`null`/空串，大小写不敏感）；本文件中实际只有 `NA`。
3. 丢弃这 7 行的**目标值**，其余 41 行全部保留；`rain_mm` 只随行保留、**未用于筛选或分层**。
4. 用 `decimal.Decimal` 对 41 个观测值做精确求和，再除以 n 得到均值，最后转为有限 float 写出。
5. 写出 `results/result.json`：`{"n": 41, "unit": "mg/g", "mean": 13.870731707317074}`。

无填补、无截断、无静默回退；遇到非数值或非有限值脚本会报错退出，而不是跳过。

## 3. 结果

| 指标 | 值 |
|---|---|
| n（可用观测） | 41 |
| 求和 | 568.7 |
| **算术均值** | **13.870731707317074 mg/g** |

精确十进制均值为 13.87073170731707317073170732…，浮点表示 13.870731707317074，
与宿主容差 1e-9 相比误差远低于阈值。

独立复核：用另一段 Python 代码（`statistics.mean`，独立解析）重算得到
n=41、sum=568.7、mean=13.870731707317074，与脚本输出逐位一致。

## 4. 局限与解释边界

- 结果只描述**本文件中有观测的 41 行**。丢弃 7 个 NA 后，均值不再代表全部 48 行；
  缺失机制未做检验，若缺失与碳含量系统性相关，均值会有偏。
- 未按 `rain_mm` 筛选或校正：数据中 `rain_mm` 随行号单调递增（300–817 mm），
  被丢弃的 NA 行也呈周期性分布。若研究者关心降水梯度上的条件均值，本结果不适用，
  需要另行分层分析。
- 只报告点估计；未计算标准误、置信区间或显著性检验（契约未要求）。
  样本标准差约 1.062 mg/g，仅作描述，不用于推断。
- 方法适用条件：目标列为单一连续数值变量、单位一致、无重复加权需求；
  这些条件在本文件中成立。算术均值对极端值敏感，但本列范围 12.0–15.6，无明显离群。
- 脚本仅依赖标准库，不创建子进程；输入固定为同目录 `input.csv`，未读取其他文件。

## 5. 复现

```bash
python3 -I results/analysis.py
```

脚本会打印行数、丢弃的站点、n、求和、精确与浮点均值，并重写 `results/result.json`。
