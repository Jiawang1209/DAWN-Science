# 结构化澄清问答实施计划

采用本会话逐项执行；用户已授权建立分支与实施，不另开聊天、不提交或合并。实施在本会话完成；按 requesting-code-review 技能要求安排一次只读独立审查。

目标：API 根会话调用 ask_user_question，用户在输入区卡片回答，答案作为真实工具结果返回，历史可恢复。
架构：协议 schema → 会话问答簿与等待器 → NativeRuntime 工具 → SessionManager/Workbench → QuestionCard。UI 只依赖 protocol。
技术：TypeScript、Zod、TypeBox、React、Vitest、Electron Playwright。
