# agent 浏览器旁观:坞「网页」格收编「agent 的浏览器」(2026-08-25)

> 作者定的(本轮对话):「agent 的浏览器」页签**不新开第六格**,合进坞的「网页」格——
> 一格两子页签。浏览器插件(`2026-08-25-浏览器插件-design.md`)在 `session.ts`
> 留的那个口(`历史`,50 条)在这轮被消费掉。

## 合并合到哪一层(边界,先说清)

**合得了的:共用坞里那一格。** 「网页」格顶上分两个子页签:
「浏览」(现在的,人自己开网页)|「agent」(旁观 agent 那台 headless 浏览器)。
网页预览 spec 里那句「两件事不共用这一栏」拦的是**让 agent 开进人的那块画布**
(共用登录态、抢方向盘);分页签之后表面仍然分开,那条禁令没破。

**合不了的:合成同一块画布。** 两台浏览器是两个进程、两套 Cookie、两个登录态:
人的是 `WebContentsView`(分区 `persist:dawn-web-preview`),agent 的是
playwright 拉起的 headless Chromium,**没有可见表面**,原理上嵌不进界面。
能做的是**旁观**:去过哪儿 + 现在看到什么(`page.screenshot()` 一帧)。

**历史是观察,不是转述**:`page.on("load")` 上记的 URL 是我们这一侧看到的事实,
与 `web_download` 同一性质——`agent的浏览器` spec §4 那条「URL 验不了」的禁令
拦的是模型自述,在这里不适用。

## 一、格内形状

- 子页签行:**「浏览」|「agent」**(文案互不为子串,进设计契约扫描)。
- 「浏览」:原样不动(WebContentsView + 地址栏 + 门)。
- 「agent」:上半是活跃页**截图一帧**(URL + 标题 + 「刷新画面」+ 截帧时刻),
  下半是**去过哪儿**(最近 50 条:时刻 / 标题 / URL)。
- agent 浏览器没开时**不藏页签**(看不见的能力等于不存在),摆空态
  「agent 还没用过浏览器」;开着时页签带活跃点。
- **刷新**:切到页签自动取一帧;可见期间轻轮询状态(~2s,只拿便宜的
  observe);活跃 URL 变了才自动重截;手动按钮常驻。**不做 CDP 投流**——旁观,不直播。
- **点历史条目**:在「浏览」子页签重新访问(复用 `请打开网址`)。措辞诚实:
  提示写「重新访问(你自己的会话,不是 agent 看到的那份)」——不同登录态下
  同一 URL 内容可以不同,两处不许长得一样却是两个东西。

## 二、数据怎么过来(依赖决策:坐哪一层)

agent 的浏览器活在 **workbench 后端进程**(`src/tools/browser/session.ts`
模块级状态);界面在渲染进程。走**现成的 workbench 后端路由**这条缝
(`backend.ts`,与 `listPlugins`/`setPluginFlag` 并排),新增两条:

- `browserObserve` → `{ open, channel, activeUrl, activeTitle, tabs, history }`(便宜,轮询用)
- `browserFrame` → 活跃页 PNG base64(贵,按需调;浏览器没开就明说,不静默回空图)

放弃了:新开 IPC 通道(主进程不认识浏览器插件内部)、历史持久化
(它是旁观面不是账本;重启即清)、多标签逐个旁观(只看活跃页)。

## 三、状态归位

- 子页签选择**不持久化**——「这个窗口此刻的样子」,进坞默认落「浏览」。
- `$待开网址` 动线不变;消息链接点进来**强制落「浏览」子页签**(人点的链接给人看)。

## 四、判据(三条准入规则逐条对)

| 规则 | 怎么满足 |
|---|---|
| 新协议操作补 mock | 同一份假后端补 `browserObserve`/`browserFrame`(假历史 + 定死的假 PNG),`dev:mock` 与 e2e 共用 |
| 可判定规则进扫描 | 「浏览」「agent」入子串扫描名单 |
| 主路径自己验 | 单测:路由形状、没开时的空态回话;`browser-live.test.ts` 加一段:真开一页 → observe 有那条历史、frame 是合法 PNG;e2e(mock):切到 agent 页签看得见假历史与假帧、点历史条目落回「浏览」。**agent 页签是普通 DOM,Playwright 看得见**——比「浏览」页签好验。视觉基线:帧与时刻 mask 掉 |

## 五、不做什么

- CDP 实时投流 / 直播。
- 点截图代操作(要操作让 agent 干)。
- 历史持久化、进账本(账本线由 `web_download` 式观察另走,这轮不动)。
- 多标签逐个旁观。
