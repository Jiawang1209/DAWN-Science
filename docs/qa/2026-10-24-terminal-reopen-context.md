# 终端直接重开与累计用量检查

分支 `codex/terminal-reopen-context`，基线 main `0c96a5e9`。仅本地开发与预览，不合并、不推送、不替换安装版。

## 修复与范围

当前页面本身被终端 Agent 恢复时，关闭最后一个终端会暂停该主会话。旧代码要求主模型活跃才能创建 Normal Shell，用户因而需要先到 GUI 点击重连。

Normal 创建现在检查持久的本地 native 主任务身份、归档状态、项目和 PTY 类型；恢复模型仍走原 ID 的历史恢复。模型控制和执行的活跃校验保持原有路径，单独打开 Normal 不会重启模型。

DAWN 底栏累计输入、输出、缓存读取、命中率直接读取原会话完整分支里的助手用量，包含压缩前记录和工具调用阶段的模型消耗。只读绝对快照，启动恢复、模型用量事件、空闲时更新；较晚返回的旧快照不覆盖较新结果，不额外发模型请求。

未提供字段显示“未提供”。SDK 会把部分缺失字段补为零，历史记录无法确认这些零的来源，故保守显示“未确认”；混合旧缺失/不确定字段的已知正数累计显示 ≥，不计算不完整的命中率。失败/中断的非零用量仍计入；空占位跳过。没有新增费用估算或每轮统计。

## 验证

- 修复前真实 Desktop CLI 传输回归为红：停止原 owner 后创建 Shell 被拒绝；修复后通过。
- 后端回归：原 owner 关闭、停止、重新创建 Shell、按原 ID 恢复；Normal 不隐式启动模型、不取得模型控制权；归档、缺失、PTY、跨项目 owner 拒绝。
- 用量回归：完整分支与压缩、工具用量排除、缺失/零/部分数据、错误/中断非零回执、原 ID 停止恢复、传输作用域、重复快照、迟到回执、快照乱序、统计失败不影响输入。
- Headless 终端验证底栏常驻、38 列折行、`> DAWN` 草稿保持及图片视口。
- `npm run typecheck`：通过。
- `npm test`：483 文件通过，5,126 项通过、10 项跳过。
- `npm run build`：通过，保留现有 Vite chunk-size 提示。
- Electron 扩展终端矩阵：8 文件、39 项通过。SDK 不确定零值的保守显示收尾后重新构建，另跑历史恢复与 CLI 交互两文件全部 11 项通过；当前 owner 用例核对每轮累计 12/8 → 24/16 → 36/24，关闭和 Normal 退出后恢复均不归零、不重复。
- 真实模型预览：使用已有 DeepSeek Flash 配置与保留的“历史恢复试用 · 原图”会话。关闭唯一 DAWN 终端后，未点击 GUI 重连，直接新开 Shell，接续同一会话并显示原图；累计输入 11,317 / 输出 62 / 缓存读取 6,272 / 命中 36% 原样保留。

- 返回 GUI 的原 ID 保持不变、原图可见、输入可用；再次打开原终端、Normal 退出和恢复、点击图片放大通过；再次恢复后累计值仍相同。最终留下一个 DAWN 终端和空的 `> DAWN` 输入，供用户试用。
