# carbon_mg_g 算术均值报告

## 1. 输入

- 数据文件：`input.csv`（唯一数据源，未筛选、未裁剪、未改写）
- 列：`site`, `carbon_mg_g`, `rain_mm`
- 数据总行数（不含表头）：48
- 分析变量：`carbon_mg_g`，分析单位 = 一行一条观测，等权

## 2. 处理

- 方法：算术均值 `mean = Σ x_i / n`（已批准方法，未替换）
- 缺失规则：仅丢弃 `carbon_mg_g` 为空 / `NA` / 不可解析为数值的行（drop NA in target column only）
- 未按 `rain_mm` 筛选任何行；未做填补（无插补、前向填充、零填充）；未剔除极值、未裁剪
- 被排除行数：7（其中 `rain_mm` 缺失与否不影响纳入决定）
- 被排除行明细：plot-1='NA', plot-8='NA', plot-15='NA', plot-22='NA', plot-29='NA', plot-36='NA', plot-43='NA'
- 纳入行数 n：41（= 48 总行 − 7 排除行）
- 数值校验：n 为正整数（n = 41）；mean 通过 `math.isfinite` 有限性断言
- 实现：Python 标准库（`csv`/`json`/`math`），无第三方依赖、无子进程、无后台线程

## 4. 局限

- 单位来源：`mg/g` 来自任务约定与宿主验收规则（并依次与列名 `carbon_mg_g` 字面相符），**不是数据内的独立单位证据**——文件无单位列、无单位元数据行、无测量方法说明。
- 偏态 / 极端值敏感性：算术均值对偏态分布与极端值敏感，当前值域为 12–15.6，本报告不宣称该值是稳健中心趋势估计。
- 缺失机制：按契约直接丢弃目标列 NA（complete-case），未检验缺失是否随机；若缺失与取值相关，均值可能存在偏倚。
- 推断范围：仅为单变量描述统计点估计，无显著性检验、无置信区间、无外推结论。
- 代表性：样本仅 48 行、单一 site 命名序列，无抽样设计信息，不能外推到其他地点或总体。
