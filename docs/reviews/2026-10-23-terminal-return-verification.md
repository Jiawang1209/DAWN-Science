- User-specified design: visible bordered/tinted arrow button; hover and keyboard focus say 返回会话. Existing Button, icon, theme and tooltip primitives reused. No credential/runtime/protocol changes.
- Checks: 114 design/i18n/boundary assertions, typecheck and UI build passed. 13 real Electron cases passed (36.7 seconds). Actual 1280×840 light and 1000×720 dark hover states checked; custom tooltip stays within viewport. Clicking returns to original conversation; draft restoration and PTY survival verified by existing Electron workflows.
- Only the explicit 返回 / 返回会话 pair is exempted from the substring contract, preserving the user's exact wording; terminal tests use scoped exact queries. No scan is bypassed.
- Context: desktop CLI creates an independent native task/session. The return action hides the dock and preserves the original conversation. Opening the CLI task from the sidebar shows its original tool messages and DAWN_CONNECTED response in the graphical conversation (verified in the running preview); automatic navigation to that CLI record is a proposed next slice, not part of this patch.
- Image capability source audit: CLI readline submits text only, tool_end renders text only, no image attachment/inline render path. The native read tool can attach local images when the selected model supports image input; desktop message image handling also exists. The bundled catalog marks deepseek-v4-pro as text input, so a visual model is required for direct image understanding. Generating an image file through tools is distinct from displaying an image inline; this change adds neither image input nor rendering.
- Kept existing preview profile and conversation data; only renderer reloaded. No model requests issued for this visual change. Main, installed application and original credentials unchanged; no merge or push.
