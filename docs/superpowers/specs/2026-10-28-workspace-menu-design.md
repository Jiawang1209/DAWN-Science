# 上下文强调与工作目录菜单

用户指定：上下文用主题色、加粗并适度放大；达到既有预警阈值仍用红色。目录选择参考提供的图片，加入最近会话工作目录，把设置里的默认工作目录固定在最下面，作为新建临时任务的另一个入口。

## 交互

- 上下文从12px改为14px、600字重，正常状态跟随主题强调色；预警和超限仍覆盖为危险色，未知读数保持弱色。默认透明背景，保留通用按钮悬停反馈。
- 本地任务与首页的工作目录入口打开带搜索的弹层，上方显示最近本地会话的文件夹名称，中间提供另选文件夹，底部固定默认工作目录；菜单不展示绝对路径。搜索只筛选最近目录，默认项始终可见。支持键盘、Escape、点击外部关闭；真实路径继续用于选择与搜索，弹层不得越出窗口。
- 默认项指向临时任务模式，不能把默认根目录误注册成普通项目。首页选择它保留草稿并清除待选项目；已有对话选择它回到新建任务页面，原对话和文件保留。真正建会话仍发生在发送首句时。
- 最近目录选择沿用现有规则：临时对话选项目继续原上下文；项目A选择B在B另起对话；同一路径不重复创建。列表按已有任务的会话创建时间排序、去重，排除远端和临时scratch目录。
- 临时落盘沿用现有默认目录下的独立scratch子目录；新会话读取最新设置，旧会话不搬迁。未配置路径时，设置显示已装配scratch根的父目录，保证隔离预览/CLI的显示与实际落点一致，不改变既有落盘根。默认路径读取失败时禁用默认项并显示原因，不能猜路径。远端/只读会话保留现有路径查看方式。
