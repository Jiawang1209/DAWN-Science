# 终端底栏布局与活动统计检查

分支 `codex/terminal-reopen-context`，基线 `f6a21291`。不合并、不推送、不替换安装版。

## 用户确认的布局

- 保留唯一 `> DAWN` 输入。
- 操作提示放在输入框上方；空闲时移除多余“就绪”，生成、权限确认和问题回答各自显示适用提示。
- 累计统计固定在终端最后一行，宽屏居中，窄屏按字符显示宽度折成居中的多行；输入和统计间留一行空白。
- 显示轮数、工具次数及累计实际耗时、输入、输出、缓存和命中率；token 与会话页共用 k/M 格式。
- 12 行及以下去掉额外空白；空闲时收起快捷键提示，生成/权限/提问提示保留，避免短视口裁掉命中率。

## 数据来源

会话页与终端共用纯协议数据统计函数，轮数是 user turn 数，工具是 transcript tool 项。工具耗时优先取转录实际起止时间；应用重开后，按原 session ID 和 tool ID 从原运行账本恢复，不使用消息时间估算、不分页截断。缺失耗时不填零，已知部分显示 ≥。工具次数包含成功、失败、被策略拒绝的真实调用尝试，与会话页口径一致。保留先前 token 未提供/未确认的处理。
