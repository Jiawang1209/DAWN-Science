# 终端会话操作统一

在现有分支继续按用户明确的布局修改：顶栏只提供“搜索历史”和“导出会话”，采用会话页的图标、按钮样式和导出反馈。

- 搜索按钮保持当前终端全文查找；移除“找回输入”按钮及顶部提示。已有 Ctrl+R 输入历史作为键盘操作保留。
- 导出复用现有 exportSession Markdown 接口、目录规则和导出提示，绑定当前终端 Agent 的 sessionId，不能误导出父会话或其他终端。
- 未有 DAWN 会话时按钮保留禁用，并说明进入 DAWN 模式后可导出；Normal 若仍绑定原 DAWN 会话，可导出该会话。
- 导出前重新核对绑定；防重复点击，成功显示路径、失败可重试，切换终端或会话后丢弃迟到提示。
- 补组件和真实 Electron 回归，验证搜索、实际导出文件、恢复会话和切换边界；在最新隔离预览中检查宽窄窗口。不合并、不推送、不替换安装版。
