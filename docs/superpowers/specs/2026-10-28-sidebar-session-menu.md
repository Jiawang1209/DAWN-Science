# 统一侧栏会话菜单

用户确认的范围：所有会话统一使用省略号入口，删除收进菜单；切换项目不改变按钮形态。「工作区」标题加粗。继续在当前独立分支开发，验证并更新隔离预览，不合并、不推送。

原因为侧栏完整会话摘要只覆盖当前项目及临时会话，其余任务行使用直接删除按钮。保留既有摘要加载范围；摘要未到的任务行复用SessionMenu/SessionMenuItems，按原taskId提供删除并走原确认流程，不伪造其余依赖摘要的动作。完整摘要行也补齐菜单的aria-haspopup语义。打开菜单时入口保持可见，Escape恢复焦点。

验证包括：摘要加载范围与当前项目切换、只打开菜单不删除、取消确认不删除、确认后删除原目标而非当前会话、原项目数据保留，以及菜单键盘操作。「工作区」标题使用现有600字重令牌并检查实际渲染。

侧栏尺寸统一：项目分组标题与项目名称均为14px；项目、完整会话和未加载摘要会话的省略号共用Button的row-action尺寸（28×32px），键盘焦点框向内绘制，避免外框显得更大。
