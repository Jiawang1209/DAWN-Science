# 设置分类侧滑详情

用户已明确：各分类内部的内容与排版保持原样，只优化点击分类后的呈现方式，并选择“侧滑进入详情”。基线main为9d867610，分支codex/settings-category-transitions，先提供独立Electron预览，不提交、合并或推送。

右侧栏保留既有标题、返回、展开及关闭入口。分类到详情时，当前详情由右向原位进入；返回分类时，列表由左向原位进入，形成相反方向的导航感。标题和当前内容当帧更新，仅当前页存在于可访问树中。过渡约220ms，横移24px并轻淡入，内容视口裁掉横向位移，滚动仍由原dock-body负责。用户进入详情后焦点落到返回按钮，返回时恢复原分类的焦点及列表滚动位置。

整页模式保留左侧导航原布局，右侧内容约140ms轻淡入。窗口首次显示不额外播放分类切换动画，同一分类的保存、输入、主题更新不重播动画或重新挂载内容。快速切换取消前次动画，直接展示最终所选分类；关闭卸载清理动画。系统减少动态效果时跳过过渡，偏好在动画中改变时立即取消。

共享小型动画hook只处理动效，原设置状态和业务回调保持。动效使用原dawn-ease，不引入外部依赖或全局页面动画；分类表、外观颜色控件、内核路径等均不重排。预览采用独立配置与数据库，不运行真实模型/SSH/解释器。

验证清单：列内进入/返回方向，当前内容立即出现，快速切换取消旧动画，同分类输入状态保留，减少动态效果，键盘返回焦点/列表滚动，整页导航固定；真实Electron亮暗/宽窄及既有设置回归。视觉检查包括动画中间帧与结束帧，确认没有横向溢出、叠页或输入被重置。

用户后续反馈：包住整个设置的最大外框使用与主内容区一致的radius-lg和四边轻描边，作用于分类清单及全部详情。头部与内容底部跟随圆角，外壳本身保留外侧拖宽命中区域；各分类内部不改。

用户后续要求面板默认背景与设置默认背景一致：普通right-dock改用surface-panel，保留亮暗主题默认表面，仅改默认CSS，不新增颜色入口或改写已有配置。自定义设置背景继续限定于设置区域。
