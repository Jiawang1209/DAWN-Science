# 会话终端协助 QA 清单

范围：独立分支 Electron 预览；真实本地 PTY；固定模型驱动工具链。不连接生产配置或服务器。

| 用户可见能力/控件 | 功能核验 | 视觉状态与证据 |
|---|---|---|
| 终端面板、标签、新建和收起 | 原 dock 回归；收起后仍能读取 | 1280×840 原始窗口，终端与主输入区同时可见 |
| 当前程序 shell/Python/R | 真实三类进程续用 cwd/env/PID/变量 | 手动模式可选，交出后锁定选择 |
| 交给当前对话、AI 协助中 | 显式交出前无输入权，跨会话拒绝 | 交出前后标签/按钮清晰 |
| 接回控制、直接键盘输入 | 同进程接回；等待授权的旧写入作废 | 返回手动状态，原终端保留 |
| Ctrl-C | 长任务仅显式中断，之后可继续输入 | AI 状态下可见中断入口 |
| 读取、执行与等待 | 实际文件证据；超时不重发 | 模型请求与终端输出可对应 |
| 窄窗与暗色 | 无主操作遮挡、横向溢出 | 900×700、暗色截图 |
| 原执行边界 | 方案/讨论/权限/内核指令拒绝，远端不提供工具 | 自动化结果记录到核验报告 |

探索场景：收起终端后继续读取；人工有未发送输入时拒绝自动写入；切会话不串；停止对话不杀终端；中断等待授权的旧操作。

上述控件与状态均已覆盖；另通过实际键盘探索程序类型切换、Ctrl-C、接回、收起和重新打开完整周期，原Python变量仍为42。状态与实测结果见同日 verification 文档。截图存放于 artifacts/terminal-assistance/。
