# 输入区分层预览实现计划

**Goal:** 在独立分支提供用户可操作的DAWN输入区预览。

**Architecture:** 复用views.tsx内现有目录和附件动作；用共享输入环境栏承载目录与运行位置，扩展现有附件菜单承载方案与终端，模型/推理/发送与添加/权限位于同卡底栏，上下文位于卡外统计行。仅修改渲染、菜单与主题令牌样式。

**Tech Stack:** React、TypeScript、CSS容器查询、Vitest、Playwright Electron。
