# 子 Agent 长词组记忆检索修复

用户已授权在当前 `codex/child-agent-resources` 实施，不合并、不推送。真实草地案例中，`生物量单位 清洗口径 固定参数 种子 解释器 产物目录` 返回空，单词 `生物量` 则能读取已有记忆。源码以整个 query 调用 includes，确认是字面连续短语要求导致漏检。

选用精确匹配优先、关键词保守召回：先做 NFKC、大小写和空白归一化；精确命中优先。记忆未精确命中时，以运行时内置 Intl.Segmenter 中文分词，移除单字符及少量检索功能词，重复词只计一次；至少两个有效词命中才召回。中文词允许在正文中连续出现，非中文词按分词边界匹配。按有效词命中数、命中字数、原目录顺序稳定排序。空查询沿用目录顺序，先排序再分页。

未选择单词任意命中即召回（泛词噪声过多），也不引入向量库/外部模型（超出本次修复且增加成本）。不承诺同义词、跨语言翻译或语义理解。技能维持归一化后的字面匹配，不扩展为正文搜索。

过滤仍先于检索：只有现有索引中已授权、活动确认、项目/分支可见的记忆参与评分。停用/手动技能、权限拒绝、远端作用域、ID读取门和响应结构不变。正文只在父侧用于检索，目录仍只返回有界短预览。

验收覆盖真实失败长查询、中英混合、标点/空白/全角、精确优先、噪声拒绝、重复词、单关键词兼容、稳定分页、可见范围与完整正文搜索。构建后用真实子进程资源链路及现有真实案例长查询复验；旧查询记录保留，追加新结果。不得改写之前模型失败为成功。
