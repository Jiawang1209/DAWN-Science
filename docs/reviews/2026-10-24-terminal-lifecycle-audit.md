本轮未发现新的终端导航阻断问题，未修改产品代码。新增 5 条 Electron 连续流程回归，初次验收时保留在检查分支；随后经用户授权合并到本地 main，结果见末节。安装版未改动，未推送。

## 实际验证

- 首页与项目会话分别验证：关闭最后一个终端后显示空态，后台列表移除对应 PTY；显式新开获得不同 ID 的新 Shell，旧环境变量没有混入；返回保留原草稿。
- 同一终端连续两次收起、重开，不额外创建进程记录；每次通过拆分 printf 输出标记确认实际收到执行结果，而非只看到命令回显。关闭、返回、刷新后能重新打开终端。
- DAWN 模式返回同一 Agent 会话，重开时仍为原 PTY；关闭最后一个 PTY 后仍能返回原对话。刷新后从侧栏打开该对话，原记录完整可读，并通过 GUI 完成第二轮回复。
- 新建终端后再次进入 DAWN，按现有规格创建新 Agent 会话；新旧记录不混入。首次编写的用例误把新 CLI 当成自动恢复旧会话，已依据现有规格修正这一测试假设，未改变产品语义。
- 关闭当前标签正确选择仍活着的同伴；同伴保留环境，返回后重开仍收到新输出。只剩已结束记录时仍可选中、返回、关闭或显式新开。
- 复验旧 PTY 恢复、最后一个会话关闭回首页、顶部标签排除 PTY、跨目录与刷新重开、已归档/删除目标、无 PTY 配置、定时页收起，以及返回时工具继续执行。
