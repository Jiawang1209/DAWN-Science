## 原有测试失败调查

`tests/env/local-tools.test.ts` 的复合测试要求 Git / Node 的临时 Shell 脚本在2.5秒内返回。单项多次复现 Git 或 Node 被记为超时，而相同脚本在独立 Node 探针中正确返回。临时事件追踪确认正常启动事件在数毫秒内发出，但脚本迟迟没有 exit；对自有探测进程采样显示停在 macOS `_dyld_start`，尚未进入脚本正文。一次追踪中 Node 约902ms返回、Git约2365ms返回，接近原期限；其他轮次超过期限。

将超时边界与失败结果隔离拆成两条测试：前者仍保持2500ms期限、5000ms总耗时断言及真实慢进程；后者允许10000ms测试期限，仍严格断言 Git 的真实报错与 Node 版本。后续全量再次在普通发现测试复现同类启动延迟，因此普通发现/结果断言共用10000ms测试预算；专门验证超时、取消和进程清理的用例维持各自原有期限。产品默认3000ms超时和进程树清理均未修改；临时诊断代码已移除。
