# 数学公式排版

用户已授权：独立分支实现，验证通过后合并本地 main，不推送。

## 方案

在 AgentMarkdown 的既有 Streamdown 渲染层接官方 @streamdown/math 的 createMathPlugin，singleDollarTextMath=true。KaTeX 样式和字体经 Vite 本地打包；不引入 CDN、服务端执行或新的渲染器。相比另建 MathJax 渲染链或自己正则替换公式，这个方案复用既有 Markdown 的代码保护、流式解析和安全边界。

支持 `$…$` 行内公式及独占行 `$$` 包围的独立公式，覆盖分数、上下标、求和、矩阵和中文上下文；金额的字面美元可写 `\$`。代码中的美元和 LaTeX 原样显示。公式插件与现有延迟代码高亮并存；公式错误局部可见，不能让整段消息或应用崩溃。使用共享组件的用户消息、助手消息与 Markdown 文件预览获得同样能力，记录及导出仍保留原始 Markdown。

独立公式在自身容器横向滚动，不能撑宽消息和窄坞；继承主题颜色与对话字号。KaTeX 保持默认不信任 HTML 指令，不为公式放宽 CSP。此项不增加公式编辑器、图片识别、自动纠错或 PDF/Office 公式转换。

## 验收

先用当前组件测试复现无公式 DOM；再验证行内/独立公式的 MathML、代码隔离、流式从不完整到完整、错误恢复及原文不变。真实 Electron 用共享推理夹具发送公式，验证用户与助手消息、Markdown 文件预览、深浅主题、长公式横向滚动、本地字体实际加载、无 CSP 或页面异常，并回归既有 Markdown 用例及视觉基线。保留截图和日志，独立预览必须走既定 launch-preview.sh。
