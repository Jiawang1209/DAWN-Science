# App 底部状态栏验证

分支：`codex/composer-toolbar-order`。不合并、不推送，不替换正式安装。

## 行为

- 30px 底部左侧为当前主区具体模型、R、Python；右侧为启用插件、Skills、MCP、子 Agent 数量和版本。按钮字体12px，无常驻色块，强调色随设置。1050px以下扩展项折叠，版本保留在末尾。
- 模型读取会话切换后的值；ACP 读取适配器模型选项；无会话取首页即将使用的默认配置。详情给出服务/接入方式，配置跳转复用已有设置入口。
- 启动仅新增一次解释器配置读取，不自动扫描环境；检测由用户点击。配置路径不冒充验证通过，检测版本/内核包/错误在详情展示。会话内核状态与所配置路径的检测明确区分，连接错误优先于旧运行状态。
- 远端只读取对应连接的配置及检测；本机/远端和同一机器修改路径时，旧结果均不能覆盖当前状态。配置入口打开本机内核设置或对应服务器编辑框。
- 数量为启用口径；0 与未读取/失败的横线区分。Skills/MCP/子 Agent 按项目隔离，已有名册变更事件刷新计数，无新增轮询。插件为全局。
- 缺 API Key、未连接和操作错误保留在底部状态栏上方，提示可增高/滚动。详情使用不透明主题面板，避免底层文字透出；Escape 恢复入口焦点。
