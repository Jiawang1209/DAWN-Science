# 照着案例分析

**目标不是「讲讲这种分析怎么做」，是让他手上的数据跑出一份有真实案例撑腰的分析。**
案例库里 1565 篇都是跑过、出过图、精修过的代码——**这份技能存在的理由就是「照着跑过的做」，而不是凭印象写**。

整件事分两段，**中间必须停下来等他挑**：

```
第一段：需求 → 检索 → 列出 3–5 个真实案例 → 停
（他说「照第 2 个」）
第二段：读那篇代码 → 看他的数据 → 说清差距 → 在他的数据上写新脚本并跑 → 产物
```

## 什么时候用

- 「我要做转录组 / 差异表达 / 富集 / 生存 / 随机森林 / 聚类…分析，有什么案例」
- 「给我几个 XX 的真实例子」「库里有没有用 R 做 XX 的」
- 他已经看过案例列表，说「照第 N 个做」「就用那篇 DESeq2 的」——直接进第二段

## 什么时候不要用

- **`mlai-science` 那台 MCP 没配**——见第 0 步，要停下说清楚，不要凭印象写分析代码
- 他拿来的是**一张图**说「这种图我也想画」——那是 `figure-like-this`
- 他已经把方法、包、参数都说清了（「用 DESeq2，design = ~ condition，给我火山图」）——直接做，别绕一圈检索
- 他问的是**概念**（「随机森林是什么原理」），不是要在数据上做

## 第 0 步：确认工具在不在

**先看 `mlai-science` 的工具在不在**（`search_cases` / `get_case` / `list_taxonomy` / `recommend_pipeline`）。

**你看到的名字带服务器前缀**：`mlai-science__search_cases`。前缀就是这台在设置里的名字。

不在就**停下来说清楚**：

> 「这件事要 mlai-science 那台 MCP（你的案例库）。它现在没接上，
> 我可以凭经验给你写一段分析代码，但那和照着库里跑过的案例做不是一回事。要我先凭经验写吗？」

**不许悄悄退化成「凭印象写一段」**。

---

## 第一段：需求 → 真实案例 → 停

### ① 把需求对上受控词表

从他的话里抽三样：**任务**、**算法**、**语言**。

**为什么要对上**（实测）：只拿「转录组 差异表达分析」这句话去搜，前六条里混进两篇**纯画火山图的教程**；
加上 `task=["differential_expression"]` 之后五条全是真做差异分析的（DESeq2、DEGseq、EBSeq…）。
**画图教程会冒充分析案例**——对不上任务 id 时要当心这一点。

拿不准 id 就查词表。**注意两边的写法不一样**：

```
list_taxonomy(dimension="tasks")        # 维度名是复数：tasks / algorithms / stages / libraries / figure_types
search_cases(task=[…], algorithm=[…])   # 过滤参数是单数：task / algorithm / stage / library
```

传 `list_taxonomy(dimension="task")` 会回 `unknown dimension 'task'`——那不是库坏了，是少了个 s。

常见的对应（以词表为准）：

| 他说的 | task | algorithm |
|---|---|---|
| 转录组差异表达、DEG、火山图背后的那个分析 | `differential_expression` | |
| GO/KEGG 富集 | `enrichment_analysis` | |
| 生存分析、Cox、KM | `survival` | |
| 随机森林 | 看目标：`classification` / `regression` | `random_forest` |
| 微生物多样性、群落 | `community_diversity` | |

**语言**：会话里已经起了内核，就跟内核走（R 内核 → `language=["r"]`）。他没说、也没有内核时两种都搜，列表里标明语言。

### ② 检索

```
search_cases(query=他的原话, task=[…], algorithm=[…], language=[…], limit=8)
```

机器学习类需求（分类、回归、生存）可以再加一次 `recommend_pipeline(task=…, n_samples=…)`，
它按「预处理 → 特征选择 → 训练 → 评估 → 解释」分阶段给案例——他问「完整流程怎么做」时有用。

**过滤之后是空的**：去掉过滤再搜一次，并**说出来**：

> 「按『差异表达』这个任务过滤没有找到用 Python 的，下面是不过滤的结果，可能混着画图教程。」

**不许把不过滤的结果当成过滤后的结果念出来**——两者在屏幕上长得一模一样。

### ③ 列给他看

挑 3–5 条，每条写四样：

```
2. 191101-R包DESeq2作差异基因分析 · R
   用 DESeq2 做两组差异表达，出 MA 图和火山图。
   http://127.0.0.1:8765/gallery/case/20191101-sxbxy3b71-191101-r-bao-deseq2-zuo-cha-yi-ji-yin-fen-xi
```

- **「它做了什么」那一句用 `task` / `algorithms` / `figure_types` 翻成人话**。
  **有的标题没有信息量**（库里真有一篇就叫 `20221223`）——那时这一句是他唯一能读的说明。
- **链接是图廊页**：他点开会在右侧「网页」格里看到那篇的真图。**不要**用 `get_asset` 把图拉进对话。
  地址是那台 MCP 的地址去掉 `/mcp` 再接 `/gallery/case/<case_id>`；缺省配法是 `http://127.0.0.1:8765`。
  那台是 stdio 起的（没有 HTTP 服务）时没有图廊，**就不给链接**，别编一个打不开的地址。
- 不要编造命中结果里没有的东西（样本量、期刊、结论）。

### ④ 停下

问他挑哪个，然后**结束这一轮**。

> 「你想照哪一篇做？也可以说『都不像』，我换个说法再搜。」

**不许顺手 `get_case`，不许开始写代码。** 挑案例是他的事。

## 第二段：他挑定之后

### ⑤ 读那一篇，只读一次

```
get_case(case_id, figure_limit=0)
```

读 `pipeline`（R 或 Python 全文）与 `notes`。**`get_case` 的体积差两个数量级**：
多数几千字，带几百个数据文件的案例一次回来十几万字（大头是数据清单，`figure_limit=0` 也缩不下来）。
遇到大的就说：

> 「这篇带了 395 个数据文件，清单很长，我只看了它的代码和笔记。」

### ⑥ 先看他的数据

在动手之前弄清：文件在哪、列名、分组（几组、每组几个样本）、数值是 counts 还是已经标准化过的、有没有缺失。
用读文件或 `run_code` 看——**他没说数据在哪就问**，不要猜一个路径。

### ⑦ 说清差距，再动手

用几行说：

- 案例的输入长什么样 / 他的数据长什么样
- 要改哪几处：读入、列名映射、分组、参数
- 案例里有、他的数据上做不了的步骤（比如案例有批次校正、他只有一个批次）

**差得太远就说不适用**，建议回第一段换一篇：

> 「这篇从 counts 矩阵开始，而你给的是已经算好 logFC 的表，照它做要跳过一大半。要不要换一篇从差异表开始画的？」

**不硬套。**

### ⑧ 写一份新脚本，在他的数据上跑

- **是新写的脚本，不是把 pipeline 原样拷进仓库**。开头注释写明：

  ```r
  # 参照案例：191101-R包DESeq2作差异基因分析
  # case_id：20191101-sxbxy3b71-191101-r-bao-deseq2-zuo-cha-yi-ji-yin-fen-xi
  ```

- 放在他的项目里（脚本 `scripts/`，出图 `outputs/figures/`）——按项目已有的目录约定来。
- 用 `run_code` **真跑**，不要只把代码贴给他。
- **跑不通就说哪一步不通**（缺哪个包、哪一列对不上、分组数不同），**不要吞掉报错换一种做法**。
- 跑完说清楚：出了哪几张图、在哪、和案例相比改了什么。

## 不要做的三件

- **不要替他决定统计方法。** 案例用 DESeq2 不等于他的实验设计适合 DESeq2；案例用 `ntree=500` 不等于他该用 500。
  照做可以，**看到疑点先问**（样本太少、没有重复、分组不平衡）。
- **不要 `get_asset` 拉图或拉示例数据。** 图不进对话上下文；示例数据不搬进他的项目——他看图走图廊链接。
- **不要跳过第一段的停顿。** 就算你觉得第一条明显最合适，也列出来让他挑。

## 库是空的怎么办

工具都在、却什么都搜不到时，**先怀疑语料库还没建**（在 MLAI-science 仓库里 `uv run mlai rebuild`），
再怀疑「库里真没有」。两者在屏幕上是同一句「没找到」。
