# 内核设置紧凑排版

用户在关于页验收后要求新开分支检查内核设置，并要求看上一轮建议的实际效果。本轮在 `codex/kernel-settings-review` 实现隔离Electron预览。预览后用户明确认可修改，并授权复核、提交及合并本地main，继续不推送。

保留现有主题色外框，按Python、R上下分组，每组依次呈现语言及配置状态、描边检测按钮、唯一的路径输入及主题色保存按钮、依赖说明。候选结果放在对应语言的路径框下方，选中只填入草稿，保存后才调用原配置动作；直接手填也使用同一输入及保存入口。不另设手填展开区，不重复解释器标题。已配置仅表示已有保存路径，不代表已运行验证。Jupyter注册清单仍折叠保留。

沿用共享InterpreterPicker，新增仅设置页使用的编辑布局，首启向导和远程解释器选择默认行为保持。后端、协议、包安装和运行逻辑不变；未改动的保存键禁用，检测期间禁用重复检测，检测失败显示原话。路径、候选长文本可换行；窄栏动作可换行，无横向溢出。

验收包括候选不提前保存、手填保存、当前值回写、无探测入口的回退、失败信息及原选择器回归；类型、构建、相关单测；真实Electron隔离预览的亮暗、整页与最窄侧栏。预览不修改生产配置、不启动Python/R内核、不连接真实服务器。
