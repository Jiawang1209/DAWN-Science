# 侧边代码编辑器：实现与验证

日期：2026-11-15

分支：`codex/ide-capability-research`；功能开发基线：`9d451ec5`。

## 已实现行为

- 原会话与输入框保持原位。从完整对话代码块的“在旁边编辑”或脚本预览的“编辑脚本”按需打开侧边编辑器；生成尚未完成的代码块暂不能编辑。
- 按需加载 CodeMirror 6，提供行号、Python/R 语法高亮、缩进、撤销和查找；未另加全局工作模式或常驻文件树、变量面板。
- 代码进入独立草稿，历史消息不被改写。关闭、重开或切换会话后保留同一窗口内的草稿和选区。进入另一会话时隐藏不属于它的编辑区。
- 保存使用真实读写。新草稿填写工作区内相对路径，以创建新文件的语义保存；已有文件使用 SHA256 内容版本检查和临时文件提交，拒绝静默覆盖外部修改。冲突时保留草稿，可明确选择放弃草稿并重读磁盘版本。
- 完整读取和保存上限为 1 MiB，接受有效 UTF-8 文本，不把截断预览、二进制或非法编码当作完整脚本保存。
- 无选区运行整份草稿，有选区仅运行选中的原文；按钮与 `⌘/Ctrl+Enter` 使用同一路径，保存快捷键为 `⌘/Ctrl+S`。运行不隐式保存。
- 原生会话复用现有 R/Python 会话内核，按实际返回的 cell ID 展示真实输出、失败或中断。其他会话或语言仍可编辑、保存，界面明确说明运行边界，不将 Shell 代码送入 Python。
- 结果默认收起，运行后展开；后续编辑显示旧结果待更新。选区可带着文件与行范围进入原会话输入框，由用户补充要求后发送，不额外创建 AI 会话或自动调用模型。

## 测试与现场证据

- `npm run typecheck`、`npm run build` 通过。
- `npx vitest run tests/ui --maxWorkers=4`：226 个文件，2155 条测试通过。
- 最终针对性回归覆盖协议、文件系统、SSH/SFTP、编辑器状态、UI、后端、IPC 与设计契约：13 个文件，325 条测试通过。与整组 UI 测试有重叠，不将次数相加。
- `npx playwright test e2e/code-editor.spec.ts --reporter=line`：3 条真实 Electron 验收通过，无跳过。

Electron 验收覆盖：

1. 从对话代码打开编辑区；实际保存至文件、再次保存和快捷键保存；关闭再开保留草稿；外部修改导致冲突且不覆盖；明确重读后显示磁盘内容；从文件预览打开已有脚本并实际保存。
2. 本机真实 Python 内核中用快捷键运行全文，定义 `shared_value = 41`，输出 `42`；随后编辑为首行抛异常、第二行输出 `shared_value + 2`，只选中第二行运行，得到 `43`，证明提交的是选区原文并复用了同一内核。选区还能带回原输入框。
3. 切到另一会话时隐藏原编辑区；返回原会话再次打开，人工修改草稿仍在。

查看了浅色、深色和 1000×740 窗口截图。窄窗口下聊天输入、保存按钮可见，没有外层横向溢出。证据位于 `output/playwright/code-editor/`：`side-editor-light.png`、`side-editor-dark.png`、`side-editor-narrow.png`、`selection-execution.png`。

## 审查与修正

独立规格审查和质量审查均已完成，发现的问题均补充回归后修正：绝对文件路径被旧交付路径校验错误拒绝；文件刷新后编辑器显示与待执行文本不同步；延迟读取覆盖新保存版本；临时文件独占创建失败后的错误清理；旧文档的重读或中断错误落到新文档。保存、运行捕获所属文档与会话；显式重读校验读取期间没有修改或保存。

## 验证边界

模型回复使用隔离的本地假服务，没有真实云调用；Python 执行使用真实本机内核。R 的语言路由及已有内核通道由自动化覆盖，本次没有另行声称 R 端到端现场运行结果。

SSH loopback 验证了 700 KB 文本新建与完整读回、冲突保护及不支持原子覆盖时保持原文件。远端已有文件覆盖需要服务器提供 `posix-rename@openssh.com`；不支持时明确报错，不回退为删除后覆盖。没有使用用户生产服务器验证。

版本检查属于乐观并发保护，无法保证任意外部写入者在最终比较与重命名瞬间不存在竞争。未保存草稿属于当前应用窗口，不承诺跨应用重启恢复。

构建的 direct-eval 与大分片提示、UI 测试中的 jsdom canvas 提示、Electron 夹具重载的加载取消提示均保留在输出中。没有据此声称发布打包或生产环境已验证。本轮只提交指定分支，不合并 main 或推送。
