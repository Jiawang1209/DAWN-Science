# SSH 启动期取消

用户已授权逐项修复并在每项验证后合入本地 main。F2 已完成主目录复验，本切片只处理 F3 连接生命周期。

根因：RemoteExecutor 到 ready 后才登记 client，close 无法结束握手对象；RemoteConnections 只记已创建执行器，私钥读取期间无法使本次尝试失效，旧完成/清理还能覆盖新尝试。

采用每次连接尝试的独立身份与取消出口：从启动即登记客户端，握手和环境捕获均能取消；事件只影响所属尝试。关闭先使尝试失效、清空所有权，再关闭客户端；迟到 ready/error/close 不改变后继连接。环境捕获结果只有当前尝试能提交。

管理器同时管理启动期和已连接资源；私钥尚未读取完也能立即取消，并在读取晚到后阻止创建客户端；断开后立即重连必须获得新尝试，旧 finally 不能删新 pending。closeAll 包括私钥读取期。主动断开保持 idle，对端握手失败/关闭保持 disconnected 并说明原因；不自动重连。

验收覆盖握手断开、迟到 ready/error/close、私钥读取期取消、立即重连与旧清理、环境捕获期取消及断开/失败正常路径。真实 Electron 用共用假 SSH 的可控延迟走连接/断开/重连，区分真实 UI/生命周期与真实服务器未验收边界。无协议和 UI 设计变更。
