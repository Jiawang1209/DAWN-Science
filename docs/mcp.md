# MCP 调用与连接恢复

DAWN 支持本机 stdio、远端 Streamable HTTP 和旧式 SSE。配置、密钥和信任开关仍在设置里的「MCP 服务器」管理。

## 返回内容与错误

MCP 返回的文本、`structuredContent`、资源链接和嵌入资源文本会进入 Agent 上下文。资源链接只作为引用，不会自动下载；嵌入二进制资源和 App 专用 `_meta` 不进入模型上下文。显式标记为仅面向用户的内容也不会发送给模型。

PNG、JPEG、GIF、WebP 图片在校验后作为图片内容交给支持图像的模型。每次结果最多包含 8 张图片，每张原始图片最多 5 MiB，总图片字节预算为 20 MiB。超过 4000 万像素、格式无效或无法解码的图片会被明确标记为未送入模型、未进行视觉检查。宽或高超过 2048 像素时，生成缩放后的模型副本并说明细节损失；MCP 层保留的原始结果不被修改。

服务器返回的 `isError` 会保留到工具状态、对话记录和续接历史。包含图片或部分有效输出的结果仍可能是失败；应同时阅读其中的错误与结构化回执。

## 长调用与停止

普通 `tools/call` 没有默认执行期限，不再沿用 SDK 的 60 秒默认请求超时。初始化、工具发现和关闭连接仍有技术超时。服务器内部或其上游服务自行设置的超时仍可能终止操作；DAWN 不会覆盖它们。

点击对话的「停止」会取消当前请求的等待，并尽力向服务器发送 MCP 取消通知。停止一个请求不会关闭其他对话共用的 MCP 服务器，也不会取消其他请求。HTTP 调用的响应流会单独释放，避免服务器忽略取消后留下持续占用的读取。

在等待权限或共享初始化期间取消，请求不会发出。初始化本身可能继续，供其他等待者使用。已发出的请求被取消或丢失响应时，DAWN 会报告「外部结果未知」：取消通知不代表外部写入、发布或计算已经停止或回滚。先检查外部状态或回执，再决定是否发起新的操作。

## 断线恢复

连接关闭、发送失败或响应流异常结束后，该连接不再作为可用连接缓存。下一次使用时重新连接并发现工具；并发等待者共用一次初始化。DAWN 不会因为恢复连接而自动重放已发送的调用。

服务器显式提供 SSE 事件 ID 后正常关闭响应流时，允许通过 GET 续取同一请求的响应，保持 SDK 的响应续传能力，不重新发送 `tools/call`。续取同样受原请求的取消信号控制；相同事件 ID 下连续两次续取仍无进展就报告结果未知。没有可续传事件 ID 且响应流已结束却缺少结果时，直接报告结果未知。

重连后工具参数或只读声明发生变化，旧会话的该工具会拒绝发送请求，并提示新建会话重新加载，避免沿用过期的工具与权限声明。

修改密钥、停用或移除服务器会关闭其已有目录范围的连接。配置或凭证发生变化时，不复用旧连接。关闭初始化、替换连接或退出应用后，晚到的初始化结果不能重新进入缓存，也不能覆盖更新的连接。

设置页的状态来自实际连接缓存；打开设置不会启动 MCP 进程。「还没试过」与连接失败分开显示。按「试一次」会关闭所选连接后重新初始化；它只测试连接和发现工具，不重放此前的调用。

## 验证范围

本地回归使用 SDK 配对传输、真实 stdio 子进程、状态化 loopback HTTP/SSE 服务和离线模型替身，覆盖富结果、错误持久化、超过 60 秒的虚拟时间等待、取消隔离、响应流截断、会话丢失、写入不重放及关闭竞态。没有使用真实 API 密钥或执行外部写操作。真实服务及 Windows/Linux 安装包仍需要各自验收。
