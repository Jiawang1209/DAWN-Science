## 原因与修复

用户原会话中四次成功检索返回分别为 21,413、25,023、22,525、2,810 字节。前三次超过 16 KiB，实时转录正文被截成头尾摘要，卡片解析 JSON 失败；剩下一次虽能解析，但正文未写可匹配的完整 ID 或唯一长 ID 前缀，实时结果为 0 张卡。

DAWN 在 `native.ts` 截断前用共享的 `src/cases/results.ts` 提取精简字段，独立以 `caseResults` 随工具事件、快照和增量传递。仅保留 ID、标题、语言、一句话和封面路径，不复制 notes、代码或图片数据。工具正文的 16 KiB 预算、全文落盘和截断提示保持。历史恢复从完整 pi 记录重建相同字段，包含没有对应调用的旧结果条目；旧前端条目仍可解析完整 JSON。协议可选字段升为 8.17，无新操作、依赖或数据库迁移。

前端在同一轮查询结果中识别完整 ID、唯一长 ID 前缀和唯一标题。标题允许去掉库名及明确的 ggNetView 系列包装，忽略空白与大小写；同名标题、短词、仅日期、任意改写不猜。长标题内包含另一篇短标题时只匹配长标题；短标题另行出现时可匹配。按照正文首次提及排序并去重。

原会话完整结果与原回复的离线回放：49 个不同案例 ID，修复后精准匹配 13 张卡。不是 40 张全部匹配；模型随意改写的标题仍可能无法识别，应使用原题或完整 ID。此回放验证解析与匹配，未向真实模型重新发请求，也未改写用户原会话。
