- 分支：`codex/fix-case-card-mcp-content`，基于 `main` / `e8047e6e`。
- 范围：本地代码和验证；不替换安装版，不修改 MLAI 服务、用户会话或配置。

## 原因与行为

本次基因家族会话的四次成功检索，每次都有两个文本块：`[mlai-science]` 后的 JSON 数组，以及 `MCP structuredContent: {"result":[...]}`。此前实时事件与历史恢复先拼接文本，再将其作为单份 JSON 提取案例；拼接后的内容无法解析，导致独立的 `caseResults` 缺失。正文中的案例编号仍能被模型写成表格，但卡片没有数据。

共享提取器现在逐块解析，识别服务器前缀及结构化内容标签，按案例 ID 合并、去重、补齐字段。坏块与非文本块不影响有效块。实时事件在输出预算截断前提取，历史恢复在文本拼接前提取；旧的单字符串入口保留。原始输出、16 KiB 预算、全文落盘、协议结构及图廊行为不变。

后续轮次没有新的案例数据时，允许复用本会话此前工具查到的案例；仍必须在当前回复中明确提及 ID、唯一前缀或唯一标题。当前轮有案例数据时优先用当前轮，历史同名标题不猜，不引用未来结果，也不从模型文字生成候选。

原始会话只读离线回放：四次检索各恢复 20 个案例，首轮回复匹配 18 张卡，后续“展示卡片”回复匹配 8 张卡。回放没有重新请求真实模型，也没有改写原记录。
