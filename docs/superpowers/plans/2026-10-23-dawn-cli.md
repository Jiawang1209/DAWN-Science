# DAWN CLI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline in the existing isolated worktree. No delegation.

**Goal:** 输入 dawn 使用 DAWN Agent，退出回原 Shell；桌面内置终端与外部终端共用入口。

**Architecture:** Node CLI → createWorkbench → 原有 NativeRuntime / 工具 / 权限 / 事件。readline 负责单一输入；CLI 每次运行独立建库；桌面终端只承载真实 PTY。

**Tech Stack:** TypeScript、Node readline、现有工作台协议、esbuild、node-pty、Playwright Electron。

- [x] 在 `tests/cli/agent.test.ts` 加真实 CLI 管道与 PTY 用例，验证构建后的入口、Shell 返回、工具文件、权限、中断、问答、错误/EOF；先运行缺失入口的失败。
- [x] 新增 `src/cli/agent.ts`（运行/生命周期/输入），`src/cli/context.ts`（独立工作台及环境凭证），`src/cli/presentation.ts`（干净文本/工具/提示）；不复制 Agent 核心。
- [x] `src/cli.ts` 默认 Agent、native run 走同入口；保留旧辅助命令及 --help。新增 `bin/dawn`、`scripts/build-cli.mjs`、package bin 与 build:cli，构建完整串联。
- [x] 删除 `src/ui/terminal-assistant.tsx` 及专用测试，移除 App 的重复消息入口；`src/ui/dock.tsx` 整页承载原 xterm，原对话保持挂载但隐藏；保持关闭/项目隔离等原终端能力。
- [x] 更新 Electron 终端回归，单一输入与真实 CLI、Normal/Agent 往返、窄窗、生命周期；跑类型检查、针对性单元/协议/i18n/设计检查、构建、相关 Electron 回归。
- [x] 依据 QA 清单检查真实隔离预览和截图；跑完整单元回归与 diff 检查，更新设计/历史/验证记录，保留实际预览打开。
