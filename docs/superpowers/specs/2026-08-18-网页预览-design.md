## 一、用什么渲染：**`WebContentsView`**

量出来的三条：

| 事实 | 值 |
|---|---|
| 我们的 CSP | `default-src 'none'`，**`frame-src` 只放了 `blob:`**（给 PDF 预览），且 `e2e/csp.spec.ts` 盯着它的形状 |
| Electron | 43（`WebContentsView` 从 30 起就有） |
| 现有用量 | **零处** `webview` / `WebContentsView` / `BrowserView` |

| 做法 | 要动 CSP 吗 | 主要代价 |
|---|---|---|
| `<iframe>` | **要**。得把 `frame-src` 放到 `http:` / `https:`——那是**整个窗口**的 CSP | 而且换不来什么：大量站点用 `X-Frame-Options` / `frame-ancestors` 直接拒绝被嵌 |
| `<webview>` | 不用 | 要开 `webviewTag`，Electron 官方明确不推荐 |
| **`WebContentsView`** | **不用**——它是独立的 web contents，不受渲染进程 CSP 管 | 见第二节 |

**拿全应用的 CSP 去换一个面板，还换不到大多数站点**——这条自己就把 iframe 排除了。

## 二、spike：跑通了，也撞出一条只有跑起来才知道的事

一次性探针（Electron 43，独立脚本，**不在 `src/` 里**）：

```
✅ 装上了：标题=探针页 url=http://127.0.0.1:50525/
✅ 自己的分区：拿到了（persist:dawn-web-preview）
✅ setBounds 改成 600 宽，没抛
✅ will-navigate / setWindowOpenHandler 都挂得上   ← 守卫的着力点在这儿
```

**而窗口自己的 `capturePage()` 截不到它**——截图上右边那一栏是**一片空白**。

这一条要写死在这里，因为它决定了这块东西**怎么验**：

- **Playwright 看不见它。** 它不是 DOM，不是 window；`page.locator(...)` 一个都命不中。
- **十张视觉基线也看不见它**——好消息是它因此**不会**把基线搞红；坏消息是
  「这块白的对不对」基线一个字都不会说。
- **能验的路子**：e2e 夹具手里有 `app: ElectronApplication`，
  用 `app.evaluate(...)` 进主进程问那个 view 的 `getURL()` / `getTitle()`，
  或者调**它自己的** `webContents.capturePage()`。
  **判据必须走这条**，不能靠 DOM 断言——那样会「绿得毫无意义」。

## 三、它浮在 DOM 之上，位置得我们自己算

`contentView` 的子视图永远盖在 DOM 上面。于是：

- 坞的宽度可拖 → 每次拖动都要 `setBounds`
- 左半切屏、坞收起、窗口缩放、全屏 → 都要跟
- **命令面板、确认框、下拉菜单会被它盖住**——这是最容易漏的一条：
  那些浮层的 `z-index` 对它**完全无效**。
  处置：**有模态浮层时把它藏起来**（`setVisible(false)`），关掉再显回来。
  藏比重排简单，而且不会有半透明遮罩压不住它的怪相。

## 四、安全：先本机，再任意

作者定的是「先本机的东西，其次任意网站」。**这两期的安全面不一样，分开写。**

### 批 1 · 只认本机

放行：`http://localhost` / `http://127.0.0.1`（任意端口）、
以及**工作区内**的 `file:`（走已有的 `files/access.ts` 路径守卫，不另开一套）。

其余一律**不在这儿开**，而是提示「用系统浏览器打开」——
**响亮拒绝，不静默跳回去**（与远端路径框那条同一个规矩）。

这一期几乎没有凭据问题：本机自家页面，独立分区里本来也没有 cookie。

### 批 2 · 任意网站（**开工前要单独确认**）

那时必须一起答掉，一条都不能拖：

| 问题 | 缺省 |
|---|---|
| cookie / 登录态 | **独立 `persist:` 分区**，与系统浏览器、与 agent 那台**都不共用** |
| 新窗口 / 弹窗 | `setWindowOpenHandler` → **`deny`**，改成在同一栏里导航或交给系统浏览器 |
| 下载 | 走**设置里那个下载目录**（②，已经做完了），不另起一套 |
| 证书错误 | **不许静默忽略**。说清是哪个域、什么错 |
| 权限请求（摄像头 / 位置 / 通知） | **一律拒**，第一版不摆一个假的授权流程 |
| 混合内容、`file:` 越权 | 沙箱 + `contextIsolation` + 不给任何 preload |

> **✅ 2026-08-18 做完了**（作者说「继续」）。上面这张表逐条落实，
> 另外两条是做的时候才想清楚的：
>
> - **弹窗从「一律 deny」改成「在同一栏里导航过去」**。批 1 时 deny 是对的
>   （只开本机的东西，`target=_blank` 罕见）；放开任意网站之后，
>   deny 会让人**点了没反应**，而那与「这个功能坏了」在屏幕上长得一模一样。
> - **下载一定要给一个落点**。不给的话 Electron 会弹一个**原生保存对话框**
>   ——那是我们完全没设计过的模态框，窗口 `show: false` 时它甚至看不见。
>   取不到配置就用兜底，**不猜路径**；重名改名不覆盖（与 SFTP 那条同一条规矩）。
>
> **门那一层还多了一条**：人没写协议、那一串又不像主机名时（`这不是一个地址`），
> 说它「不像一个地址」。批 1 不需要这条——那时主机名不是 `localhost` 就直接拦了。

## 五、入口：三个，且都看得见

1. **消息里的链接**——今天是 `<a target="_blank">`，而 `src/electron/` 里
   **没有 `setWindowOpenHandler`**：点下去到底发生什么**我没验过**，
   批 1 第一件事就是查清楚它（现在很可能是新开一个 Electron 窗口，那要改掉）。
2. **卡片**——像截图那样，链接下面一张「网页预览」卡，带「打开方式 ▾」。
3. **地址栏**——坞里那一格顶上，输 URL 回车就走。

> **「打开方式」两个选项的文案不许互为子串**（设计契约那条扫描）。
> 「在这儿打开」/「用系统浏览器打开」——后者包含「打开」，前者也包含，
> 但**两者互不包含**，可以。落地时用扫描确认，别靠眼看。

**「看不见的能力等于不存在」**：地址栏与卡片都是常驻的，
不做「悬停才出现」的入口（这个项目为它栽过两次）。

## 六、不做什么

- **不做多标签页**（Codex 有；我们先一个）。要开第二个就换掉当前这个。
- **不做书签、历史、下载管理器**——那是往「做一个浏览器」滑。
- **不给 agent 用**。那是另一份 spec，走 MCP。**两件事不共用这一栏**。
- **不动 CSP。** 这是选 `WebContentsView` 的全部理由，别在实现里又绕回去。
- **不做阅读模式 / 广告拦截**。

## 八、怎么验（逐条对着第二节那个发现）

| 判据 | 怎么做 |
|---|---|
| 那个页面真的加载了 | `app.evaluate` 进主进程读 `getURL()` / `getTitle()`——**不是 DOM 断言** |
| 它真的在坞那一栏里 | 读 `getBounds()`，与坞的宽度对得上；坞拖宽之后再读一次 |
| 模态浮层不会被盖住 | 开命令面板，断言它 `setVisible(false)` 了 |
| ~~非本机地址被拦下~~ → **外网真的放行了** | 批 3 之后这条反过来了：断言输一个 `https://example.com` 之后**真的建出了 view**（在那之前门直接拒，一个 view 都不会有——所以「有 view」本身就是判据）。而**工作目录外的 `file:` 仍然要被拦下并说清为什么** |
| 坞切到别的房客 | 断言它藏起来了，且**没有被销毁**（切回来还是那一页） |
| 视觉基线 | **它不进逐像素基线**（截不到）。这一条写在这里，免得下一个人以为漏了 |
