# 笔记本：坞里一格看 agent 的内核、同一台内核里自己敲 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 坞新房客「笔记本」：把对话挂着的 Python / R 内核跑过的每个 cell（代码 + 富输出）按时间线列出来；你能在同一台内核里敲一句；你敲的记进对话，下一轮随上下文告诉模型。

**Architecture:** cell 从对话转录派生（agent 的 = `tool` 项 `run_code` + 紧随其后的 `kernelOutput`；你的 = 新转录项 `cell`）。后端新操作 `runInKernel` 走与 `run_code` 同一台内核（`对话内核.执行`），`interruptKernel` 走内核运行时的 `abort(<对话>::<语言>)`。内核状态由 `挂载.ts` 从内核事件里跟踪，经中枢推 `kernels` 更新。「告诉 agent」= 后端每会话一段缓冲，在 `writeToSession` 里拼进 `发出去的`（模型看的），转录不变。

**Tech Stack:** TypeScript / zod 协议 / nanostores / React / vitest / Playwright（真内核用例本机有 kernelspec 才跑）。

**Spec:** `docs/superpowers/specs/2026-08-26-笔记本-design.md`。**分支 `notebook`**（从 `data-platform` 开）。

```ts
/** 你在内核里敲了一段（笔记本）。返回 cell id；pty/cli 没有内核，返回 undefined */
beginCell(sessionId: SessionId, language: "python" | "R", code: string): string | undefined {
  const e = this.entries.get(sessionId)
  if (!e || e.kind !== "native") return undefined
  const id = `cell-${++e.turnSeq}`
  this.putItem(sessionId, e, { type: "cell", id, language, code, status: "running", startedAt: this.now() })
  return id
}
finishCell(sessionId: SessionId, id: string, 结果: { status: "ok" | "error"; runId?: string }): void {
  const e = this.entries.get(sessionId); const it = e?.items.find((i) => i.id === id)
  if (!e || !it || it.type !== "cell") return
  this.putItem(sessionId, e, { ...it, status: 结果.status, endedAt: this.now(), ...(结果.runId ? { runId: 结果.runId } : {}) })
}
/** 对话挂着的内核变了：整份换掉（与 team 同一纪律） */
setKernels(sessionId: SessionId, kernels: KernelState[]): void {
  const e = this.entries.get(sessionId); if (!e) return
  e.kernels = kernels
  this.bump(sessionId, e, { type: "kernels", kernels })
}
```

```ts
runInKernel: async ({ sessionId, language, code }) => {
  const k = opts.kernels
  if (!k) throw fault("internal_error", "这台没有接对话内核")
  const cellId = events.beginCell(sessionId, language, code)
  if (!cellId) throw fault("invalid_request", "这种会话没有内核，笔记本不可用")
  let 输出: unknown[] = []; let 出错了 = false; let 原因: string | undefined
  try {
    const r = await k.执行(sessionId, language, code)
    输出 = r.输出
    const s = 摘要(输出); 出错了 = s.出错了
    if (出错了) 原因 = 首个错误的ename_evalue(输出)   // 从 entry.kind === "error" 取 `${ename}: ${evalue}`
    const runId = runRecorder?.记内核执行(sessionId, language, { hasError: 出错了, ...(原因 ? { terminalReason: 原因 } : {}) })
    events.finishCell(sessionId, cellId, { status: 出错了 ? "error" : "ok", ...(runId ? { runId } : {}) })
    const 语言名 = language === "R" ? "R" : "Python"
    const 列 = 不在场缓冲.get(sessionId) ?? []
    列.push(`[用户在 ${语言名} 内核里跑了]\n\`\`\`${language === "R" ? "r" : "python"}\n${code}\n\`\`\`\n输出：${s.文字}`)
    不在场缓冲.set(sessionId, 列)
    return { cellId }
  } catch (err) {
    const 消息 = err instanceof Error ? err.message : String(err)
    runRecorder?.记内核执行(sessionId, language, { hasError: true, terminalReason: 消息 })
    events.finishCell(sessionId, cellId, { status: "error" })
```
