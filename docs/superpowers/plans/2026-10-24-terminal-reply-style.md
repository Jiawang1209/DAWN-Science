# 终端回复呈现与自然表达

用户已确认同时优化排版、工具摘要与语气。沿用 `codex/terminal-reopen-context`，基线 `0079aae8`；不合并、不推送、不替换安装版。

设计（含用户明确纠正）：历史问题仅用 `❯ 问题` 引导，不出现“你”或“你：”身份标签；助手正文前放轻量圆点，不逐轮占一行重复品牌。Markdown、代码、表格、图片、复制、流式输出和单一 `> DAWN` 输入保持可用。成功工具默认单行展示动作与简短参数，Tab 展开原命令和原输出；错误始终展开，截断与完整输出位置明确保留。

回复指引按每次输入的来源生效：终端发送用自然、简洁、先回答结果的风格；复杂工作给必要进展，技术细节按用户需要展开；不机械复述工具输出、不强制标题、不编造执行结果。内部来源上下文只传到原运行时，不增加公开协议字段、不改变用户消息。模型身份始终取当前实际配置，允许用自然语言回答；从 GUI 继续发送时恢复原指引，排队消息保留自身来源，不改权限、模型或历史正文。

参考：OpenAI 官方 Codex Prompting Guide 的 CLI 正文与语气建议；Claude Code 官方 Output styles 的结果优先与精简表达。本项目仅实现适合自身交互的规则，不复制产品身份或预设模型。
