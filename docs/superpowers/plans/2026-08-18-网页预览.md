## 硬性纪律（每一批都适用）

1. **不 push。** 只在本地提交（全局约定）。
2. **每批自己能验、能停。** 打勾之前必须真的跑过判据，不是「应该能行」。
3. **判据不许靠 DOM 断言。** `WebContentsView` 截不到、也定位不到——
   走 `app.evaluate` 进主进程（设计文档第二节，spike 实测）。
4. **新增协议操作 = 同一次改动补 mock**（准入规则 1）。
5. **改了主路径自己验一次**（准入规则 3）：`npm test` 绿不等于能用。
6. 每批完成后：更新本文件的勾、写 `DEVELOPMENT_HISTORY` 条目、提交、回填 hash。

## 批 1 · 坞里第三格「网页」（只认本机）

- [x] `坞房客` 加 `"web"`；菜单、快捷键、持久化跟着走
- [x] 主进程：`WebContentsView`（独立 `persist:` 分区、sandbox、无 preload）
- [x] 位置跟随：坞宽变化 / 窗口缩放 / 全屏 / 坞收起 / 切房客
- [x] **有模态浮层时藏起来**（命令面板、确认框——`z-index` 对它无效）
- [x] 地址栏：输 URL 回车就走；**只认 `localhost` / `127.0.0.1` / 工作区内 `file:`**
- [x] 越界响亮拒绝并说清为什么，**不静默跳回去**
- [x] 判据（全部走 `app.evaluate`）：加载成功 / bounds 跟着坞走 / 模态时隐藏 /
      越界被拦且屏幕上说了 / 切走再切回还是那一页（没被销毁）
