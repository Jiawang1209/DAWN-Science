# CLI / 原生终端 QA 清单

批准交互：Normal 为原 Shell，`dawn` 启动 Agent，`/exit` 返回。所有预览使用独立配置、假凭证与固定模型；实际命令、文件与进程为真。

| 可见行为 / 控件 | 功能验证 | 视觉状态 / 证据 |
|---|---|---|
| 命令入口 | bin/dawn --help；真实 Shell 输入 dawn | Agent 欢迎、模型、目录、单行输入 |
| 自由对话 | 固定模型普通回答，不调用工具 | 一份回复、单一提示符 |
| 工具过程 | 实际工具写文件，核对 cwd/env 和输出 | 工具名、命令、完成状态及结果 |
| 权限选项 | 输入 y / n / 数字经既有 answerPermission；管道拒绝 | 权限说明与当前选项，不重复输入框 |
| 结构化问题 | 数字选择经 answerQuestion | 问题、选项、当前回答提示 |
| Ctrl-C | 中断真实 sleep，下一轮可继续 | 停止结果、恢复 Agent 输入 |
| /exit / EOF | 退出回原 Shell，PID/cwd/env/stty 一致 | 原 Shell 提示符和可输入状态 |
| 终端工作区 | 真实 xterm 占满主区，聊天输入不可见 | 1280×840 与 900×700，明暗主题 |
| 返回对话 / 再打开 | 原草稿保留，PTY 不重启 | 只有一份原聊天框、没有小聊天组件 |
| 新建 / 关闭 / exit | 原终端生命周期回归 | 标签、结束状态、无终端空态 |
| 缺凭证 / 模型出错 | 失败状态清楚，恢复输入，不留下原始模式 | 清楚的错误说明 |
| 数据隔离 | CLI 独立数据库，不修改桌面 sentinel；双 CLI 可并行 | 记录目录可由 /status 查看 |

额外探索：执行期间退出；权限未决时 Ctrl-C；长/带空格的目录；工具文本含转义序列；输入过快与非交互 EOF。检查工具输出不会作为终端控制序列执行，退出不把 Agent 输入遗留给 Shell。
