# 终端底栏模型与上下文

用户明确要求沿用会话页的上下文长度读数，并在累计 token 栏最前显示接入模型、最后显示上下文。继续当前隔离分支，不合并、不推送、不替换安装版。

采用 CLI 用量快照扩展，不改变累计 token 定义：`context` 来自同一 nativeRuntime.contextUsage，复用当前模型、usedTokens、contextWindow、estimated、afterCompaction。独立 CLI 与桌面接入共用这份快照。新进入、恢复、轮次用量、工具、模型变更及压缩完成时刷新；晚回包不得覆盖新快照。

显示顺序：当前模型 → 轮数/工具/累计用量/命中率 → 上下文 已用/上限（百分比）。估算标“约”，首次未知标“未采集”，刚压缩标“已压缩”，未知上限不算百分比。保留居中和按字段换行；短视口去掉上方重复的模型与目录，优先保留单一输入和完整底栏。
