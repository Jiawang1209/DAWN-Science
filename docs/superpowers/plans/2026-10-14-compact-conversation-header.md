# 紧凑会话顶栏实施计划

**Goal:** 会话标题位于应用顶部，与侧栏折叠按钮的垂直中心对齐，16px、500 字重、单行省略。

**Architecture:** App 提供顶栏插槽，主 ConversationView 用 React portal 放入现有会话头，保留搜索、导出、会话类型、远端目录和状态。累计用量单独留在对话内容上方；侧边会话不使用顶栏插槽。导航组保留品牌和三个按钮的原顺序、8px 间距，顶栏插槽随侧栏宽度让位。

**Tech Stack:** React、现有 CSS 令牌、Electron / Playwright。

- [x] 新增 Electron 几何验收：标题和折叠按钮中心差不超过 1px；16px、500 字重；长标题省略；拖宽/收合侧栏、窄窗口、开坞、亮暗主题均不重叠。
- [x] 基线构建、93 项设计契约及 12 项会话/侧栏测试通过；旧搜索两项断言在基线已失败并单独记录；新增位置断言在旧布局上失败（中心差约 73px）。
- [x] App 增加稳定 callback-ref 插槽并只传给主 ConversationView；会话头通过 portal 进入顶栏，累计用量在主区保持可见；侧边会话仍在坞内显示自己的头。
- [x] CSS 使用 16px 会话字号令牌、500 字重、24px 行高，导航和标题同排居中；长标题省略并可悬停读取完整标题，远端目录保持可见。
- [x] 更新受 DOM 位置影响的现有测试定位，保持原断言强度；验证切会话/回首页无旧标题残留，搜索、导出仍可用。
- [x] 类型检查、构建、相关单测和 Electron 回归；逐张查看亮暗截图，记录开发历史及实际验证结果。保留在分支，等待用户审阅。

用户中途补充的标题内容要求：

- [x] 新 API 会话独立概括主题，限制长度、重复、输出格式和 15 秒超时，手动改名优先；旧标题保留，外部运行时短标题回退。
- [x] 同项目/同服务器去重，跨组互不污染；持久化摘要并同步侧栏/页签/顶栏/任务投影。
- [x] 后台 title 元信息独立于转录版本，飞行中的旧名单不覆盖新标题。
- [x] 模型 mock 将标题请求单独记录，不触发/消耗主对话工具夹具；真内核停止与侧边并行回归通过。
