## 已复现并修复

1. **清理期间同步重入停止，会发起第二轮清理。** 原代码先调用清理，再登记关闭屏障，依赖回调可以在登记前再次进入。现在先登记同一份停止 Promise，再同步进入清理，保留立即撤销与禁止重开的语义。覆盖同步重入、重复停止、启动中/运行中延迟清理、启动快照/started 回调停止、取消及失败后立即重试。
2. **非 ISO 格式绕过日期校验，无时区时间依赖宿主环境。** 新建和替换时间字段现在只接受 ISO 日期（UTC 零点）或带明确偏移/Z 的 ISO 日期时间。空白、斜杠和英文月份输入不再绕过；仍支持闰日、24:00、毫秒、大小写、基本/扩展偏移及扩展年号。三个宿主 TZ 的子进程验证了确定性。协议和工具说明同步补充；没有新增协议操作。
3. **0—99 年被算成 1900—1999 年。** 统一使用公历 400 年周期处理字面年号、日期加减和星期，保留 BCE 年号，并避免时区反解时过早裁剪本地日历坐标。覆盖每天、每周、每月、每 N 天及 UTC/固定正负偏移的范围端点。
4. **超大周期及日期范围边界抛异常或丢失毫秒。** 超出完整可表示日历跨度的周期在保存前拒绝；存量异常周期不再参与到期计算。合法周期走到范围端点时返回没有下一次，保留最后一次有效到期。间隔运算使用精确整数处理跨全范围的差，避免 1 ms 舍入。无效参考时钟、日期范围上下界和偏移/时钟交叉用例均有回归。

此前已保存的非法 ISO 日历日也不再按滚动后的日期执行。合法的旧 RFC/斜杠格式任务仍可读取、改名、暂停，并显式替换为 ISO；新建或替换时不再接受这些格式。未知存量格式保留既有读取语义，本轮没有扫描、推断或改写正式任务库。
