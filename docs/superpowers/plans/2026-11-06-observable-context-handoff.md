# 可解释运行总览与有界上下文交接

目标：复用统一编排、Team DAG、冻结契约、任务文件版本、子运行目录和恢复机制，减少用户排查分散状态与重复转述背景的负担。专项分支 codex/observable-context-handoff；不自动提交、合并、推送、发布或替换安装应用。

## 阶段 A：会话运行总览

- 在现有团队面板上方显示父会话所辖 subagent/team/bot，继续使用原 Team DAG。
- 新增只读 IPC，runtime 存活时读取同一个 OrchestrationService；冷记录只读解析，不启动 runtime、不改写恢复状态。
- 显示执行代次、状态、实时停止/排空、失败原因、契约验收和已有版本数量；无记录的等待原因显示未知，不把 queued 冒充产物锁等待。
- API 仅返回 UI 必要字段；不暴露凭证、system prompt、任务权限设置或其它会话。
- 验收：状态转移/取消排空/冷读不改盘/跨父会话隔离/IPC mock/真实 Electron。

## 阶段 B：有界交接

- ordinary subagent 的 single/parallel/chain 与 start_subagent 使用同一个宿主交接入口；显式选择父会话已完成消息，默认不复制历史。
- 冻结来源会话、来源条目标识、选择内容与摘要指纹；限制条目与 UTF-8 字节，超限明确拒绝。
- 只允许用户文本、已完成助手正文；排除工具原始输出、thinking、system、凭证和未完成当前输出。
- 保存到对应子运行目录，注入任务正文并展示来源；不增加 tools、TaskSettings、文件访问或授权。
- 续问复用原快照，不重新抓取父上下文；旧记录保持可读；恢复不隐式执行。
- 已有科研路线/输入输出/验收/版本由冻结契约继续提供，不增设一套科学版本或复用签名。
- 验收：来源伪造、越权/跨会话选择、截断、代次续问冻结、取消与恢复，以及真实子进程收到快照。

## 阶段 C：收益记录与审查

- 扩展同一个 evaluate:science 入口，保留原基线与现有增量/并行/纠偏比较。
- 用确定性本地对照记录可见事实、交接选中信息保真、额外字节；不推断真实模型质量、token 节约或人的操作时间。
- 每阶段保存实际截图/宿主回执/JSON 到独立 validation 目录。
- 执行 typecheck、适用单元/协议/界面测试、构建与 Electron 回归，审查取消排空、隔离、契约和恢复。
- 更新开发历史，报告测试边界与遗留风险；主仓 main 和正式应用数据保持原状。

执行方式：单一实现主线，测试先行；阶段结束展示可核查效果。若源码约束使接口需要细调，保持上述行为与保护边界，并在此记录实际设计。

## 实际接口与边界

- 入口沿用“团队”坞，不新增坞类型；普通委派没有团队时总览仍可使用。原 DAG、流水线/批量/复用状态保留。
- `getRunOverview({sessionId})` 为无副作用只读 IPC，协议 8.45。存活 runtime 直接读 service；冷状态使用相同持久化 schema 解析，绝不调用会执行恢复写入的 Store 构造器。
- 交接选择为 `handoff:{recentMessages:N}`，N 为 1–8，取当前父分支最近最多 N 条可用正文；实际条目 ID、角色、全文、字节和指纹保存于对应子运行目录的 `handoff.json`。没有该参数时沿用原行为。
- single 顶层、parallel/chain 各任务、后台 start_subagent 均支持；续问不重新选取。科研契约任务拒绝普通快照，继续使用既有路线/契约/产物版本，避免改变复用有效性口径。
- 用户正文可来自含附件的消息，但仅提取 text 块；不带图片字节、工具原始结果、thinking、系统提示或凭证容器。已完成助手正文仅认 Pi stop 状态，排除 toolUse/aborted/error/length。
- 指纹绑定来源会话、条目 ID/角色/正文与选取数量；相同请求重试复用原快照；选择数量改变拒绝。元数据保存快照指纹，丢失/修改时拒绝续问，排队后启动前再次核对，避免降级为无背景运行。
- 快照是历史正文引用，不证明其中提到的文件仍有效；文件内容有效性仍由冻结科研契约的版本检查负责。
- 实际界面与转录证据：`docs/validation/observable-handoff-20261106`。评测通过原 `npm run evaluate:science -- <新目录>` 入口追加 handoff 对照，不修改既有验收标准。
