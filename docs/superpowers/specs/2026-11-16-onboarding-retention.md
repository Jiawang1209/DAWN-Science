# 正式版配置与引导保留

用户已批准：正式版保留现有 API 配置；配置过模型，或完成、跳过四步引导后，之后启动进入首页。升级和保留用户数据的覆盖安装不重复引导。底部“导航栏”仍可手动打开四步引导。

- 沿用当前应用标识、userData、系统安全存储及更新凭证交接机制，不复制真实凭证到代码、测试或仓库。
- 引导接受状态按本机应用用户配置保存，与版本和安装世代分离。兼容已有全局键及旧安装/版本后缀键，只保存非敏感布尔值。
- 没有历史状态时，等待凭证元数据返回后才判断是否首次使用。已存凭证（包括暂时无法解密的凭证）视为配置过，不因钥匙串状态强迫重新引导。
- 自动判断每次窗口启动只做一次；手动打开的引导不会被异步加载或保存凭证打断，也不清除长期完成状态。
- 真正首次使用者仍展示四步引导。缺少本地环境或模型不妨碍主动跳过。新窗口默认首页；同一窗口热刷新保留工作台和草稿。
- 清空用户数据或换电脑不属于升级保留；不承诺绕过 macOS 自身钥匙串授权。

密钥防护：补齐运行时凭证文件忽略规则，使用 Gitleaks 进行脱敏扫描；本地提交检查暂存内容，推送检查待推送提交，CI/发布检查当前 Git 内容。工具缺失或扫描错误时阻止相应动作。测试仅使用人工假值；命中报告只显示文件、位置、规则，不显示密钥。检测是防线，不能替代系统安全存储，也不能保证识别所有任意格式的秘密。
