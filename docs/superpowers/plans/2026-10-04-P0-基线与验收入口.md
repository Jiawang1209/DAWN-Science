# DAWN P0 基线与验收入口 Implementation Plan

> 给后续执行者：使用 `superpowers:executing-plans` 逐任务执行，默认在当前会话内工作。本文是文档、证据和只读核实计划；发现功能缺陷时记录到 P1 或相应阶段，不混入未设计的功能修改。先读 [长期路线图](2026-10-04-长期开发路线图.md)。

**Goal:** 建立当期能力台账、五个参考任务和可复查的基线报告，为 P1 选择最小首项实现提供依据。

**Architecture:** 按规格、代码、自动化测试、真实使用四层记录能力。使用仓库内的 Markdown 和确定性合成数据保存证据，不修改执行协议或数据库，不引入新平台或依赖。

**Tech Stack:** Markdown、既有 Node.js 脚本、Vitest、Playwright、现有 Python/R 内核；真实模型仅用于显式安排的端到端验证。

**状态：** 未开始。P0 完成后才依据结果生成 P1 独立设计和实现计划。

- [ ] 读取 `git status --short`、`git rev-parse HEAD`、`package.json` 版本，记录当日代码和已有修改。
- [ ] 台账按以下固定列建立，不将空字段填为“支持”。

```markdown
| 能力/场景 | 规格 | 实现入口 | 测试入口 | 支持边界 | 最近实测证据 | 状态 | 缺口任务 |
|---|---|---|---|---|---|---|---|
```

- [ ] 覆盖首次配置、API 对话、两种 ACP、取消/方案/回退、会话搜索、Python/R 内核、本地/SSH、产物、Office、浏览器、权限、记忆、团队、定时、通知、更新和三平台安装。
- [ ] 内核按切换会话、应用正常退出/重开、内核退出/重开、机器重启四种情况各写一行；只记录观察结果。
- [ ] 对 `filesRead`、产物版本、宿主中断处理、跨运行时切换、Windows 和 Linux CI 六个关注点逐项定位代码，不照搬旧规划的完成标签。
- [ ] 每个缺口关联长期路线任务 ID；不能确定时写未验证及所需验证方法。

**验收：** 每行至少有实现或缺失定位、支持边界和状态；实测与静态检查明确区分。

## Task 2 · 五个参考任务（P0-2）

**文件：**
- 新建 `docs/quality/参考任务.md`。
- 新建 `examples/quality/observations.csv`、`examples/quality/README.md`。
- 读取 `e2e/environment.spec.ts`、`e2e/remote-kernel.spec.ts`、`e2e/office-plugin.spec.ts`、`e2e/artifacts.spec.ts` 和团队相关用例，复用现有夹具方式。

- [ ] 写入下列合成数据，标明它不是正式科研数据；表格统计与 R 绘图任务共用它。

```csv
sample,treatment,value
C1,control,1
C2,control,2
C3,control,3
W1,warming,3
W2,warming,4
W3,warming,5
```

- [ ] **Q1 Python 分析**：读表，核对 6 行、无缺失、每组 3 个；生成组均值表（control=2、warming=4）和散点图；保存代码和实际输出，保留输入。
- [ ] **Q2 R 绘图**：使用同一表生成可编辑 PDF 与 PNG，图包含 6 个原始点和两组均值；新内核重跑均值仍为 2/4；只要求描述统计，不虚构显著性。
- [ ] **Q3 SSH 任务**：先在可用测试服务器执行可控的有限循环并按步写入临时目录；断开后核验进程、已完成步和重复写入情况。无测试服务器时标受阻，不把 fake SSH 当真机。
- [ ] **Q4 Office 修改**：构造可编辑 DOCX、含公式的 XLSX 和带模板元素的 PPTX 夹具；记录初始结构；只改指定段落、数据单元格和幻灯片文字；检查其余结构、公式结果和渲染。先核实本机可用渲染器，缺失时明确版式未验证。
- [ ] **Q5 并行代码任务**：在独立临时 Git 仓库创建两个同名目标修改任务与一个用户手改文件；记录各任务 diff 和用户文件内容，验证污染与归属。当前未支持隔离时记录失败，不提前修改 DAWN。
- [ ] 每个任务填写输入、执行环境、请求文本、预期结果、失败注入、输出位置、验收和隐私边界。Q3 的临时输出与 Q5 的测试仓库均不得使用用户正式目录。

**验收：** 五个任务可按文档重复执行；Q1/Q2 的数值判据固定；Q3/Q4/Q5 的环境条件与未验证项明确。
