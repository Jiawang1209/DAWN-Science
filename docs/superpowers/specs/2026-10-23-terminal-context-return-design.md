# Terminal context return

用户已明确同意：点击“返回会话”直接打开当前终端 Agent 的同一段会话，在图形界面继续原来的对话。独立分支、实际预览，不合并、不推送、不替换安装版。

- 后端以私有本机连接认证后的真实 CLI 会话 ID 为权威，在 getTerminalAgentMode 的响应中附带 sessionId、项目和模型信息。退出到 Normal 后仍保留该终端最近一段 CLI 会话引用，下一次真正进入 DAWN 才更新；终端关闭时清理引用。
- 返回动作每次重新查询所选终端，不依赖轮询旧值。复用现有会话路由，明确在主区打开同一 ID；不创建、复制、摘要或合并消息，不中止运行中的 CLI / 工具，不触碰原 Shell。
- 从未进入过 DAWN 的 Normal 终端返回原界面。已删除/归档的目标按现有路由明确提示，保留终端界面。请求期间切换终端、会话或项目时丢弃迟到结果；按钮仅锁定正在返回的终端。
- 保留原会话草稿。图形会话与终端视图用别名关联，使同一项目内回到这条 CLI 会话再打开终端仍显示原 PTY；不改变后端原始终端归属。
- 不添加图片功能。验证历史和工具记录可见、GUI 续问使用原 sessionId、模型实际可记住终端内随机标记、Normal / 无 Agent 回退、并行终端隔离、返回时任务继续、明暗/窄窗、原会话草稿与 Shell 存活。
