# 学 dsh 的 GUI：A / B / C 三档全做

分支 `learn-deepseek-harness`。依据：`docs/学习-dsh-GUI/00-对比与建议.md`。
作者 09-29 原话：*「你就把 A B C 都做了……和我们规矩冲突的，我们不学，我们就学它的优点，界面，响应速度，高效。做就完了。」*

**总纪律**（每个 Task 都适用）：
- 加一条路，不改旧路（[[add-without-breaking]]）；旧 e2e 红了先怀疑自己。确实要翻旧判据时翻面并写理由。
- 看不见的等于不存在：不做只在悬停时出现的东西；新快捷键在界面上用字写出来。
- 失败必须出声。
- 新协议形状：同一次改动里版本号升 minor、`version.ts` 写一段、e2e/mock 链路跑通。
- 可判定的规则加进 `tests/ui/design-contract.test.ts`。
- 每个 Task：typecheck + 单元 + 相关 e2e 全绿后提交（英文 commit，不带 Co-Authored-By），并在 `docs/DEVELOPMENT_HISTORY.md` 顶部追加一条。
- 视觉基线红了先看 diff 图；改样式的 Task 用 `test:e2e:visual:update`（=all）重存，重存后再验两遍。

## A 档：小改动，立刻有感

- [x] **A1 用户气泡即时上屏**。直接发送（不在忙、不进待发条）时，渲染进程在转录槽里本地插一条回显，样子和真的一样（没有操作行）。真 `user` 条到了（或快照到了）就在同一次落地里撤掉回显；发送失败也撤掉，原话退回输入框（这一步已有）。不能出现两条一样的气泡。
- [ ] **A2 失败钉在轮上 + 截断给下一步**。`failed` notice 画成：红点 + 「这一轮没做成」+ 人话原因 + 原始错误（等宽，可折叠）。pi 的回复因输出上限停下（`stopReason: "length"`）时，推一条 notice：「回复到了输出上限，被截断了——说『继续』可以接着写」。
- [ ] **A3 审批卡键盘化**。焦点在审批卡里时：回车 = 允许一次（allow 类的主按钮），Esc = 这一轮先不做；组字中、长按重复、带修饰键的都不算。卡片出现时，如果输入框是空的，就把焦点移到卡上。卡上用字写出「回车 允许 · Esc 先不做」。
- [ ] **A4 侧栏「等你点头」**。会话行状态优先级：等你点头 > 跑着 > 未读 > 空闲。等你点头时，圆点换成 warning 色，行尾时间那一格换成「待批准」。

## B 档：治长回复越写越卡

- [ ] **B5 增量传输**（协议 8.8）。新增更新类型 `append`：`{ id, field: "text" | "thinking", delta }`，只在「同一条 agent 发言、只是这个字段往后接」时用；其他情况照旧推整条。中枢按帧合批（约 16ms），任何别的更新、快照、`final` 之前先冲掉挂着的增量，保证顺序和 revision 连续。渲染进程按 id 往后接；找不到那条就走跳号重同步。所有 `onUpdate` / 全听的消费者都要逐个检查（远程助理通道、侧边对话、子转录、终端、通知）。
- [ ] **B6 输入卡搬出重渲染**。流式落字时，输入卡那一片不跟着重跑：拆成独立的 memo 组件，只接收窄的 props。用 `perf:streaming` 量改前改后。
- [ ] **B7 代码块高亮减负**。流式中的代码块先不高亮，写完再高亮；转录里屏幕外的代码块进视口才高亮（全局共享一个 IntersectionObserver）。复制按钮始终在。

## C 档：界面

- [ ] **C8 过程两层收纳**。①工具组标题写成一句人话：做完是「读了 3 个文件、跑了 2 条命令」，在跑是「正在运行 · pytest」，每个标题至少停 150ms。失败仍然只在汇总里标红（09-15 作者定的）。②每个做完的 agent 轮上面加一行「已完成，用时 1分12秒 · N 步 ⌄」，点一下收起或展开这一轮的过程（思考 + 工具），答复永远在外面。③设置 → 外观加「工作步骤展示：简洁 / 标准」，简洁 = 做完的轮默认收起；**默认是标准（行为不变）**。理由：画出来的图多在工具结果里，收起来人就看不见了。
- [ ] **C9 思考按段落推进**。思考中那一行显示最近一段已写完的段落的首行，右端渐隐，文字上有扫光（减弱动效时关掉）；秒数照旧。想完是「想了 Ns · 首行」。
- [ ] **C10 节奏与细节**。条间距分档：同一轮里的过程行之间紧，答复与过程之间中等，换一轮说话大；代码块标题栏 sticky（长代码滚动时复制按钮还在）；diff 的 ± 统计平时灰色、悬停或展开时才上颜色（数字始终可见）。
- [ ] **C11 性能预算进 e2e**。一条 e2e：假模型流一段长回复，期间往输入框打字，量键入到画出来的延迟，以及这一轮 IPC 传了多少字节；阈值写成常量，另配一条零余量的反例单测，证明判据真会拒。
- [ ] **C12 一根字号轴**。设置 → 外观加「对话字号」（13–19，默认 15）；对话里的字号、行高、图标都从一个变量派生。默认值下视觉基线不变。
