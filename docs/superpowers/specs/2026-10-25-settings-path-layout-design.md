# 设置长路径布局修复

用户授权继续逐项修复 F5，前一项内核清理已独立合并并通过主目录验收。本项只修设置页路径行的宽度分配，不改变目录选择、下载流程或其他设置布局。

路径行保留标签/说明与右侧路径控件两列；右列不能再按完整路径的 max-content 吞掉左列。两列均可收缩，路径使用既有省略号，按钮保持完整单行。窄窗口路径行按现有设计意图上下排列；右侧设置栏继续沿用原单列作用域，不被新规则覆盖。

验收：真实 Electron 默认/长路径/恢复默认，明暗与较窄窗口均保持说明和按钮可见、没有横向溢出，长路径确实省略；原下载目录到磁盘与右栏设置流程保持。沿用现有设计契约，无新 UI 设计方向或协议。
