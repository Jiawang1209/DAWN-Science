## 2. 处理

脚本：`results/analysis.py`（stdlib：`csv` / `json` / `math` / `os` / `sys`，无第三方依赖，不创建子进程，确定性输出）。

处理步骤：

1. 以 `csv.DictReader` 读取 `input.csv`，校验表头含 `carbon_mg_g`，否则中止。
2. 逐行解析目标列：字面缺失标记集合 `{na, n/a, nan, null, none, 空字符串}`（大小写不敏感）判为缺失；其余必须能解析为**有限**浮点数，否则脚本以非零状态中止——不静默强转、不静默填补。
3. 缺失值规则：**只在目标列丢弃**，得到有效样本 n = 41。不改动、不填补任何单元格；`rain_mm` 全部读入但不参与筛选或加权。
4. 求和用 `math.fsum`（精确舍入求和），均值 = 总和 / n；校验均值有限后写出 `results/result.json`。

——位置在数据中等间距出现（每 7 行一条），其余列（`site`、`rain_mm`）在这些行上完整。

## 4. 局限与说明

1. **单位仅有列名依据**：数据文件内没有单位溯源元数据（方法学、仪器、干重/湿重、燃烧法或湿氧化法等），mg/g 直接取自列名。若原始单位另有约定，结果需重算。
2. **缺失机制未知**：7 个 `NA` 无成因说明（未测、丢失、低于检出限皆可能）。按批准规则做完整案例丢弃（complete-case on target），相当于假设缺失与取值无关（MCAR/MAR）；若缺失与碳含量系统性相关，均值可能有偏。
3. **无精度信息**：单一 CSV、每站点单次测定，没有重复测量，无法估计测量误差或给出置信区间；本报告仅给出点估计，不做推断统计。
4. **未做的分析（有意为之，避免超出批准方法）**：未按 `rain_mm` 分层、筛选或加权，未剔除离群值，未做任何变换或填补。`rain_mm` 在本阶段完全不参与计算。
5. **样本量与代表性**：n = 41，来自同一数据集的 48 个样地；对更广总体的外推不在此契约范围内。
6. 脚本的 `csv` 解析假设标准逗号分隔、无引号内换行（本文件满足）；若输入格式变化，脚本会因表头/解析校验而中止而非产出错误数值。
