# 首启向导与解释器检测 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 没有 key 时首屏是向导：填 key 立刻可聊；顺带检测本机 Python / R 解释器路径让人选（可跳过）。

**Architecture:** 探测是 `src/kernel/probe.ts` 的纯函数（枚举候选 + 解析输出，spawn 可注入），协议只读操作 `probeInterpreters`。界面一个 `InterpreterPicker` 组件，向导（`SetupWizard`）与设置「内核」屏共用。向导只在凭证为空且未跳过时替换主区。spec：`docs/superpowers/specs/2026-08-27-首启向导与环境检测-design.md`。

**Tech Stack:** TypeScript / zod / React / vitest / Playwright。

### Task 1: 探测的纯函数 `src/kernel/probe.ts`

**Files:** Create `src/kernel/probe.ts`；Test `tests/kernel/probe.test.ts`

```ts
export type 语言 = "python" | "R"
export interface 候选 { path: string; source: "settings" | "PATH" | "kernelspec" | "common"; version?: string; kernelPackage: "present" | "missing" | "unknown"; problem?: string }
export interface 枚举依赖 { platform: NodeJS.Platform; home: string; exists(p: string): boolean; glob(pattern: string): string[]; pathLookup(name: string): string[]; settings: { python?: string; r?: string }; kernelspecs: { language?: string; executable?: string }[] }
export function 枚举候选(语言: 语言, d: 枚举依赖): { path: string; source: 候选["source"] }[]   // 去重、按 settings > kernelspec > PATH > common
export const 探测命令: Record<语言, (path: string) => { cmd: string; args: string[] }>   // python -c ... / Rscript -e ...
export function 解析探测(语言: 语言, r: { code: number | null; stdout: string; stderr: string; timedOut?: boolean }): Pick<候选, "version" | "kernelPackage" | "problem">
export async function 探测解释器(语言: 语言, d: 枚举依赖, run: (cmd: string, args: string[]) => Promise<{ code: number | null; stdout: string; stderr: string; timedOut?: boolean }>): Promise<候选[]>   // 并发 4
export function R的Rscript(rPath: string): string   // 同目录的 Rscript（Windows 加 .exe）
```

- 常见目录清单见 spec §2。`glob` 只用于 `~/.pyenv/versions/*/bin/python`、conda `envs/*`、Windows `Python3*`、`R-*`。
- `pathLookup(name)`：调用方给（后端用 `bash -lc "which -a name"`，Windows 用 `where name`）。
- 解析：Python 退出码 0 → present，stdout 第一行是版本；非 0 且 stderr 含 `No module named 'ipykernel'` → missing（版本仍取 stdout 第一行，因为 print 在 import 之前）；其它 → unknown + problem（stderr 末尾 5 行）；`timedOut` → unknown + 「8 秒没应答」。R：退出码 0 present、3 missing、其它 unknown。
- [x] 测试先写：枚举（假 exists/glob/pathLookup，验去重与顺序、Windows 分支）、解析四态、`探测解释器` 并发用假 run。
- [x] 实现；`npm test -- probe`；commit `feat(内核): 本机解释器探测的纯函数`。
