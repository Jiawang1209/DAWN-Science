# 本轮真实复验范围

用户已明确新增最多 30 次请求。使用 DAWN 当前受支持模型；只读核对当前模型路由，不输出对话正文、端点或凭证，不修改正式配置/数据。

本轮一个自制 carbon-missing 任务，单执行者与多执行者各一次、各最多 15 请求。多执行者采用 automatic-plan：通过产品 propose_plan 生成实际安排，规划调用计入工作共享 11 次，独立审阅独享 4 次不可借用。任务块数是模型输出，不预设为三。冻结同一科学方法、产物、科学契约与独立真值；不因模型安排改变验收。可选额外核查保留同一核查契约，必须有唯一科学分析和独立只读审阅。

所有模型请求由原 EvaluationGate 原子预占，剩余提示读取同一分区账本；无自动 SDK 重试、无整组重跑。退出、失败、额度用尽和无有效安排均如实记录，不切换模型/候选或追加额度。先完成离线验收，冻结源码、子进程构建和模型声明后启动；真实调用期间不改 src/scripts，不与全量/Electron 并跑。

规划在独立系统临时工作区，只复制自制输入，禁用全局技能、扩展、记忆和外部工具；只允许读取声明输入与 propose_plan。会话/执行记录写本轮目录，临时工作区 finally 清理。模型凭证仍通过现有隔离 Electron 只读钥匙串入口取得，密码只在系统提示中操作。

最多 30 次授权上限不等于必然用满。当前候选的真实结果单列，不把先前固定三阶段报告或离线夹具当作本次模型收益。历史偶发 OS 退出和 PTY 清理保持 OPEN，不改阈值。本轮不提交/合并、不推送/发布、不替换正式 App。
