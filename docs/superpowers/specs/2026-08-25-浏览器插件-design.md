# 浏览器插件：agent 的手伸进真浏览器（2026-08-25）

学自 `huey1in/reef`（dsh-reef 的 browser 模块；awesome 清单里的 `dsh-browser-panel` 已 404，能力在此）。
解读：`ccb_hive_code_learn/dsh-reef-浏览器-解读.md`。

## 与既有两条路的关系

- 坞「网页」格：**人**看网页。本插件：**agent** 操作网页（headless）。方向相反，不重叠。
- `docs/怎么给-agent-配一个浏览器.md`（外部 MCP）：目的相同、手段不同——本插件零安装内置，MCP 是进阶选项（接更强的专用服务器）。

## 依赖决策（规格 §4）

- 坐在 `playwright-core` 上（唯一新依赖，**external**——它自带 createRequire，与 pi 同雷）：
  **复用系统浏览器**（channel 探测 msedge → chrome → 已装 chromium），不下载 Chromium。
  探测不到时报人话（装 Edge/Chrome 或 `npx playwright install chromium`）。
- 放弃了 reef 的 cordis 壳、MCP Server（方向相反）、GitHub/GitLab（交给 bash + `gh`，它自己也这么说）、
  form 回放与多 profile（等用出需求）。
- 复用 office 插件的定义 DSL 与 pi 包壳（`包成pi工具`）；插件册（`src/tools/plugins.ts`）自此成为唯一名单。

## 形状

- **一台共享浏览器**（v1 单 profile，headless，lazy 启动）：多段会话共用；`browser_close` 的描述写明共享。
- 15 个工具、四族：浏览 7（open/tabs/back/reload/wait/status/close）· 读页 2（**snapshot** 文本优先：innerText 截断说明 + 链接清单 + 输入框数；**elements** 给现成 CSS 选择器）· 操作 4（click/type/press/eval，eval 结果净化成 lossless JSON）· 产物 2（screenshot 落工作区 `.dawn/screenshots/` 双阈值自动清理；download 经页面上下文带 Cookie 落工作区）。
- 插件屏第二张卡；设置键 `plugin.browser.off` / `.browse` / `.read` / `.act` / `.artifact`（没记 = 开）。
- 访问历史留了口（session.ts `历史`，50 条）——第二步坞里「agent 的浏览器」页签用。

## 判据

- `tests/tools/browser.test.ts`：名册 / 开关 / 清理（老图删、别人的文件活着）/ 净化。
- `tests/tools/browser-live.test.ts`：**真浏览器**整链路（open→snapshot→elements→type/click→eval→screenshot），探测不到浏览器带理由跳过。
- `e2e/browser-plugin.spec.ts`：第二张卡四族 15 工具、开关持久；假模型点名调 `browser_status`（不启动浏览器也证明工具装上了）。
