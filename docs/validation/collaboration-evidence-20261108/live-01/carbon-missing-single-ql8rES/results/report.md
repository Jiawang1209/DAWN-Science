## 2. 处理

脚本：`results/analysis.py`（Python 标准库 `csv`/`json`/`math`，无子进程、无随机性）。
调用方式（单条隔离命令）：

```bash
python3 -I results/analysis.py
```

步骤：

1. 以 `csv.DictReader` 读取 `input.csv`（`utf-8-sig`），保留全部 48 条数据记录（跳过纯空行；本文件无空行）。
2. 校验表头含 `carbon_mg_g`；逐行只在目标列判定缺失（token 集合含 `""`, `na`, `n/a`, `nan`, `null`, `none`, `.`；本文件实际出现的是 `NA`）。
3. 缺失行整行剔除并逐条登记（`dropped_rows`，含 site/rain_mm 以便复核），**不填补、不插值、不做回归/均值替代**。
4. 其余 41 个值原样进入计算：`mean = fsum(values) / n`（Kahan 求和，无中间四舍五入、无截断、无异常值剔除、无加权）。
5. `rain_mm` **完全未参与**：既未用于筛选行、分组、加权，也未用于插补；因此不存在「按 rain_mm 筛选」的隐式路径。
6. 写出 `results/result.json`（平铺对象），并把审计信息（行数、剔除清单、min/max/sum）打印到 stdout。

## 4. 方法适用条件

- **算术均值适用于**：目标变量为区间/比率尺度、单位统一（mg/g）、无分组结构下的「典型水平」汇总。本列取值 12.0–15.6，量级一致、无零值/负值；描述性核对得样本标准差 ≈ 1.062（n=41，仅作适用性旁证，未写入 `result.json`），极差 3.60 约合 3.4 个标准差，未见需要剔除的极端离群点，故不做截尾或剔除。
- **未加权的等权平均**符合批准方法；48 行对应 48 个独立样地（plot-1…plot-48），未见重复测量或嵌套结构，故无需混合效应/加权处理。
- **不适用于**：若研究问题是「碳与降水的响应关系」或「某降雨区间的条件均值」，则应做回归或分层；本任务的冻结口径是单一列的总体均值，故不作此扩展。

## 5. 局限与证据缺口（不猜测）

1. **单位不可由数据自证**：CSV 无单位行、无 data dictionary、无方法文件；`mg/g` 来自任务契约与列名，属**约定值**，不是从文件内部核实的结果。若原始实验室记录另有单位（如 g/kg 或 %），换算需另行提供依据——本次未做任何单位换算。
2. **缺失机制未记录，且明显周期性**：缺失出现在数据行 1, 8, 15, 22, 29, 36, 43，为每 7 行一次的严格等距模式（plot 编号 1, 8, 15, …）。等距缺失更像采样/导出的系统性安排，而非随机丢失；完整案例均值仅在 MCAR（或至少在缺失与取值无关）下无偏。本任务口径要求「仅丢弃 NA」，故按此执行，但**结论应读作「41 个有观测样地」的均值，而非全部 48 个样地的无偏估计**。
3. **`rain_mm` 是严格等差序列**（300, 311, 322, … 817，步长 11，48 行无缺失）。这提示该列可能是按设计生成的梯度而非实测记录；本分析未使用该列，故不影响均值，但若后续要做碳–降水关系，需先核实其来源与真实性。
4. **无重复/无空白/无对照信息**：文件不含重复样地、重复测量或 QC 标记，无法评估测量误差与检出限，也未做精度/不确定度估计（未提供仪器或方法的重复性数据，故不编造 SD/CI）。
5. **无分布假设检验**：仅点估计，未做正态性检验或稳健性对照（如中位数、trimmed mean），因为批准方法是算术均值且任务只要求该指标；这些替代量未计算，以免超出冻结口径。
6. **未评估抽样代表性**：48 个 plot 的空间布设、样地面积、土层深度未知，均值只能解释为「本文件所载样地的平均碳含量」。

## 6. 可复现性

- 全部计算可由单条命令重跑：`python3 -I results/analysis.py`（隔离模式、无子进程、仅标准库、路径基于脚本位置解析，任意 cwd 均可）。
- 脚本只声明并读写 `input.csv` → `results/result.json`；不写其他文件、不联网。
- 输入 `input.csv` 未被修改（只读打开；sha256 `568eaee3…aaf789` 在两次观测间相同）。

- 审计轨迹：stdout 的 JSON 给出 `rows_read=48`、`rows_with_value=41`、`rows_dropped_missing=7`、逐条 `dropped_rows`、`min/max/sum`，与 `result.json` 的 `n` 自洽（48 − 7 = 41）。

## 7. 结论

在「仅丢弃 `carbon_mg_g` 的 NA、不使用 `rain_mm` 筛选或填补、保留全部其余输入」的口径下，`carbon_mg_g` 的算术均值为 **13.870731707317074 mg/g**（n = 41，合计 568.7，范围 12.0–15.6 mg/g）。主要保留意见是缺失的严格等距模式与单位只能取自契约，二者都限制了对总体无偏性的推断。

## 8. 复核记录（自查）

- 独立算法交叉核对：`awk -F,` 直接聚合原始 CSV → `n=41, sum=568.7000000000, mean=13.870731707317074`，与脚本逐位一致。
- 行数守恒：读取 48 条记录 − 剔除 7 条目标列缺失 = 41 = `result.json` 的 `n`；`rain_mm` 48 行全部有值，未被用于任何筛选。
- 结构核对：表头为 `site,carbon_mg_g,rain_mm`；无重复样地号、无参差行、无非数值单元格。
- 复核后修正的非结论性问题：脚本 docstring 中输出字段名由 `carbon_mean` 更正为 `carbon_mg_g_mean`，并移除一段未使用的死代码；报告初稿中「极差约为若干标准差」的表述改写为实测 `sd ≈ 1.062`（原写法不准确）。上述修改**不改变任何数值结果**。
