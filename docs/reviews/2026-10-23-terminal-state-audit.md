## 发现与修正

- 异步创建完成后会覆盖后选终端；关闭重开、会话/项目切换也会被迟到结果覆盖。增加终端操作代次和作用域检查，原会话的终端仍按原归属留存。
- 欢迎页原先仅按“无会话”共享终端，跨项目可能看到另一个项目的进程。按项目区分欢迎页归属，恢复前查询当前范围，避免列表尚未加载时重复创建。
- CLI 切入子目录后，Agent 会话属于新项目；返回图形会话再打开终端，旧 PTY 不在当前项目列表中。保留 PTY 来源项目引用，刷新后仍接回原进程。
- 删除项目后的旧选中 ID 会让新恢复查询失败，家目录终端无法出现。恢复查询只访问仍存在的项目，与创建时的家目录回落保持一致；真实 Shell 家目录写入验证恢复。
- 终端 A→B→A 的迟到订阅快照会倒灌旧输出；为每次订阅增加生命周期检查。
- 返回请求在切换/关闭重开之后仍可能导航或关闭新页面；迟到的旧请求还可能清除同一终端的新返回忙碌状态。导航与清理均按当前操作代次判断。
- 定时页面有 Agent 终端时，“收起面板”曾被会话导航条件挡住。非会话页面直接收起并保留所在页面。
- 查询恢复或手动进入 DAWN 后仍残留旧错误。区分查询错误和切换错误，恢复读取/模式变化时清理对应提示。
- Shell 已结束仍可以输入、启动模式切换。保留已结束记录和返回入口，停止输入与模式操作。
- 切换到 Normal 后，迟到的待发送图片读取可能重新打开原图弹层。原图读取与预览按附件作用域代次检查并清理。

## 边界

Agent 目标被删除/归档时，明确提示并留在原终端；不会跳到无关会话。模式正在启动/停止时，返回提示稍后重试。检查覆盖上述状态路径，不表示所有平台、安装包及任意外部 Shell 程序均已验证。无主进程、模型协议或权限策略变更。

用户原模型配置和加密凭证仅复用到隔离预览；不改源配置，不推送，不替换安装版。
