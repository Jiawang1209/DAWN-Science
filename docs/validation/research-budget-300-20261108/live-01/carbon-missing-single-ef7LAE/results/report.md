# carbon_mg_g 算术均值 — 交付报告

- 模板：`tabular-ecology@1`；语言：python（仅标准库）；批准方法：arithmetic mean
- 单位：mg/g（沿用输入列名 `carbon_mg_g`，未做单位换算）
- 缺失规则：**仅**丢弃目标列 `carbon_mg_g` 的 NA；不按 `rain_mm` 筛选，不填补

## 1. 输入

| 项 | 内容 |
|---|---|
| 文件 | `input.csv`（工作目录根，48 行数据 + 1 行表头） |
| 列 | `site`（标识）、`carbon_mg_g`（目标，单位 mg/g）、`rain_mm`（协变量，仅读取不参与计算） |
| 目标列取值域 | 数值型，观测范围 12.0 – 15.6；NA 记为字面量 `NA` |
| 使用文件 | 仅 `input.csv`；无外部数据、无网络、无第三方依赖 |

结构核查（脚本内建断言）：
- 表头存在且包含目标列，否则以非零状态退出；
- 空行跳过，不计入行数；
- 目标列中凡是「非 NA 且无法解析为有限浮点数」的单元格，**立即报错退出**，不做静默转换。

## 2. 处理

1. 逐行读取 CSV，目标单元格为 `NA`（及同义空标记）者剔除，记录其 `site`；
2. 其余全部行保留，不因 `rain_mm` 取值做任何过滤；
3. 求和用 `math.fsum`（精确求和，结果与行序无关），均值 = 和 / n；
4. 结果写入 `results/result.json`，字段严格为 `{n, unit, mean}` 的平铺对象。

被剔除的 7 行（唯一原因：目标列 NA）：
`plot-1, plot-8, plot-15, plot-22, plot-29, plot-36, plot-43`

这 7 行的 `rain_mm` 值本身完好（300、377、454、531、608、685、762），说明本次剔除只作用于目标列，`rain_mm` 未参与任何决策。

## 3. 结果

| 量 | 值 |
|---|---|
| n（保留样本数） | 41 |
| 合计 Σ | 568.7 |
| **算术均值** | **13.870731707317074 mg/g** |
| 最小值 / 最大值 | 12.0 / 15.6 |

`results/result.json`：

```json
{ "mean": 13.870731707317074, "n": 41, "unit": "mg/g" }
```

独立复核：用与脚本无关的 `awk` 通路重算同一规则（跳过 NA、不筛 `rain_mm`），得
n=41、sum=568.700000、mean=13.870731707317，与脚本结果之差约 3e-16，远小于验收容差 1e-9。

## 4. 方法适用条件核查

- **量纲一致**：目标列全部为同一量纲的连续数值，列名已声明 mg/g，无需换算，故算术均值可直接解释为 mg/g。
- **均值有意义的前提**：本次只求单变量中心位置，未做加权、未做分组比较；无权重设计信息，等权算术均值与已批准方法一致。
- **缺失机制**：完全案例（complete-case）均值无偏仅要求缺失与目标值无关（MCAR/MAR）。本数据 NA 恰好落在每 7 行一次的位置（plot-1, 8, 15, …），呈规律性，**更像设计性缺测而非随机缺失**；若缺失与真实碳含量相关，则该均值可能略偏。任务已冻结「仅丢目标列 NA」，故按此执行，不作调整，但见下节。
- **未做的事（遵守冻结范围）**：没有按 `rain_mm` 阈值筛选、没有插值/回归填补、没有删除 `rain_mm` 或 `site` 的行以外操作、没有截尾或异常值剔除。

## 5. 局限与证据缺口

1. **无抽样设计元数据**：文件未提供采样面积、重复结构、权重或分层信息，「算术均值」只能理解为对现存 41 个观测的等权平均，不能外推为区域无偏估计。
2. **缺失机制未知**：无实验室记录说明 7 个 NA 的成因（未测、低于检出限、样品丢失）。若为检出限导致的缺失，则观测均值会偏高，此类偏差本数据无法校正。
3. **无检出限 / 精度信息**：原始值保留 1 位小数，报告按浮点全精度给出，实际有效精度受原始记录限制（不建议解读到小数第 10 位）。
4. **单变量结论**：`rain_mm` 全程参与读取但未进入计算，本报告不提供任何关于碳–降水关系的推断。
5. **未做分布检验**：均值对偏态与离群值敏感，本次未报告中位数或分布形状作为对照（不在冻结范围内，故未输出）。

上述缺口均不构成计算阻塞：目标列存在、数值可解析、方法（算术均值）与数据结构匹配，缺失规则按冻结要求执行。
