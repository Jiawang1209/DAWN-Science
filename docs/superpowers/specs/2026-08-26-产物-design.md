## 1. 今天的实际状态（动手前核的）

- 每次工具调用都是一条 Run（`requestType = tool_call:<工具名>`），带 `filesWritten`（git 前后 `status --porcelain` 算的）、`mayIncludeUserEdits`。缺省 = 不知道，空数组 = 确认没改（R3 的口径）。
- `filesWritten` **不分新建与改动**。但 `--porcelain --untracked-files=all` 的 `??` 行、以及 `policy/artifacts.ts` 的产物登记（按设备号 + inode + 出生时间登记「此前不存在、现在存在」）都知道哪些是新建的——只是没记进账本。
- 探针（`runtime/provenance.ts`）只跑本地 git。远端会话、PTY agent（claude / codex 内置工具）的文件事实都是「不知道」。
- 坞（`ui/state/right-dock.ts`）现有房客：审阅 / 文件 / 概览 / 网页 / 团队。**终端不在这里**，它是底部另一个坞。文件格有图 / CSV / PDF / 文本三态预览，远端预览 = 一次下载。
- `@` 引用语法已支持本地与远端路径，路径 + 类型不喂内容。

## 2. 数据层：Run 加一列 `files_created`

schema 15 → 16，事务迁移。与 `filesWritten` 并列、**同一口径：缺省 = 不知道；空数组 = 确认没新建**。老 run 一律缺省。

算法在包装器（`runtime/native.ts` 的 `wrap`）里：

```
filesCreated = (porcelain 的 ?? 行) ∪ (产物登记里「此前不存在、执行后存在」的)
```

交给 `tool_files` 事件多带一个 `filesCreated` 字段，`run-recorder.ts` 照写。
- 探针起来了（git 工作区）：两半都有。
- 非 git 工作区（临时会话 `scratch/<ts>/`、用户自己的目录）：**走文件系统探针**（`project/fs-facts.ts`，2026-08-26）——执行前后各扫一遍工作区，按 inode / mtime / size 对比；跳过 `.git` / `.dawn` / `node_modules` / 虚拟环境；2 万条上限，**超限如实「不知道」并出声**（每个工作区只喊一次）。剔不掉作者手改的，`mayIncludeUserEdits` 如实为 true。两条路口径一致：缺省 = 不知道、空 = 确认没有。
- 远端会话、PTY agent：缺省。
- 覆盖已有文件不算新建（登记的既有规则）。
- 登记到的新建也并进 `filesWritten`（新建当然也是写过）。
- **只读内置工具（`read`）按设计发空事实**（2026-08-26 审查 A）：它不在探针白名单里、探针不观察它，但它是我们自己写的工具，白名单本身就是「它不写文件」这条声明——调用成功后发四个空数组，是「确认没写」，不是猜（不变式 5）。不发的话一段只 read 的普通对话会被标成「本轮产出未知」，主路径上一句假话。**只给内置白名单外的那几个用**：外部工具（MCP、内核 `run_code`）一律观察 git；`subagent` 不经这条包装。

**产物是查询，不是表**：

```
产物(sessionId) = ∪ runs(session).filesCreated    按出生 run 的 startedAt 排序
```

跨会话不算（另一段会话生成的进不了这一格）。删掉后仍列，标「已不存在」——它曾被生成是事实。

## 3. 协议（纯新增，minor 版本）

一个只读操作（`mutating: false`，无 `sideEffects`）：

```
listArtifacts { sessionId }
  → { artifacts: [{ path, kind, bornRunId, bornAt, exists }], unknown: { runId, toolCallId? }[] }
```

- `unknown` = 这段会话里 `filesCreated` 缺省的那几次（run，细到工具调用时带 `toolCallId`）。**界面必须显示它**。写成清单不写成总数，是因为产物条要按轮数未知——「这一轮有没有不知道的」得对得上 run，光有总数不够。
- `kind` 由后缀映射（`ui/file-kind.ts` 那一套搬到共享层），未知后缀 = `other`，不猜。
- `exists` 服务端查实（`lstat`）；**远端会话缺省**（本轮不走 `pathInfo`，见 §0 收窄 2）。
- 会话更新事件 `artifactsChanged { sessionId }`：run 结束且 `filesCreated` 非空时推一条，客户端重拉。事件只说「变了」，数据走查询（与 `dropItem` 同一纪律）。
- **不新增转录项类型**：产物条是按 turn 派生的视图——agent turn 结束后从 `listArtifacts` 筛出 `bornRunId` 的父 run 属于这一 turn 的那些（`parentRunId` 链已有）。历史会话打开也能画出来。
- **mock**：`scripts/mock-inference-server.mjs` **不用改**——e2e 与 `dev:mock` 跑的是真后端，假的只是模型；`listArtifacts` 与 `artifactsChanged` 在真后端里。e2e 夹具让假模型吐一个 `write` 真写一份 csv（不是 `run_code` 写 png：起内核太重，而要验的只是「新建一个文件 → 产物条」这条链）。

## 4. ① 对话里的产物条

位置：agent 那一轮回复的底部，标签 `GENERATED · N`。三种状态，**「不知道」不许画成「没有」**：

| 状态 | 判据 | 画法 |
|---|---|---|
| 正常 | 本轮有 `filesCreated` 非空的 run | chip（类型徽标 + 文件名），按出生顺序；已删的划掉标「已不存在」；超过 8 个折叠成「还有 N 个」；可访问名是「打开产物 <相对路径>」（设计契约禁 `title`，全路径在 aria-label 里） |
| 未知 | 本轮所有 run 的 `filesCreated` 都缺省 | 一行「本轮产出未知」+ 原因（外部 CLI 的文件操作不可见 / 远端会话 / 探针没跑）。**agent 声称的文件一个不列** |
| 混合 | 部分知道 | 列出数得出的，再加「另有 N 次运行产出未知」 |
| 确认没新建 | 全是空数组 | **不画**。`GENERATED · 0` 是噪音 |

点 chip：打开坞的「产物」格并选中它（坞关着就开）→ 直接进预览。chip 没有 ⋮ 菜单（§0 收窄 3）。

## 5. ② 坞的「产物」格

坞的一个新房客，标签 `产物 (N)`，N 实时跟着变。两个视图：

**清单**（默认）：
- 按目录分组，组头 `outputs/ · 5`，不可折叠（§0 收窄 1）；组内按出生时间。
- 一行 = 文件名 + 类型徽标 + ⤓ 下载（远端才有）+ ⌖ 在文件里定位；没有 ⋮ 菜单（§0 收窄 3）。远端会话 `exists` 缺省，行上不标「已不存在」也不禁用。
- 顶上「另有 N 次运行产出未知」（N > 0 才显示）。
- 已删的标「已不存在」，不移除；⤓ 与预览禁用。
- 空态：「这段会话还没有生成文件」——与「未知」分得开。
- **实时**：收到 `artifactsChanged` 就重拉；新长出来的行不闪不跳，清单保持滚动位置。

**预览**：点一行 → 这一格里显示（**复用文件格的预览组件**，三态；远端 = 一次下载），头上一条「← 返回清单 · 文件名 · outputs/ · 本机」+ ⤓。

面板状态（清单 / 预览、选中项）是**组件内状态**，按会话 `key` 重挂——切会话不带过来；不持久化（§0 收窄 1）。清单取失败时产物条说「产物清单没取到：<原因>」，**不落成「没有」**。

## 6. 失败必须出声（规格 7.5）

| 情况 | 说什么 |
|---|---|
| run 的 `filesCreated` 缺省 | 「另有 N 次运行产出未知」+ 原因 |
| 产物已不存在 | 清单标「已不存在」；预览「找不到 outputs/x.png（曾由这段会话生成）」 |
| `listArtifacts` 失败 | 格里出错态 + 重试，不是空清单 |
| 远端预览下载失败 | 沿用文件格的出声 |

## 7. 分层

## 8. 怎么验（准入规则 3）

- 单测：迁移（老 run 的 `filesCreated` 缺省）；`filesCreated` 算法（`??` ∪ 登记、覆盖已有不算、非 git 且工具声明了 = 登记结果、非 git 且没声明 = 缺省、探针失败 = 缺省）；产物查询（跨会话不算、删后仍列、按出生排序、`unknownRuns` 数对）；`listArtifacts` schema 双向校验；按 turn 派生的筛法。
- e2e（真构建产物 + 假模型）：假模型吐 `write` 真写一份 csv → 产物条出现 → 点 chip 进预览 → 返回清单。另一条：外部 CLI 会话那轮画「本轮产出未知」且**不列 agent 声称的文件**。第三条：只 `read` 的一轮既不画产物条也不说「产出未知」。
- 设计契约扫描：新文案不与已有按钮文案互为子串。
- 视觉基线：坞多一个房客会动几张基线——**先看 diff 再重存**。
