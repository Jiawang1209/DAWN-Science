# 舒展双栏首页与新建项目

用户已于 2026-11-16 选择“舒展双栏”并授权在独立分支实现。

## 页面与导航

顺序保持四步引导 → 首页 → 工作台。首页使用 DAWN 现有主题令牌与图标：居中的有限宽版心、品牌和操作区、左侧项目卡片、右侧最近会话。最近一段会话有柔和强调。工作台仍可返回首页，底部“导航栏”仍打开四步引导，保留挂载的工作台与草稿。

首页可直接新建普通对话；打开项目继续使用原生目录选择器。项目卡片可收藏、编辑名称与仅供展示的说明。收藏优先，其余保留已有创建顺序。所有项目和会话来自真实后端，无样例数据。

## 新建项目

独立模态弹窗包含名称、父目录、可选说明；原生选择器选择父目录，同时允许粘贴绝对路径，显示最终子目录路径。名称是单个跨平台安全目录名。必须选择已存在的父目录；创建同名子目录，目标存在（包括空目录和符号链接）时拒绝，引导使用“打开项目”。不复用、覆盖或移动既有文件。

默认收起“科研目录与 AI 约定”：可选标准科研布局默认关闭，Agent 上下文默认空。说明仅存数据库、不进入提示词。启用布局时复用 `policy/science-layout.ts` 的目录和约定；自定义上下文与布局约定共同写入新目录的 `AGENTS.md`，复用既有资源加载机制，不额外发一条用户消息。Native 新会话应读取该文件；外部运行时对指令文件的支持遵循其既有行为，不新增虚假的支持保证。

创建成功后刷新项目并进入该项目工作台，首句才创建会话。失败保留表单和原因；取消原生选择器保留原值；保存中禁用重复创建与关闭。弹窗支持 Escape、焦点约束与关闭后焦点恢复。窄窗允许纵向滚动，不出现横向滚动。

## 数据与边界

新增 `createProject` 与 `updateProject` 协议。项目描述和收藏在 SQLite 项目记录中保存，兼容旧记录。项目设置只改名称、说明和收藏；目录不重命名，Agent 上下文通过工作区文件编辑。

创建由主进程执行：验证父目录、独占创建子目录、创建可选文件和目录、最后插入数据库。失败仅清理本次创建且未被外部改动的内容；如无法清理则报告残留路径，不递归删除。只读宿主拒绝两种写操作。数据库迁移采用现有事务机制。

## 验收

项目创建、重复目标拒绝、路径穿越/相对路径/保留名拒绝、无布局无上下文、布局和上下文保存、描述隔离、失败回收、旧数据迁移、收藏保存。组件验证目录取消、错误重试、重复提交与焦点；Electron 验证从引导到首页到工作台、创建后首句归属、Agent 实际读取项目上下文、返回首页与设置持久化、明暗主题和窄窗。假模型和开发模式共享同一推理夹具，协议与数据库仍走真实后端。
