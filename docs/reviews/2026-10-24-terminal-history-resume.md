# 终端历史会话恢复检查记录

基线：本地 main `77c49585`。开发分支：`codex/terminal-history-resume`。工作区使用独立 Electron 配置、数据库和工作目录；不合并、不推送、不打包、不替换安装版。

## 交付行为

Normal 工具栏的“接续旧对话”按 Shell 当前真实目录列出本地、未归档的 API 主会话；支持标题搜索与取消。`dawn --resume` 支持编号选择，`dawn --resume <完整ID>` 直接恢复。普通 `dawn` 仍新建。

恢复复用原 session ID、pi 历史记录、模型选择和图片上下文；不复制消息、不新建替代任务。返回会话打开同一 ID。应用重开后也从原始消息重建用户图片缩略图。另一 CLI 已占用、正在流式回复/转述/压缩/回退/停止、已归档、已删除、远程、PTY 或跨目录目标会被拒绝。

## 复核修正

补齐外部无 terminal ID 的 CLI 占用登记和退出清理；历史查询通过空闲 Shell 的随机标记探针读取 `pwd -P`，协议新增操作明确标为 mutating；旧 Markdown 返回图通过现存工作区原文件恢复。剥离 CLI 历史中的 GUI 图片字节，超过缓存时过滤失效 ID 并标记截断。忙碌检查在异步订阅前后执行。上述问题均有复现与修正后回归；最终只读复核未发现其他必须修复项。

## 第一版边界

只恢复当前目录的本地普通 API 主会话；独立 CLI 未连接桌面时明确拒绝此入口。列表最多 100 项，显示最近 100 条/1 MiB 记录、最近 12 张原始图片，终端缓存最多 24 张/64 MiB；展示截断不会替换或裁剪模型的原始上下文。旧返回图文件若已移走则提示，不重跑工具。不恢复已经结束的 Shell/REPL 变量。

证据位于本工作区忽略目录 `tmp/terminal-history-resume/`：测试日志、真实模型文字记录和界面截图；不含凭证及原图字节的实测 JSON。真实预览为单独临时 profile，数据库、模型会话目录和工作区均隔离。
