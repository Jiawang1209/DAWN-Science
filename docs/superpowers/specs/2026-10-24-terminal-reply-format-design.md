# DAWN 完整终端 Agent 交互设计

状态：用户已选择“连输入区和整个终端交互一起重做”；本方案据此扩展，取代之前仅改善输出的提案。分支 `codex/terminal-reply-format`，基线 main `367d2f61`。

## 布局和行为

Normal 始终是原 Shell。进入 DAWN 后使用真正的终端 TUI：顶部两行显示产品、模型、工作目录；中间为可滚动的会话记录；底部固定多行输入区和一行状态/快捷键。实际输入行使用 `> DAWN ` 前缀，问题直接跟在后面；续行与问题文字对齐。没有另一套网页聊天输入。

Enter发送；Shift+Enter或Alt+Enter换行（内置终端显式传递Shift+Enter）；粘贴的多行作为一条输入，方向键编辑和浏览历史；斜杠菜单提供/help、/status、/exit。生成期间可以编辑下一句，但发送时明确提示本轮仍在执行，不新增隐式队列。Ctrl-C执行时中止，空闲有草稿时先清草稿，再次Ctrl-C退出；/exit退出。Normal按钮仍通过原控制通道退回同一个Shell。

正文实时Markdown渲染，而非等待整轮后打印。标题、列表、代码、表格按终端列宽换行。工具使用紧凑记录，Tab切换工具详情，失败、权限确认和结构化问题必须直接可见。浏览旧内容暂停跟随，End/回到底部入口恢复跟随；PgUp/PgDn和鼠标滚轮可滚动。输入焦点与候选位置正确支持中文。

## 架构和兼容

复用已有pi-tui的Editor、Markdown、ScrollView和TuiAltScreen，通过显式直接依赖固定当前版本0.86.0。会话记录是组件树；输入、权限问答、取消与已有Agent操作共用控制器。非交互管道保持逐条请求、纯文本、EOF退出；模型、工具权限和数据库协议保持原有入口。

TUI使用备用屏幕，退出恢复原Shell屏幕和终端模式。启动失败和连接断开也必须恢复。完成输出可以通过“返回会话”查看同一原生会话；本轮新增格式不合入main，先打开独立分支真实预览。

现有xterm图片装饰在备用屏幕隐藏，不能直接沿用。新增仅用于TUI可见区域的图片定位帧，宿主按不透明ID读取缩略图；滚动/重排/离屏时同步隐藏或定位，点击时重新读原图，禁止保留失效原图。旧Normal历史行装饰继续兼容。

定位帧为OSC777，payload是`dawn-viewport;`加JSON：`{"images":[{"id":"UUID","row":0,"col":2,"width":30,"height":7}]}`。坐标单位为终端格、从0开始，必须完全在屏幕内；仅在备用屏幕处理，最多24张。空数组清理当前可见图片。帧中只有ID和位置，不包含图像数据、路径或凭证。

正文与工具仍先清除外部终端控制指令，Markdown仅生成受控样式。复制选择使用本机剪贴板接口并报告真实失败，不能只写OSC52就声称复制成功。颜色使用默认终端前景、强调色和语义色；NO_COLOR禁颜色。模型原文不因界面设计被改写。
