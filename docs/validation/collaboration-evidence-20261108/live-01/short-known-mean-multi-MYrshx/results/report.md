# temperature_c 算术均值 — 结果报告

## 1. 输入

- 数据文件：`input.csv`（相对项目根目录，只读；本脚本不修改它）
- 目标列：`temperature_c`；单位：`°C`（由用户指定，非由数据推断）
- 数据行数：4；目标列非缺失样本数：n = 4
- 目标列取值：14, 18, 22, 26
- 缺失值规则：`drop NA in target column only`（宿主 missing=block）；仅对目标列判定缺失，本轮目标列缺失 0 个
- 结论：目标列 4/4 有效，规则未触发，未删除任何行、未插补任何值

## 2. 处理

- 方法：等权算术平均 `mean = sum(x_i) / n`，全部观测等权，无加权、无分组、无抽样
- 单位保持 `°C`，不做任何单位换算
- 无插补、无删行（除目标列缺失）、无截断、无离群值剔除
- 未引入外部数据、网络请求或第三方包；Python 标准库 `csv`/`json`/`math` 与内置算术
- 脚本内断言：n > 0、所有观测有限、均值有限、均值落在观测区间 [min, max] 内
- 执行模型：单进程，脚本内不创建子进程/线程；只读 `input.csv`，只写本目录两个产物

## 3. 结果

| 项目 | 值 |
|---|---|
| n（参与计算样本数） | 4 |
| unit | °C |
| mean | 20.0 |
| 观测区间 | [14, 26]（均值落在区间内） |

即 Σx = 80.0，n = 4，算术均值 = 20.0 °C。

机器可读结果见 `results/result.json`（平铺对象，三项键：`n`、`unit`、`mean`）。

## 4. 局限

- 仅报告点估计；n = 4 且为自制小样本，不报告置信区间、不做假设检验，也不外推总体
- 单位 `°C` 来自用户指令；数据本身无独立单位标记，无法由数据佐证量纲
- 均值对离群值敏感；本样本量下有单个异常值即可显著移动结果，但按契约不剔除任何行
- 未做分组/分层比较（如按 site），本任务只求总体算术均值
- 未评估测量误差、采样代表性或缺失机制（本轮目标列无缺失，故缺失机制未受检验）

## 5. 复现

在项目根目录（含 `input.csv` 与 `results/`）执行单一命令：

```bash
python3 -I results/analysis.py
```

预期输出：`n=4 unit=°C mean=20.0`，并重写 `results/result.json` 与本报告。
