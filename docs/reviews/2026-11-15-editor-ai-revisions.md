# 对话修改应用回原脚本：实现与验证

日期：2026-11-15。分支：`codex/editor-word-wrap`；基线 `f0767d04`。本轮保留原有自动换行功能，未合并 main 或推送。

## 当前流程

1. 在当前脚本中选择代码，点「带入对话」。完整当前草稿（含未保存内容）和精确选区、文件路径/行号一起进入原会话输入框，用户补充要求后主动发送。
2. 当前窗口保存请求快照，绑定原文档与会话。只有实际用户发言所对应的已完成 AI 回复能显示「查看差异」。普通独立代码块仍能「在旁边编辑」。
3. 原生差异对话框显示实际将应用的增删行、行号和目标文件。默认把 AI 返回的完整脚本作为候选；若回复只有片段，可选择「仅替换所选代码」并重新查看实际候选差异。
4. 点「应用到原脚本」后，通过原 CodeMirror view 产生一次独立可撤销的编辑，原文档 ID、路径、保存基线、磁盘版本和会话内核保持原身份。应用只更新草稿，保存和运行仍是显式操作。已应用的回复可以「回到原脚本」。

每次修改对应一次完整草稿快照。下一轮修改应重新选区、带入最新草稿；普通追问不自动复用已经消耗的快照。AI 回复期间或审阅期间继续修改原文后，旧建议会拒绝应用。请求过期、窗口重新加载后失去上下文、错误会话或重复应用都不会创建替代草稿或覆盖后续编辑。

## 审查与修复

规格审查与独立质量审查完成，最终均通过。

- 质量审查发现：原始 CRLF 上下文经过真实 textarea 会规范化为 LF，原来的完整字符串匹配会错误地把合法回复判为失效。新增真实 textarea 回归，先失败后通过；关联比较与多请求歧义检查统一使用规范化 LF，脚本及选区原字节仍保留 CRLF。
- 真实模型现场回复使用大写 `R` 围栏，旧的自定义 Markdown 渲染器只注册小写语言，因此没有编辑/差异入口。新增 `R`、`Python`、`PYTHON` 三个失败回归；为已知语言注册大小写及首字母大写写法，并统一语言身份，随后通过。真实回复无需再次请求即可关联到原文件并应用。
- 绘图历史回归最初少一张图。检查证明旧测试用 Shift+Home 只选中了软换行的可视行，提交的并非它声称的整条逻辑行；改用 CodeMirror 的原生逻辑行选择快捷键（macOS Ctrl+L，其他平台 Alt+L），并增加选区原文逐字断言。未放宽图形数量或执行结果断言，重跑通过。

## 真实模型现场与边界

在当前隔离体验实例里只读复用已有模型凭证，发送了一次真实 DeepSeek 请求。示例使用 R 内置 iris 数据与 ggplot2，要求只改选中的绘图语句。实际回复保留了原脚本的分析设置/对象定义，增加 Okabe–Ito 配色、底部图例和新标题。

现场确认：查看差异前后磁盘文件未被自动改变；主动应用后文档仍指向原 R 文件；主动保存后字节与草稿一致；真实 R 内核执行成功，生成 720×480 图形。示例会话为「AI 修改回原脚本 · R」，文件位于体验工作区的 `plot-experience/original-script-ai-demo.R`。原来的 4 个文档、未发送要求、选区和保存版本已备份恢复，并逐文档比较一致；新增示例没有替换它们。

自动化的模型回复来自隔离假服务；真实 DeepSeek 验证仅上述一次现场，不代表所有模型都能遵守完整脚本回复约定。差异人工确认承担语义审核；片段需明确选片段模式。完整上下文上限 128 KiB，候选脚本及差异有字节/行数/时间限制，超限不截断、不静默应用。请求仅保留在当前窗口，不承诺重启后恢复。后端文件冲突保护与远端路径/原子保存沿用原实现，本轮没有验证用户生产 SSH 服务器或发布安装包。
