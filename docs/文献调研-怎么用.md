# 多篇论文精读与对照

内置技能 `literature-review` 默认启用，在 **设置 → Skills** 可查看、改为只手动或关闭。它复用当前会话已有的 PDF、Excel 和文件工具，无需新增密钥或插件。

## 开始使用

把论文放进项目目录，或作为附件加入会话，然后直接说：

> 比较 papers/ 中这几篇论文的实验设计、生物重复与技术重复、分析方法、主要结论和局限。每项附原文件、PDF 物理页和原文短摘，生成 Excel 对照表与 Markdown 总结。

也可以明确指定：

```text
/skill:literature-review 比较这 5 篇论文，按样本量、方法与结论整理证据对照表。
```

已有具体字段或输出位置时直接说明。只想先讨论可加“先讨论，不读写文件”。模型可根据技能说明选择此流程；显式调用更直接，但阅读、提炼和判断仍由当前模型完成。

## 会得到什么

每次使用一个新的 `outputs/literature-review/<本次唯一目录>/`，保留论文与旧输出：

- `论文对照.xlsx`：文献清单、逐项证据、差异对照三张表。以 P1/P2 等文献编号和 P1-E1 等证据编号连接；样本量保留单位和组别，生物重复与技术重复分开。
- `文献总结.md`：问题、材料与已读范围、发现、分歧、局限和待补充信息。原文结论与模型归纳分开，并连接同一组证据编号。

引用页码为从 1 开始的 PDF 物理页；论文印刷页码可能不同。可从产物清单打开文件，在原 PDF 中回到对应页核对。此版本不增加点击证据自动跳页的界面。

## 材料和能力边界

- PDF 需可提取文字。扫描件、空白页和需要看图才能核实的内容会标记，不承诺自动 OCR。全文可读不表示已经逐页读完，交付应写实际已读范围。
- 只有摘要、题录或文献索引记录时，不能补造正文中的 n、方法与结论。缺字段写“未提供”，未读全文与文本提取失败分别标记。
- OpenAlex/Crossref 可按需协助查询元数据，不会自动获得受限全文；DOI 可查到也不证明论文支持某项结论。检索属于另一步，给定论文对照不必联网。
- 相反方向不等于研究互相推翻，需要先核对对象、设计、终点和独立样本；同一研究的多篇报告不算多份独立证据。不自动做荟萃分析或将所选材料称为穷尽的系统综述。
- PDF/电子表格工具由原 Office 插件开关控制；关闭后不会借别的工具安装或绕行。更改工具开关后新建 API 会话。外部 CLI/ACP 的工具取决于对应运行时；技能不额外赋予读写能力。

保存后会读回核对表格与总结。工具显示截短的长单元格仍需查看完整文件；文件生成和读回核验不代替研究者对证据与科学判断的复核。
