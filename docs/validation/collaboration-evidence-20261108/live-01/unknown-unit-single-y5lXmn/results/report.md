## 5. 方法适用条件与局限

- 算术平均适用于同一变量、同一单位、同一尺度的独立观测；本数据每行一个 `site`（plot），未见重复测量或权重字段，故未加权平均与数据形态一致。若站点为不等面积/不等抽样强度，正确做法是按权重加权，这需要额外信息，当前数据不具备。
- `carbon` 的分布、异常值与检出限未做处理，仅按约定规则剔除目标列 NA；n=41 的简单均值对极端值敏感，本数据未见明显极端值（范围 12.0–15.6），但未做正式异常值检验。
- 未做任何推断统计（无置信区间、无假设检验），任务只要求均值。
- 结论仅覆盖该 CSV 中的 41 个有效站点，不能外推到其它样地或区域。
- 报告中的未带单位数值已由独立于脚本的 `awk` 复算核对（n=41，sum=568.7，mean=13.870731707317），与脚本输出一致；这不改变「单位缺失 → 阻塞」的结论。
