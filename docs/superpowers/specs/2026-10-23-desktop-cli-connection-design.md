# DAWN / Normal 与桌面模型复用

用户要求直接复用已经配置的模型和 API key，接真实模型预览，并增加 DAWN 模式 / Normal 模式按钮；继续独立分支，不合并、不推送、不替换安装版。

采用本机 CLI 连接：CLI 与桌面主进程通过私有 socket 通信，Agent、模型解析、凭证读取、工具、权限都在桌面现有 Workbench 中执行。协议只允许当前 CLI 会话的发送、等待、权限、问答、中止和关闭，不提供凭证读取或通用工作台调用。API key 不传入 CLI，不写命令、环境或新文件。连接用短期随机令牌及私有目录，仅为本机前端建立连接，不是模型凭证。

CLI 默认跟随其终端所属 DAWN 对话当前选中的模型；CLI 独立运行历史由同一个桌面后端管理，不干扰主对话的正在执行任务。没有所属对话时使用已配置的本地 API Agent。每次启动验证真实 cwd，CLI 工具在启动目录工作。退出只停止 CLI 自己的 Agent 会话，保留原 Shell；返回后再次打开创建新 CLI 会话。

顶部 DAWN 模式 / Normal 模式按钮复用同一个 xterm。DAWN 按钮仅在真实 Shell 就绪且没有未提交输入时启动 CLI；程序正在运行或解释器未退出时明确说明，不盲目发送命令。Normal 请求 CLI 正常退出，等待连接结束，不对原 Shell 发送终止信号。状态来自已认证 CLI 连接，手动 dawn / exit 同步按钮；转换期间锁定按钮并就地显示失败。

开发版生成自己的临时命令启动器和连接描述，PATH 只传给自己创建的终端；外部源码 CLI 可发现同一开发版连接，独立 CLI 仍保留已有环境凭证方式。主进程退出、终端退出或连接断开时清理 CLI 会话和自身临时资源。

真实预览另建配置与数据库，只读复用现有加密凭证；原配置/凭证内容用校验值核对未修改。预览不复制明文 API key，不迁移生产数据库、不替换安装包。真实模型只在隔离的小目录做有限读文件/写演示文件验收；不让它操作真实科研数据。

验证包括错误令牌、越权操作、错会话、断开与中止、模型继承、无 API key 环境变量启动、真实权限/工具、手动与按钮状态同步、Shell PID/cwd/env 保留及窄窗明暗布局。检查通信描述、命令和日志中没有模型密钥。
