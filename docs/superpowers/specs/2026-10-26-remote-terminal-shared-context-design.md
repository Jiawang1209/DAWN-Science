# 远端终端与原会话共享上下文

用户已批准实现，独立分支，不合并、不推送、不替换安装版。当前正在使用的会话和预览不能被测试操作影响。

一个远端 API 会话拥有同一 sessionId、connectionId、RemoteCwd、模型、权限、方案和历史。通过当前 SSH 客户端新增持续交互 Shell 通道；每个终端有独立实例标识。Normal 原样转发键盘和输出；DAWN 模式使用本机 CLI/TUI 作为呈现端，绑定原远端会话和所选远端终端，不在服务器安装 Agent、不复制对话。返回会话/退出 Agent 只解绑呈现端，不能停止主会话；明确关闭终端才关闭对应远端 Shell。

会话内的 bash 在存在关联终端时复用该 Shell，不使用每命令新进程的路径。结构化完成、目录和就绪标记同步真实状态；忙碌、断线、未知状态均不得偷偷改用本地执行或另一条 Shell。相对文件路径同步 RemoteCwd；原 Notebook 内核仍是独立进程。并发写入通过同一会话任务状态与具体终端身份约束。手动操作后的状态在下一次 Agent 请求前更新。

显示仍沿用现有页面、终端工具栏、DAWN/Normal、返回会话。标题显示服务器和远端目录。断线清楚标明状态，恢复对话历史不等同于恢复旧进程；不添加固定会话到期。

验证仅使用临时数据库、临时工作区、测试模型和 loopback SSH 服务器；不得读取或写入当前预览的数据库、凭证或终端。最终独立测试预览也必须使用独立资料，不能为预览关闭用户正在使用的窗口。
