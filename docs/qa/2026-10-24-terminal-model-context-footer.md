# 终端底栏模型与上下文检查

分支 `codex/terminal-reopen-context`，基线 `11f794a9`。不合并、不推送、不替换安装版。

用户要求模型位于 token 统计最前，上下文长度位于最后，沿用会话页原有口径。实现为 CLI 用量快照中的独立 `context`：同源调用 nativeRuntime.contextUsage，保留当前模型、已用/上限、估算与压缩状态，不把累计输入输出当作上下文占用。桌面与独立 CLI 共用同一装配读数。

底栏顺序：模型 → 轮次/工具/输入/输出/缓存/命中率 → 上下文已用/上限（百分比）。未知显示未采集，估算标约，刚压缩显示已压缩，不将缺失当零；未知上限不算比例。模型变更与压缩完成会刷新，沿用既有晚回包守卫。

宽屏居中，窄屏按完整字段居中换行。12 行及以下隐藏顶部重复模型/目录，保留单一输入和完整底栏；图片坐标同步使用实际顶栏高度，补回归防止图片下移覆盖输入。

- 最终相关测试：11 文件、201 项通过（CLI、桌面历史接入与 UI 边界）。类型检查、构建通过，既有 chunk-size 提示保留。

- 宽窗口 1280×840 与窄窗口 900×700 实际观察并保存截图，模型与上下文完整可见，页面没有横向溢出；38×10 输入、权限提示及底栏由 headless 回归验证，短视口图片由帧坐标回归验证。
