## 交付行为

DAWN 模式粘贴/拖图先暂存，下一句话与原图一起发送；原终端仍是唯一文本输入。待发图可放大/移除，上传处理中阻止回车，发送失败保留图片。Normal 不附图，隐藏的原主人会话不接图。目标在主进程绑定当前认证 scope，退出/新 CLI 不继承待发图片。

输入图、内核结构化图片、工具文件事实及回答中已验证的本地 Markdown 图片，在 xterm 标记位置用 decoration 显示缩略图，点击同一预览浮层，Esc/关闭返回原输入。图片不进入 PTY 字节缓冲或 4 MiB CLI socket，只有不透明 ID 标记；文字继续过滤转义。图片操作由协议 8.29 的三个具名操作承担，共享 mock 和精确操作/版本清单同步。

返回会话继续原 native ID，保存的图片继续参加模型上下文；原主人草稿不混入。终端输出缓存有数量/字节上界，过期 ID 给出提示，输出路径沿用 realpath 工作区守卫。
